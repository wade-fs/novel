# 《萬界風月樓》敘事規則與詞庫 v1.2

> **文件定位**：本文件是全書寫作的核心參考手冊，分為兩大部分。
> - **第一部分：敘事規則** — 創作原則，決定「怎麼寫」。
> - **第二部分：詞彙庫** — 查詢工具，決定「用什麼詞」。
>
> **重要聲明**：詞彙庫是**查詢工具，不是寫作配方**。
> 正確做法是：先確定人物此刻的情緒、關係與劇情目的，再從詞庫中選擇適合的表達。
> 切勿每次都按照固定順序套用詞彙——十次下來，讀者立刻感受到公式化。

## 第一部分：敘事規則

### 規則一｜三種敘事語言模式

| 模式 | 適用場景 | 語言風格 |
|---|---|---|
| **A. 古風含蓄型** | 重要情感場景、初期關係、女主道心蛻變 | 以雲雨、鴛衾、交頸、陰陽交泰等詞為主；重視情感、羞澀、信任的層次變化 |
| **B. 通俗直白型** | 熱烈段落、輕鬆情節、人物調侃 | 可用讀者熟悉的俗稱與動作名稱；嚴禁讓敘事退化為「姿勢清單」，必須配合人物情緒 |
| **C. 玄幻雙修型** | 修煉共鳴場景、萬界樓本源提升 | 以靈息、陰陽、本源、神魂、道基、天人感應為主；親密關係須真正影響修為、世界法則與萬界樓演化 |

**切換原則**：同一**場景**應保持主要敘事模式一致；同一**章節**可因情節轉折切換模式，但必須有明確的敘事理由，並保持轉換自然。

> **示例**：一場雙修情節可先用古風含蓄型描寫情感交流（A），進入修煉高峰時切換為玄幻雙修型（C），修煉結束後的溫存再回到古風含蓄型（A）——三段各有主調，層次更豐富。

### 規則二｜依女主個性選詞，禁止共用同一套模板

《萬界風月樓》每位女主個性不同，不可讓她們在親密場景中呈現相同反應。

| 女主類型 | 核心個性 | 親密場景原則 |
|---|---|---|
| **清冷仙子**（如柳清虛） | 清雅、克制、道心堅守 | 以含蓄為主，羞意內藏而非外露；進展緩慢，逐步展現主動 |
| **溫婉賢淑型** | 柔情、細膩、善解人意 | 情感外露但不積極主動；以依偎、低語、溫柔回應為主 |
| **熱情奔放型** | 坦率、主動、情緒外顯 | 可直接使用主動靠近、坦率表達；不必鋪陳太長 |
| **傲嬌強勢型** | 表面硬撐、內心動搖 | 寫「逞強後的崩潰」；別開目光→忍不住回頭 |
| **成熟御姐型** | 從容、掌控、柔中帶剛 | 她主導節奏；顧淵偶爾被她牽著走 |
| **高冷女帝型** | 威儀難撼、偶露柔情 | 只在極私密的瞬間卸下威儀；以稀缺感製造衝擊 |
| **魔族女主型** | 直接、強烈、愛恨分明 | 情慾直白，不繞彎子；衝突與激情並存 |
| **理性女學者型** | 克制、觀察、以理解代替衝動 | 寫她的「觀察→理解→接受」三段心理；情感發展有邏輯推進 |

### 規則三｜親密場景的五個寫作禁忌

1. **禁止只寫「許久之後」** — 時間流逝必須有詞彙支撐（見詞庫第九節）。
2. **禁止讓顧淵以粗獷急切的方式主導** — 他的性格是從容、克制、溫柔而有力量；強勢感來自從容，而非急切。
3. **禁止讓女主只是被動等待** — 每位女主都有自己的行動與選擇，即便是羞澀的反應也要有她主動的成分。
4. **禁止所有場景都以男主為視角** — 適時切換至女主的內心視角，讓讀者感受到她的情感變化。
5. **禁止雙修場景與劇情脫節** — 每次雙修必須對應劇情需求（救命、突破、萬界樓修復），且雙修結果必須在後續章節中有所體現。

### 規則四｜雙修的四個層次，逐步推進

雙修深度應隨兩人關係發展而推進，不可一步到位。

> **注意**：四個層次是雙方關係與修煉深度的**發展階段**，不是每次親密互動都必須依序完成的固定流程。實際寫作中，可在同一層次內多次深化，也可在某次特殊情境下短暫觸及更深層次，視劇情而定。

| 層次 | 關係階段 | 核心體驗 |
|---|---|---|
| **第一層** | 初識·互相信任 | 試探、陌生、少量靈力初步交換 |
| **第二層** | 信任建立 | 神魂接觸，彼此感受對方的道心與過去 |
| **第三層** | 情感確認 | 本源深度融合，心境共鳴，彼此真正了解 |
| **第四層** | 道侶契合 | 神魂相契，生命印記深化，超越肉身的靈魂連結 |

### 規則五｜萬界樓修復的書寫規範

- **基準**：初次共鳴以 **0.01%（1/10000）** 作為起點，此後增量依共鳴品質及本源契合度判定，非固定公式。
- **禁止自動累加**：不得單純因為時間更長或次數更多，就自動增加修復量；每次修復必須交代具體原因與結果。
- **三軌分離**：樓體修復、顧淵修為成長、女主成長，三者有不同的計算依據，不可混為一談。
- **品質優於數量**：心境突破、危機救助、跨世界本源首次接觸等，可觸發比基準更高的共鳴獎勵；低品質的重複則不超過基準。
- **顧淵的能力展現以「樓主特權」為主**（如破妄真視、神魂感知），不以個人武力橫推；個人修為成長附屬於萬界樓修復進度，不可單獨暴漲。

### 規則六｜情感與修煉不可交易化（兼論正文反哺分寸與「選擇性同行」）

**親密關係本身不是換取力量、資源或萬界樓獎勵的交易。**

- 雙修可以帶來修煉成果，但人物必須先有自己的情感、意願與選擇。
- **正文書寫「感情昇華順帶反哺古樓」（嚴防工具化觀感）**：大綱層面雖將雙修定義為萬界樓「唯一修復能量引擎」，但**正文落筆時絕不可反客為主寫成「為了刷修復度而雙修」**。正文必須始終以兩人的情感積累、心防卸下、靈肉交融與事後溫存為主體；萬界樓的本源回流與設施顯化，只作為**感情昇華後水到渠成、順帶引發的自然反哺**輕落於後，杜絕任何「女主是系統燃料」的工具化觀感。
- **「獨立」分寸是「選擇性同行」，而非「拒絕依賴」**：塑造獨立型女主（尤其如洛寒衣等強者武道／仙道角色）時，不可將「獨立」寫成生硬排斥幫助、冷漠逞強的「拒絕依賴」；真正的獨立是**「本有獨行天地的底氣與判斷，卻願意清醒而主動地把後背與前路交給對方——選擇性同行」**。
- 女主不能因為需要救師尊、拯救宗門或取得資源，就被敘事設定成必須付出親密關係作為代價。
- 顧淵可以提供幫助，但不能利用對方的危機換取情感或身體上的承諾。
- 任何一方都有拒絕、暫緩或中止的權利，敘事中不得設計讓這種拒絕顯得「愚蠢」或「代價慘重」的情節。

> **這不會削弱爽文**，反而讓顧淵更有魅力，也讓女主更有獨立人格。讀者對一個「值得被愛」的男主，遠比對一個「讓女主別無選擇」的男主更有好感。

---

### 規則七｜長文篇幅與推進節奏規範

本書面向喜愛沉浸式長文閱讀的讀者，**嚴禁為了趕章節進度而將重要戲份寫成大綱式快轉**：

- **常規推進章節**：建議 **5,000～7,500 字**，留足環境氛圍、角色神態、對話機鋒、心理轉折與生活日常的呼吸空間。
- **重要情節／核心大章**：舉凡關鍵情感雙修、多女主同堂交鋒、重大商政談判、宗門保衛戰、核心世界觀揭露與卷末收官章節，**建議寫至 8,000～12,000+ 字（破萬字完全合理且鼓勵）**，以飽滿細節撐起劇情推進的合理性與情緒張力，絕不刻意壓縮字數。

### 十三｜親密關係的情緒轉折

> 適用於親密場景中間及前後，讓人物關係有真實的發展弧線，而非直線推進。

| 情緒階段 | 詞彙 |

### 十四｜事後對話與溫存

> **這一節尤其重要**。親密場景結束後，直接跳到系統提示是最大的敘事損失。
> 女主可能在此時問一個問題、談起自己的過去、表達擔憂，或第一次主動提出未來的約定——這些往往才是關係真正深化的地方。

| 情境 | 可寫內容 | 詞彙提示 |
|---|---|---|
| **輕鬆調侃** | 兩人說笑、顧淵少見地被女主打趣 | 低笑、眼角含笑、調侃一句、被她說中了 |
| **沉默溫存** | 不說話，只是靠在一起，各有心思 | 靜靜相依、無需言語、呼吸漸緩、各自想著 |
| **問出心底話** | 女主問顧淵一個她平時不敢問的問題 | 忽然開口、聲音很輕、猶豫了很久才問 |
| **談起過去** | 女主講述自己的師門、往事或傷痛 | 閉上眼、語氣平靜、像是自言自語 |
| **表達擔憂** | 女主說出她對未來的不安或疑惑 | 蹙眉、咬著下唇、說出那個最怕的可能 |
| **安慰** | 顧淵用行動而非言語安慰 | 輕撫、緊了緊手、低聲應答、只說了兩個字 |
| **立下約定** | 兩人說出某種未來的承諾，可輕可重 | 那就說好了、我記住了、她伸出手來 |
| **共同規劃** | 討論接下來要做的事，讓親密場景自然接回劇情 | 說起明日的計畫、她又恢復了平日的神情 |

### 十五｜不同世界的親密文化

> 萬界樓會到訪不同的世界，各世界的文化背景與人物價值觀不同，親密場景的語言與反應也應有所區別。
> 切勿讓每個世界的女主都以同一套修真仙俠語言作反應。

| 世界類型 | 文化特色 | 語言風格調整 |
|---|---|---|
| **修仙世界**（如青玄界） | 道心至上、以禮為重、身心皆修 | 古風含蓄；以道心、靈脈、陰陽、心境為核心意象 |
| **武俠世界** | 重義氣、重承諾、以身相許即江湖誓言 | 豪爽直白；以刀劍、江湖、義字為情感錨點 |
| **魔法世界** | 契約觀念強、情感表達直接、魔法與情感往往交織 | 中西混合；魔法意象（星芒、契印、魔力共鳴）融入親密描寫 |
| **星際科幻世界** | 理性優先、種族差異、身體接觸具有特殊文化意義 | 理性觀察→情感突破；以數據、波長、心跳頻率等為情感隱喻 |
| **神域世界** | 神格威儀、感情稀有而珍貴、一旦動情便震動天地 | 莊重、稀缺、以天地異象烘托情感分量 |
| **魔族世界** | 情慾直白、強弱關係明確、以力量表達情感 | 直接、強烈；衝突與激情共存，情慾中帶著力量的較量 |
| **人間帝王世界** | 權謀優先、情感被壓抑、一旦釋放更有衝擊力 | 克制→崩潰；用「對比」製造爽點，以禮教束縛的崩解作為情感高潮 |
| **靈獸異族世界** | 本能驅動、氣息感應、情感表達方式迥異於人族 | 以氣息、本能、靈性感應為主；語言描述可更感官化 |
