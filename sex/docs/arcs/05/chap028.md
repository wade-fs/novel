# 第028章｜藏書雅集

- **所屬篇章**：第四篇《亂世流年》（chap025～chap032）
- **時間**：第三年夏
- **地點**：江左文社雅集園林
- **主要人物**：顧淵、蔡琰、李清照、薛濤、謝清之
- **關鍵進度**：
  - 思想高潮：史書與金石的理念交鋒與互補融合。

## 核心劇情
江左文社舉辦藏書雅集。蔡琰以《大胤史稿》論歷史真相，李清照以金石拓本論生活痕跡，兩人對史料保存的優先次序產生激烈討論。顧淵提出：「史書留興亡，金石留痕跡，合之方為完整時代。」這句話成為兩人思想互補的起點，而真正完成理念融合的，是蔡琰與李清照自身的討論。

## 場景節拍
1. **江左雅集**：名士才女齊聚一堂，展示各自劫後餘生的珍本與拓片，氣氛雅致卻暗藏亂世焦慮。
2. **雙姝論道**：
   - 蔡琰主張：人力有限，當優先搶救與寫定《大胤史稿》，讓後世知道王朝興亡的真相，即使真相得罪權貴。
   - 李清照主張：歷史不只屬於帝王將相，碑刻、器物、書畫與詞章所留下的生活痕跡，同樣是證明一個時代存在過的鐵證。
3. **顧淵點題**：顧淵在旁靜聽良久，微笑開口：「史書留興亡，金石留痕跡，合之方為完整時代。」
4. **思想融合**：蔡琰與李清照相視而笑，順著此意繼續深入推演，真正由她們兩人共同確立了書院「史籍與金石並重」的新體系。

## 人物與關係重點
- **蔡琰與李清照**：思想上的互相成就，讓兩位女主都獲得成長。
- **顧淵**：作為點撥者而非說教者，真正完成理念融合的仍是兩位才女自己。

## 敘事原則與寫作提醒
- 務必保留核心台詞：「史書留興亡，金石留痕跡，合之方為完整時代。」

## 伏筆與下章銜接
- 雅集之後，書院聲望漸起，眾人迎來一段難得平靜卻充實的書院歲月。
