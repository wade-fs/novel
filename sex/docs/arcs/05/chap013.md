# 第013章｜亂舟奪書

- **所屬篇章**：第二篇《孤舟南渡》（chap009～chap016）
- **時間**：第二年春
- **地點**：瀾江峽口
- **主要人物**：顧淵、蔡琰、周伯
- **關鍵進度**：
  - 重大抉擇：蔡琰在珍本與民間災荒地方簿冊之間，選擇救回地方簿冊。

## 核心劇情
水匪與亂兵攔截船隻，意圖奪取財物與典籍。蔡琰面臨兩難：一批價值連城的珍本與記錄民間災荒、徭役及百姓生活的地方簿冊只能優先保住一部分。她選擇救回地方簿冊。

## 場景節拍
1. **峽口遇襲**：客船行至狹窄江段，水匪與散兵駕快艇圍攏登船劫掠。
2. **倉促應變**：顧淵與周伯利用船艙地形與雜物阻滯敵人、爭取時間，無法硬拚，只能棄物保命。
3. **兩難抉擇**：船尾火起、水勢湍急，兩箱書只能帶走一箱——一邊是世家追捧的珍本孤卷，一邊是記錄民間災荒、徭役與戶口變遷的地方簿冊。
4. **捨珍保民**：蔡琰幾乎沒有猶豫，抓住地方簿冊與《大胤史稿》，眼看部分珍本沉入江水。

## 人物與關係重點
- **蔡琰**：用行動證明她不是藏書癖或貴族才女，而是真正心懷蒼生的史學家。

## 敘事原則與寫作提醒
- 顧淵在此戰中一樣是凡人，只能靠地形、智謀與拚命掩護，不能突然爆發武力。

## 伏筆與下章銜接
- 脫險靠岸後，顧淵對蔡琰放棄珍本的決定感到不解，引發下一章深入的史觀對話。
