# 第023章｜故人遺物

- **所屬篇章**：第三篇《江湖文瀾》（chap017～chap024）
- **時間**：第二年秋
- **地點**：江左外圍臨時落腳處
- **主要人物**：顧淵、蔡琰
- **關鍵進度**：
  - 心理後果：兩人各自承受失敗與失去，沒有迅速和解。

## 核心劇情
蔡琰表面冷靜地處理周伯後事，實際上陷入深切悲痛。她失去了父親，如今又失去陪伴自己多年的周伯。顧淵也因自己的誤判而自責，兩人一度無法互相安慰。他們沒有迅速和解，而是各自承受這次失敗的後果。

## 場景節拍
1. **安葬周伯**：蔡琰親手替周伯整理衣冠、立下簡碑，全程冷靜得近乎克制，沒有崩潰大哭。
2. **沉默的裂痕**：顧淵坦言改道是自己的誤判，願承擔全部責任；蔡琰沒有責怪他，卻也無法說出「沒關係」。
3. **各自承擔**：夜裡兩人同處一院卻相對無言——蔡琰撫著周伯留下的舊包袱，顧淵獨坐廊下反覆復盤自己的傲慢。
4. **殘存危機**：追兵仍在附近搜尋，剩餘書箱無處安放，兩人陷入最孤立無援的低谷。

## 人物與關係重點
- **顧淵與蔡琰**：真實的創傷需要時間消化，不急著用擁抱或台詞強行撫平，這讓兩人的感情更有真實重量。
