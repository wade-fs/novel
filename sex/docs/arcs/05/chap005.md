# 第005章｜白玉書院之火

- **所屬篇章**：第一篇《焚書亂世》（chap001～chap008）
- **時間**：第一年秋
- **地點**：白玉書院、蔡府
- **主要人物**：顧淵、蔡邕、蔡琰、周伯
- **關鍵進度**：
  - 危機爆發：權臣查抄白玉書院與蔡府。
  - 顧淵成長：首次展現失去超凡力量後仍具備的組織與調度能力。

## 核心劇情
權臣派兵查抄白玉書院，蔡府亦遭到牽連。蔡邕拒絕交出史稿原件，命蔡琰與周伯設法搶救典籍。顧淵協助安排人員、路線與物資，首次展現失去超凡力量後仍然具備的組織能力。

## 場景節拍
1. **兵臨書院**：官兵強闖白玉書院，封門搜檢，要求交出私史與禁書。
2. **蔡邕拒交**：蔡邕挺身周旋，拒絕交出《大胤史稿》原件，為眾人爭取撤離時間。
3. **緊急調度**：面對混亂局面，顧淵迅速冷靜下來，協助蔡琰與周伯清點最優先的書箱、分配人手、規劃後門與暗巷撤離路線。
4. **火勢起於夜色**：官兵強行破門，書院與蔡府外圍同時起火，搶救行動刻不容緩。

## 人物與關係重點
- **顧淵**：不再依賴武力或法寶，而是以組織、分工與冷靜決斷成為蔡琰的助力。
- **蔡邕**：以文人風骨直面強權，選擇留下斷後。

## 敘事原則與寫作提醒
- 寫出凡人面對兵災時的真實慌亂與體力極限，顧淵不能像武俠高手一樣打退官兵。

## 伏筆與下章銜接
- 火光沖天，眾人衝入火場搶救核心典籍，蔡邕獨自面對追兵。
