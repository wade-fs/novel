# 第025章｜江左新居

- **所屬篇章**：第四篇《亂世流年》（chap025～chap032）
- **時間**：第二年冬
- **地點**：江左新書院、素琴小築
- **主要人物**：顧淵、蔡琰、薛濤
- **關鍵進度**：
  - 典籍工程第四階段：**重建**展開（重新編目、比對與抄錄散落各地的典籍）。
  - 顧淵成長：投入書院庶務，逐漸習慣凡人日常。

## 核心劇情
在薛濤協助下，眾人於江左逐漸立穩腳跟。蔡琰與顧淵建立新藏書與校勘體系，將散落各地的典籍重新編目、比對與抄錄，開始典籍工程的最後階段「重建」。顧淵負責書院庶務，從安排人員、物資到修繕房舍，逐漸習慣凡人日常。

## 場景節拍
1. **安頓新居**：薛濤為眾人尋得僻靜院落「素琴小築」與鄰近舊書院，避開世家耳目。
2. **重建體系**：蔡琰制定嚴謹的校勘、抄錄與分架規矩，將先前分散各地的書卷陸續對帳、彙整。
3. **凡俗庶務**：顧淵主動扛起修繕屋瓦、採買紙墨、調度抄書匠人與管帳等瑣事，雙手沾滿木屑與墨漬。
4. **裂痕緩釋**：在日復一日的共同勞作中，兩人因周伯之死產生的沉重沉默開始慢慢化開。

## 人物與關係重點
- **顧淵**：不再把凡人生活當成「過渡與忍耐」，開始認真對待眼前的每一件小事。

## 敘事原則與寫作提醒
- 寫出書院從荒廢到重現書香的具體過程，呈現典籍保存的長期耕耘。
