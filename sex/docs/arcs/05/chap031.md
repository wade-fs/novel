# 第031章｜詞心相印

- **所屬篇章**：第四篇《亂世流年》（chap025～chap032）
- **時間**：第四年早春
- **地點**：江左金石齋／春雨花亭
- **主要人物**：顧淵、李清照
- **關鍵進度**：
  - 情感與雙修：顧淵與李清照在思想相知與自主選擇下建立親密關係。
  - **萬界樓本源修復**：**+30**（本卷累計：**55**）——恢復部分內部資料整理與記憶索引。

## 核心劇情
顧淵與李清照在金石拓本整理、詞作唱和及文化保存理念上持續交流。李清照對顧淵的情感並非單純依附，而是來自思想上的相知與對彼此才華的欣賞。兩人經過充分了解與自主選擇，建立親密關係。

## 場景節拍
1. **春雨校拓**：春雨微寒，兩人在齋中完成一部重要金石目錄的最後校勘，並即興填詞唱和。
2. **思想相知**：李清照坦率直言，她一生最怕遇到只把女子當附庸或玩物的人，而在顧淵眼中，她看見的是平等的欣賞與真正的傾聽。
3. **詞心相印**：燈火搖曳、墨香未散，兩人在完全平等與自願的前提下相擁相許，風雅含蓄而真摯。
4. **本源再復**：萬界樓本源獲得精純陰陽共鳴反哺（+30，本卷累計 55），部分內部資料整理與記憶索引功能悄然恢復。

## 人物與關係重點
- **李清照**：第二核心女主的情感里程碑，展現她率真、獨立、敢愛敢表達的江南才女氣度。

## 敘事原則與寫作提醒
- 區隔於薛濤的溫潤人情，李清照的情感戲應突出「才華共鳴、詞心相印與平等知己」的韻味。
