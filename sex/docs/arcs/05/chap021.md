# 第021章｜恐懼之人

- **所屬篇章**：第三篇《江湖文瀾》（chap017～chap024）
- **時間**：第二年秋初
- **地點**：江左外圍官驛、密道渡口
- **主要人物**：顧淵、蔡琰、周伯、護書官吏
- **關鍵進度**：
  - 判斷成本伏筆引爆：顧淵因過度依賴心念感知而做出致命誤判。

## 核心劇情
為轉移一批重要典籍，眾人必須依靠一名護書官吏提供路線與接應。顧淵感受到官吏強烈的恐懼，誤以為他畏懼權臣、不敢真正合作，因此臨時改變運輸路線。實際上，官吏恐懼的是家人遭到挾持，他不敢說出真相，是因為對方已經控制了他的妻兒。

## 場景節拍
1. **接應部署**：一批重要典籍準備分批轉移，負責開具路引與安排水陸接應的是一名地方護書官吏。
2. **察覺恐懼**：會面時，顧淵透過心念共鳴感受到官吏內心極度恐懼且言行閃爍，卻不知道恐懼的真正原因。
3. **致命誤判**：顧淵憑經驗推斷官吏畏懼權臣清算、可能臨陣退縮或出賣，遂決定不按原定路線走，臨時改道偏僻水路。
4. **隱蔽的真相**：官吏欲言又止——實則權臣耳目早已挾持其妻兒，故意逼他引誘眾人走偏僻備選路線（或正因顧淵改道而撞入早已佈下的埋伏網）。

## 人物與關係重點
- **顧淵**：本卷最關鍵的性格與能力教訓——「心念共鳴只提供觀察線索，不提供答案」。

## 敘事原則與寫作提醒
- 顧淵的推論在當時看來必須合情合理，不能寫成降智；正因為合情合理卻仍錯了，才顯得「判斷成本」真實殘酷。

## 伏筆與下章銜接
- 夜色深沉，改道後的書車與船隊緩緩駛入無人的蘆葦渡口，殺機四伏。
