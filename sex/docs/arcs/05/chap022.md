# 第022章｜不可挽回

- **所屬篇章**：第三篇《江湖文瀾》（chap017～chap024）
- **時間**：第二年秋
- **地點**：江左外圍蘆葦渡口
- **主要人物**：顧淵、蔡琰、周伯
- **關鍵進度**：
  - 重大犧牲：周伯為保護蔡琰與剩餘書箱而犧牲。
  - 典籍損失：一批典籍被焚毀。
  - 顧淵成長：深刻體會凡人判斷錯誤的不可逆代價。

## 核心劇情
改道後的運輸隊遭到伏擊，一批典籍被焚毀。周伯為保護蔡琰與剩餘書箱而犧牲。顧淵第一次深刻體會到，感知到情緒不代表理解一個人；凡人的判斷錯誤可能造成不可逆的死亡，沒有法寶可以挽回。

## 場景節拍
1. **蘆葦伏擊**：改道後的運輸隊落入權臣暗探伏擊，火矢與刀兵驟至。
2. **火焚典籍**：混戰中數車書箱起火，眾人無力全部救出，只能在濃煙中死守核心箱籠。
3. **周伯犧牲**：為掩護蔡琰與剩餘書箱撤離，年邁的周伯以血肉之軀擋住追兵，重傷力竭而亡。
4. **真相大白與無力感**：事後眾人得知護書官吏妻兒被挾持的真相。顧淵看著周伯逐漸冰冷的遺體，第一次徹底明白：在這個沒有法寶與丹藥的世界，一個誤判就是永遠無法挽回的生命。

## 人物與關係重點
- **周伯**：忠厚一生的老僕，其犧牲絕不可工具化，將持續影響後續第四篇的「周伯遺物」場景。
- **顧淵**：徹底戒除對心念共鳴的傲慢與僥倖心理。

## 敘事原則與寫作提醒
- 寫出凡人面對死亡的真實無力感，不要讓顧淵在最後關頭開掛反殺。

## 伏筆與下章銜接
- 逃離伏擊點後，蔡琰與顧淵面對周伯後事與彼此之間沉重的沉默。
