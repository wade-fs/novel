# 第004章｜史稿留白

- **所屬篇章**：第一篇《焚書亂世》（chap001～chap008）
- **時間**：第一年秋
- **地點**：蔡府書房
- **主要人物**：蔡邕、蔡琰、顧淵
- **關鍵進度**：
  - 核心物件：《大胤史稿》、焦尾琴正式交託。
  - 主線動機確立：蔡琰的史學志業與自主人生觀。

## 核心劇情
蔡邕將未完成的《大胤史稿》與焦尾琴交給蔡琰。史稿中有數處刻意留白，涉及大胤王朝建立、權臣崛起及邊境軍政等重大事件。蔡邕告訴女兒，史書不應只記載勝利者願意留下的內容，並叮囑她：「史脈不可絕，然人生終究當由己定奪。」

## 場景節拍
1. **書房夜談**：風雨欲來之夜，蔡邕將蔡琰喚入書房，取出《大胤史稿》與焦尾琴。
2. **史稿留白**：蔡琰翻閱史稿，發現數處關鍵章節刻意留白；蔡邕解釋，有些真相他來不及寫完，也不能只讓勝利者書寫。
3. **父女託付**：蔡邕叮囑「史脈不可絕，然人生終究當由己定奪」，既傳承史家風骨，也不願將女兒綁死在家族責任裡。
4. **顧淵旁觀**：顧淵在廊外或書房一角協助整理書箱，隱約感受到蔡邕平靜之下的決絕與不捨。

## 人物與關係重點
- **蔡邕與蔡琰**：父女情深與精神傳承，讓後續蔡邕之死具有真實的情感衝擊力，而非工具化。
- **蔡琰**：確立「決定哪些歷史該被留下」的史學家自覺。

## 敘事原則與寫作提醒
- 務必保留核心台詞：「史脈不可絕，然人生終究當由己定奪。」
- 焦尾琴在此章作為文化與情感信物登場，為後續十二律呂時間錨與夜雨撫琴埋線。
