# 第019章｜三方清議

- **所屬篇章**：第三篇《江湖文瀾》（chap017～chap024）
- **時間**：第二年夏
- **地點**：江左文社清議堂
- **主要人物**：顧淵、蔡琰、謝清之、上官婉兒
- **關鍵進度**：
  - 心念共鳴：第三階「心念感知」前兆（察覺上官婉兒言行與內心存在複雜落差）。

## 核心劇情
上官婉兒、謝清之與蔡琰圍繞史稿真實性、政治後果及典籍保存方式展開激烈辯論。上官婉兒認為，史料若不考慮權力結構，便可能害死更多人；蔡琰則認為，不能因為真相危險就任意刪改。顧淵在旁觀察，逐漸察覺上官婉兒的言行與內心存在複雜落差。

## 場景節拍
1. **清議交鋒**：三方在文社閉門清議，焦點直指《大胤史稿》與宮廷秘檔的去留與公開尺度。
2. **三種立場**：
   - 謝清之：保全士族與文社根基，主張暫時刪節敏感記載。
   - 上官婉兒：從權力結構出發，警告貿然公開真相只會引來血腥報復，害死無辜者。
   - 蔡琰：堅持史家底線，若連記錄真相的勇氣都放棄，保存下來的只是勝利者的粉飾。
3. **顧淵旁觀**：顧淵不急於站隊，而是仔細觀察三人神態與語氣，察覺上官婉兒口氣冷硬，內心卻藏著沉重的疲憊與矛盾。
4. **不歡而散中的轉機**：三方雖未達成共識，但都意識到彼此手中握有對方無法忽視的籌碼。

## 人物與關係重點
- **蔡琰 vs. 上官婉兒**：兩位女性的價值觀碰撞，展現「史學真實」與「政治代價」的深刻矛盾。

## 敘事原則與寫作提醒
- 辯論要有真實的邏輯與歷史厚重感，三方皆言之成理，不貶低任何一方。

## 伏筆與下章銜接
- 清議散後，顧淵與上官婉兒私下交談，心念共鳴正式邁入第三階。
