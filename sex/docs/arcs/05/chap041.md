# 第041章｜戰後清寧

- **所屬篇章**：第六篇《素琴歸途》（chap041～chap048）
- **時間**：第四年冬初
- **地點**：江左素琴小築
- **主要人物**：顧淵、蔡琰
- **關鍵進度**：
  - 情感收束起點：劫後重歸平靜，兩人回顧四載春秋，確認彼此在生命中的份量。

## 核心劇情
戰火暫歇，江左逐漸恢復秩序。顧淵與蔡琰回顧四載相處，從雲京火場、孤舟南渡、周伯犧牲到江左重建，彼此已經成為生命中無法取代的存在。兩人不急於告別，而是重新確認彼此真正想要的未來。

## 場景節拍
1. **冬日重整**：戰事暫緩，江左書院陸續迎回分散各處的書箱，素琴小築重歸清寧。
2. **四載回望**：兩人圍爐煮茶，細數從雲京火光、陳留關卡、瀾江夜雨到周伯犧牲的點點滴滴。
3. **坦誠相待**：顧淵沒有迴避自己終有一天會找回歸途的事實，蔡琰也沒有迴避自己對江左書院與《大胤史稿》的責任。
4. **珍惜當下**：兩人都不急於用離別提前定義此刻，只願在歷經生死之後，真正誠實地面對彼此的心意。

## 人物與關係重點
- **顧淵與蔡琰**：四載歲月沉澱出的深情，克制、真誠、無可取代。

## 敘事原則與寫作提醒
- 節奏放緩，營造大戰之後的靜謐與溫潤餘韻，為下一章的正式定情鋪墊。

## 伏筆與下章銜接
- 冬夜月明，焦尾琴聲再起，兩人迎來四載相知後最自然的定情之夜。
