# 第035章｜危機感知

- **所屬篇章**：第五篇《朔漠風雲》（chap033～chap040）
- **時間**：第四年夏末
- **地點**：江左城防外圍、文社暗巷
- **主要人物**：顧淵、上官婉兒
- **關鍵進度**：
  - 心念共鳴：進入第四階「危機感知」（能察覺異常情緒、殺意與危險變化，但不知道敵人位置、武器、行動時機與完整計畫）。

## 核心劇情
顧淵的心念共鳴進入第四階「危機感知」。他能察覺異常情緒、殺意與危險變化，卻不知道敵人位置、武器、行動時機與完整計畫。顧淵與上官婉兒合作，將感知結果與情報、地形及政治利益交叉比對。

## 場景節拍
1. **第四階覺醒**：在一次與士族代表周旋的場合，顧淵敏銳察覺到幾名隨從與門客身上散發出異常的緊張與隱蔽殺意，心念共鳴正式邁入第四階「危機感知」。
2. **記取教訓**：吸取第三篇周伯犧牲的慘痛教訓，顧淵絕不再憑單一感知妄下結論。
3. **交叉比對**：顧淵將自己察覺的異常人物名單交給上官婉兒，兩人徹夜比對江左士族聯姻譜系、北岸私商帳目與城防換崗規律。
4. **鎖定異動**：結合感知線索與情報推理，兩人逐步拼湊出妥協派準備私下劫人獻城（或強奪史稿）的輪廓。

## 人物與關係重點
- **顧淵**：真正實踐「心念共鳴只提供觀察線索，不提供答案」，展現成熟的判斷力。

## 敘事原則與寫作提醒
- 嚴格遵守第四階限制：顧淵不知道敵人具體藏在哪、何時動手，必須靠上官婉兒的政治分析與實地查證補足。

## 伏筆與下章銜接
- 徹夜合作識破妥協派盤算的過程中，上官婉兒長年緊繃的心防也終於在顧淵面前卸下。
