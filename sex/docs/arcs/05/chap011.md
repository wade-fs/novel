# 第011章｜四千卷目錄

- **所屬篇章**：第二篇《孤舟南渡》（chap009～chap016）
- **時間**：第一年冬末
- **地點**：瀾江舟中
- **主要人物**：顧淵、蔡琰、周伯
- **關鍵進度**：
  - 典籍工程第二階段：**整理**展開（建立四千卷典籍分類目錄）。
  - 空間錨：開始蒐集九州輿圖、地理志與沿途實地考察。

## 核心劇情
瀾江舟中，蔡琰重新建立四千卷典籍目錄。她將典籍分成孤本、抄本、可重得之書、地方史料及待考資料，為未來的整理與重建奠定基礎。顧淵則根據九州輿圖、地理志與沿途實地考察，建立文瀾界的空間參照。

## 場景節拍
1. **舟中開箱**：江面平穩，蔡琰展開殘卷與紙墨，憑記憶與現存書箱重編四千卷總目。
2. **五類分級**：將典籍明確分為「孤本、抄本、可重得之書、地方史料、待考資料」，展現嚴謹的史學家與文獻學家思維。
3. **輿圖對照**：顧淵在一旁翻閱殘存的九州輿圖與地方地理志，對照沿途所見江道、山勢與城鎮。
4. **各自專注的靜謐**：船艙燈火下，一人編目、一人繪圖，亂世中難得浮現片刻安寧。

## 人物與關係重點
- **蔡琰**：四千卷不只是數字，而是她用專業與記憶重新架起的文化骨架。
- **顧淵**：在協助整理典籍的同時，默默為日後重返萬界樓建立空間參照。

## 敘事原則與寫作提醒
- 典籍保存是長期工程，此章要寫出具體的分類標準與操作細節。
