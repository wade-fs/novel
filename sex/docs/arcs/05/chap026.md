# 第026章｜周伯遺物

- **所屬篇章**：第四篇《亂世流年》（chap025～chap032）
- **時間**：第二年冬末
- **地點**：素琴小築
- **主要人物**：蔡琰、李清照、顧淵
- **關鍵進度**：
  - 人物登場：第二核心女主**李清照（字易安）**初入核心生活圈。
  - 情感與主題深化：周伯的離去轉化為記憶與友誼的起點，蔡琰與李清照建立深厚友誼。

## 核心劇情
蔡琰整理周伯遺物，發現他多年來默默保存著她兒時的字帖、病中藥方與隨手寫下的小詩。這些東西沒有什麼史料價值，卻保存著她不曾留意的生活痕跡。李清照參與整理，從器物與記憶的角度陪伴蔡琰面對失去，兩人由此建立深厚友誼。

## 場景節拍
1. **打開舊包袱**：冬日午後，蔡琰終於打開周伯的遺物箱，裡面沒有金銀，只有用油紙仔細包好的瑣碎舊物。
2. **無用卻珍貴的痕跡**：兒時歪斜的習字帖、幼年發熱時的藥方、隨手丟棄的小詩草稿——周伯替她記住了連她自己都忘了的歲月。
3. **李清照陪伴**：受薛濤引薦前來交流金石與舊籍的李清照恰逢此事，她沒有泛泛安慰，而是細心幫蔡琰將這些紙片逐一裱糊、歸檔，輕聲道：「史書不記這些，但一個人活過的證明，往往就在這些舊物裡。」
4. **淚落與釋懷**：蔡琰終於卸下多月來的強撐，安靜落淚；兩位才女由此結下超越尋常文人客套的深厚友誼。

## 人物與關係重點
- **蔡琰與李清照**：不是爭風吃醋的後宮關係，而是彼此照亮、互相成全的知己。
- **周伯**：即便已逝，仍透過遺物深刻影響著蔡琰與全卷「記憶與痕跡」的核心主題。

## 敘事原則與寫作提醒
- 本章是全卷極具情感重量的名場面，筆調須溫柔、克制、細膩。

## 伏筆與下章銜接
