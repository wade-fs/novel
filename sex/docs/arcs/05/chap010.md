# 第010章｜相互依靠

- **所屬篇章**：第二篇《孤舟南渡》（chap009～chap016）
- **時間**：第一年冬
- **地點**：陳留道小鎮、渡口前站
- **主要人物**：顧淵、蔡琰、周伯
- **關鍵進度**：
  - 關係推進：兩人形成「整合方案＋辨識人情」的互補合作模式。

## 核心劇情
一次糧食與通行憑證危機中，蔡琰利用典籍知識與地方關係化解困境。顧淵負責整合線索、制定行動方案，蔡琰負責辨識人情與實際風險。兩人逐漸形成互補，而非單方面保護與被保護的關係。

## 場景節拍
1. **憑證與斷糧危機**：行至渡口前站，舊路引失效、米價飛漲，又逢地方豪強封鎖碼頭。
2. **分工破局**：蔡琰憑藉對當地士族譜系與典籍淵源的了解，找到可通融的舊識或書院門生；顧淵則整合船期、路線與盤查規律，擬定低風險的登船方案。
3. **周伯配合**：周伯老練地打點船家與行李掩護，將書箱偽裝成普通貨擔。
4. **登舟入江**：三人順利登上南下客船，駛入煙波浩渺的瀾江。

## 人物與關係重點
- **顧淵與蔡琰**：默契成形，雙方都看見彼此不可替代的長處。

## 敘事原則與寫作提醒
- 危機解決必須完全靠人情、知識與謀劃，絕不開金手指。

## 伏筆與下章銜接
- 舟行瀾江，暫得喘息，蔡琰開始在舟中系統整理四千卷典籍目錄。
