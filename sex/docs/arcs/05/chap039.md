# 第039章｜五才女之局

- **所屬篇章**：第五篇《朔漠風雲》（chap033～chap040）
- **時間**：第四年秋
- **地點**：江左城內、瀾江防線與秘密渡口
- **主要人物**：顧淵、蔡琰、李清照、薛濤、上官婉兒、魚玄機、謝清之
- **關鍵進度**：
  - 群像高潮：五位才女與顧淵務實分工，共同完成典籍轉移與反制妥協派。

## 核心劇情
五位才女與顧淵各自發揮所長，分別解決不同層次的問題：薛濤管人脈與安置、李清照管文化資產轉移、上官婉兒管政治清議與揭露妥協派、魚玄機管水路突破與密信傳遞、蔡琰做核心決策、顧淵整合全局。這不是一支軍隊，而是一群各有專長的人共同完成一項不可能的任務。

## 場景節拍
1. **各司其職**：
   - **薛濤**：動用詩社與女商網絡，暗中籌措物資、安排藏身處與分批轉移人員。
   - **李清照**：冷靜甄別哪些金石拓本、器物與記錄必須優先轉移，並留下可供後世辨識的編目。
   - **上官婉兒**：公開部分宮廷秘檔與妥協派私通證據，穩住江左清議，迫使謝清之與主和派無法暗箱操作。
   - **魚玄機**：利用江湖水路突破封鎖，將關鍵密信與書箱分批送出險境。
   - **蔡琰**：決定《大胤史稿》真本與副本的去留與公開原則，並決定親自赴約直面呼延烈。
   - **顧淵**：整合各方情報、地形、時間節點與退路方案，確保每個環節緊密咬合。
2. **步步推進**：妥協派的陰謀在輿論與事實面前瓦解，核心典籍與《大胤史稿》順利完成安全轉移。

## 人物與關係重點
- **群像合作**：每位女性都在自己最真實的專業領域發光，絕不變成輪流放招的戰鬥小隊。

## 敘事原則與寫作提醒
- 節奏緊湊、調度清晰，寫出凡人以智慧、勇氣與協作對抗強權的震撼感。

## 伏筆與下章銜接
- 典籍既已脫險，蔡琰懷抱焦尾琴，在顧淵陪同下登上瀾江北岸談判之所，正面迎見呼延烈。
