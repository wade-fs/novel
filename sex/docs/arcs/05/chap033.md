# 第033章｜朔漠鐵騎

- **所屬篇章**：第五篇《朔漠風雲》（chap033～chap040）
- **時間**：第四年夏
- **地點**：江左北岸、瀾江防線
- **主要人物**：呼延烈、顧淵、蔡琰、上官婉兒、謝清之
- **關鍵進度**：
  - 重大危機：朔漠左賢部統領**呼延烈**率軍南侵，點名索要《大胤史稿》與蔡琰。

## 核心劇情
朔漠左賢部統領呼延烈率軍南侵。他並非單純為了掠奪財物，而是有三個明確政治目的：取得《大胤史稿》掌握舊臣士族與軍政部署、以蔡琰作為文化控制的象徵、利用蔡琰的名望迫使江左士族在政治談判中讓步。

## 場景節拍
1. **北岸告急**：瀾江北岸烽火連天，朔漠左賢部大軍壓境，渡江威脅直逼江左。
2. **呼延烈遣使**：朔漠使者渡江遞交條件——若江左交出《大胤史稿》與大儒之女蔡琰，可議停戰之約。
3. **三大政治目的**：上官婉兒與顧淵冷靜剖析呼延烈的真正盤算：
   - 取得《大胤史稿》，掌握大胤舊臣、士族及軍政部署。
   - 以蔡琰作為文化控制的象徵，宣示朔漠對大胤文化傳承的掌控。
   - 利用蔡琰的名望，迫使江左士族在政治談判中讓步。
4. **風暴將至**：蔡琰的處境不再只是個人安危，而是整個江左文化尊嚴與政治博弈的焦點。

## 人物與關係重點
- **呼延烈**：有頭腦、懂政治的強敵，不是只會搶女人的粗莽蠻將。

## 敘事原則與寫作提醒
- 強化政治與文化博弈的真實感，讓危機建立在利益與權力結構之上。
