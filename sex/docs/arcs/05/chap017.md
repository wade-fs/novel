# 第017章｜江左文社

- **所屬篇章**：第三篇《江湖文瀾》（chap017～chap024）
- **時間**：第二年夏
- **地點**：江左外圍渡口城鎮、江左文社別院
- **主要人物**：顧淵、蔡琰、謝清之、周伯
- **關鍵進度**：
  - 典籍工程第三階段：**分散**展開（分批交由可信書院、士族與商旅轉移保存）。
  - 人物登場：江左文社領袖謝清之登場。

## 核心劇情
顧淵一行抵達江左外圍，開始將典籍分批交由可信書院、士族與商旅轉移保存。他們遇見江左文社領袖謝清之。謝清之主張先保存士族與文化火種，再考慮完整記錄大胤滅亡的真相。蔡琰對其有所保留，雙方在史料取捨上產生分歧。

## 場景節拍
1. **抵達江左**：一行人進駐江左外圍城鎮，展開典籍分散計畫，避免所有書卷集中於一處再遭焚毀。
2. **會見謝清之**：江左文社領袖謝清之慕名來訪，氣度儒雅、深諳士族政治，願提供庇護與藏書之所。
3. **理念初歧**：謝清之委婉建議先隱去《大胤史稿》中觸怒權貴與江左世家的章節，以「保全文化火種」為先。
4. **蔡琰有所保留**：蔡琰禮貌應對卻不肯交出原稿，意識到江左文社既是助力，也是另一場政治博弈的起點。

## 人物與關係重點
- **謝清之**：並非臉譜化反派，而是典型的士族現實主義者，與蔡琰形成理念張力。

## 敘事原則與寫作提醒
- 寫出江左文壇的雅致與暗藏的門閥利益，讓政治衝突自然浮現。
