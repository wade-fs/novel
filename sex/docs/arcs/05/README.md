# 《萬界風月樓》第五卷方向｜《諸女相逢・萬界情緣》（方向草案）

> **卷定位**：**「既有女主的關係深化與跨世界互動卷」**  
> **世界範圍**：青玄界（01）、滄瀾界（02）、九曜神域（05）與萬界樓中樞（**暫不指定新世界**，亦不強制開啟新世界主線）  
> **設計階段**：方向定調草案（不安排具體事件、不限定誰與誰必須互動、不展開逐章細綱）

---

## 一、核心方向（六大支柱）

1. **延續原世界生活**：延續前四卷女主各自在原世界（青玄界、滄瀾界、九曜神域）的生活、事業與發展。
2. **顧淵跨界串聯**：以顧淵跨世界往返作為主要敘事串聯方式，連結各個持續演化的世界。
3. **萬界樓自然聚首**：適時安排女主回到萬界樓，形成不同女主之間的相遇與互動，讓萬界樓成為真正的共同生活空間。
4. **建立獨立關係網**：讓女主之間逐步建立自己的關係（欣賞、切磋、商政合作、思想交流、日常相處），不限於顧淵這個共同連結。
5. **持續解決世界難題**：顧淵協助女主處理各自世界的困難，延續各世界的劇情生命力。
6. **深耕既有情感**：不以增加新女主為主要目標，重點放在前四卷既有女主的關係深化與群像默契成形。

---

## 二、四大敘事原則

> [!IMPORTANT]
> 本卷必須嚴格遵守以下四條敘事紅線：
> - **不強迫聚集**：不為了製造「全員同堂」而把所有人硬拉回萬界樓。
> - **不強迫跨界**：每位女主的跨界行動都必須有自身合理的動機與條件。
> - **不凍結原世界**：遵循 R24 原則，各世界在顧淵離開期間依然自主演化。
> - **不犧牲人物自主性**：不為了互動而讓角色降智或變成低層次爭寵工具。

---

## 三、兩種核心互動模式

第五卷的群像互動分為兩個層次並行推進：

### 1. 第一種：女主與女主的直接互動
- 兩位或多位女主因各自事務、修煉需求或顧淵的安排，同時來到萬界樓。
- 互動內容包含：談論彼此的世界、修煉體系（修仙／高武／神道）交流、商業與情報合作、實力切磋、彼此欣賞、競爭與調侃。
- 允許存在性格碰撞與不認同，不必強行寫成「所有人很快變成好姐妹」。

### 2. 第二種：透過顧淵產生的間接互動
- 不需要所有女主同場，也能讓整部小說產生強烈的跨世界連續感。
- 例如：顧淵剛從某個世界回來，另一位女主詢問那個世界的情況；或顧淵帶回某件異界物品、某個消息，引發其他女主對另一個世界的興趣或思考。

---

## 四、與第四卷的銜接備註

- 第四卷《九曜神域・神座之爭》卷末**不必前往新世界**，收束重心放在九曜神域新秩序建立、修復度突破 `500/10000` 與「諸天神藏殿」顯現，自然過渡至第五卷的跨界回訪與群像深化。
