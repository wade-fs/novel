# 第045章｜清照金石

- **所屬篇章**：第六篇《素琴歸途》（chap041～chap048）
- **時間**：第四年冬
- **地點**：江左金石齋、書院
- **主要人物**：顧淵、李清照、蔡琰
- **關鍵進度**：
  - 群像收束（李清照線）：李清照確立長期金石與詞學傳承志業，與顧淵真誠道別，與蔡琰約定共同整理史稿與文化遺存。

## 核心劇情
李清照決定繼續整理金石拓本與詞作，建立更完整的收藏、校勘與傳承體系。她與顧淵真誠道別，兩人不否定彼此的情感，也不以離別否定曾經的選擇。她與蔡琰約定共同整理史稿與文化遺存。

## 場景節拍
1. **金石新卷**：李清照將最新編成的金石拓本總目與一卷新詞贈予顧淵留念。
2. **真誠道別**：兩人沒有怨懟或悲戚，李清照灑脫而深情地表示，相知一場已是難得，離別不會抹去曾經的詞心相印。
3. **雙姝之約**：李清照與蔡琰立約，今後一主史稿、一主金石，共同守護大胤留下的時代記憶。
4. **各自前行**：顧淵目送李清照回到案前繼續拓碑校詞，深知她的光芒從不因任何人離去而減弱。

## 人物與關係重點
- **李清照**：獨立大氣、有始有終的第二核心女主，留下未來重返文瀾界時繼續延伸的伏筆。

## 敘事原則與寫作提醒
- 寫出「不以離別否定曾經的選擇」的成熟情感觀。

## 伏筆與下章銜接
- 告別李清照後，顧淵再訪薛濤、上官婉兒與魚玄機，見證她們各自的人生去向。
