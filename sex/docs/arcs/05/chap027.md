# 第027章｜金石之交

- **所屬篇章**：第四篇《亂世流年》（chap025～chap032）
- **時間**：第三年春
- **地點**：江左新書院、金石齋
- **主要人物**：顧淵、蔡琰、李清照
- **關鍵進度**：
  - 群像成形：李清照正式進入核心群像，展開金石拓本與典籍的互證整理。

## 核心劇情
攜帶金石拓本的江南才女李清照正式進入核心群像。她對古器、碑刻、拓本與詞作有獨到見解，認為文化不只存在於史書，也存在於器物的使用痕跡與人的生活記憶。蔡琰與她開始共同整理不同類型的文化資料。

## 場景節拍
1. **金石拓本入書院**：李清照帶來大批戰火前搶拓的碑刻、鐘鼎銘文與書畫拓本，向眾人展示如何從器物銘文考證年代與風俗。
2. **雙姝合作**：蔡琰擅長經史文獻，李清照精於金石考據與詞學，兩人以碑銘補正史稿缺漏，以史稿印證器物來歷。
3. **顧淵參與**：顧淵協助製作拓印工具、整理索引目錄，並與李清照在詞句與古物見解上自然交流，彼此留下深刻印象。
4. **江南文壇回響**：書院的整理工作漸成氣候，江左文社決定舉辦一場藏書雅集。

## 人物與關係重點
- **李清照**：獨立、敏銳、才氣縱橫，兼具江南士女的雅致與亂世中搶救文化記憶的執著。

## 敘事原則與寫作提醒
- 李清照是第二核心女主，從本章起必須有持續發展的文化線與情感線。

## 伏筆與下章銜接
- 藏書雅集在即，蔡琰與李清照雖為摯友，卻在「史書」與「金石」的保存優先次序上迎來正面思想交鋒。
