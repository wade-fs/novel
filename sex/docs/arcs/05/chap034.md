# 第034章｜江左兩難

- **所屬篇章**：第五篇《朔漠風雲》（chap033～chap040）
- **時間**：第四年夏
- **地點**：江左文社議事廳
- **主要人物**：謝清之、蔡琰、顧淵、上官婉兒
- **關鍵進度**：
  - 政治施壓：江左士族內部分裂，蔡琰直面自己可能成為政治籌碼的現實。

## 核心劇情
謝清之面臨是否妥協的困境。部分士族認為，只要交出史稿與蔡琰，就能換取江左暫時和平；另一部分人則認為這會讓大胤最後的文化尊嚴徹底淪為政治籌碼。蔡琰第一次直接面對自己可能成為政治工具的事實。

## 場景節拍
1. **士族分裂**：江左議事廳內爭吵激烈，妥協派以「保全江南生靈與百年世家」為名，暗中施壓要求交出史稿與蔡琰。
2. **謝清之的兩難**：謝清之夾在家族存亡與文人風骨之間，態度動搖，試圖勸說蔡琰「以大局為重」。
3. **直面工具化**：蔡琰第一次切身感受到，在權力談判桌上，連自己的學識、名望與人生都可能被他人輕易標價。
4. **拒絕妥協**：蔡琰冷靜表態，史稿與自己的人生都不容任何士族替她簽字畫押。

## 人物與關係重點
- **蔡琰**：面對的不只是外部強敵呼延烈，還有內部看似儒雅實則自私的士族妥協派。

## 敘事原則與寫作提醒
