# 第032章｜酒肆驚鴻

- **所屬篇章**：第四篇《亂世流年》（chap025～chap032）
- **時間**：第四年春末
- **地點**：江左酒肆、素琴小築
- **主要人物**：顧淵、魚玄機、蔡琰、李清照、薛濤
- **關鍵進度**：
  - 人物初現：核心才女之一、不羈女冠**魚玄機**初現身影（先埋伏筆，第五篇正式入局）。
  - 三錨點：**時間錨完成**（結合焦尾琴十二律呂、節氣、曆法、史料與四載生活紀錄）。
  - 第四篇收束：顧淵深深留戀凡人生活，五位才女群像輪廓成形。

## 核心劇情
不羈女冠魚玄機在江左酒肆初現身影，以一首反禮教詩作引起文社爭論。她不願受士族禮法束縛，也不認為女性必須為家族、王朝或文化傳承犧牲自己的人生。顧淵對她的率性與鋒芒留下深刻印象。同時，顧淵發現自己已經深深留戀這段凡人生活，並正式完成「時間錨」。

## 場景節拍
1. **酒肆題詩**：江左臨河酒肆中，一身道裝卻眉目張揚的女冠魚玄機微醺提筆，寫下一首直斥士族禮教虛偽的詩作，滿座文人嘩然。
2. **鋒芒初露**：面對老儒責難，魚玄機笑語犀利、拂袖而去，只與旁觀的顧淵短暫交鋒數語，留下深刻印象。
3. **時間錨完成**：回到素琴小築，顧淵將焦尾琴十二律呂、四季節氣、大胤曆法、史料紀年與自己四載生活日誌互證，文瀾界的「時間錨」終於穩固成形。
4. **留戀凡塵**：望著院中燈火與正在校書的蔡琰，顧淵清楚意識到——自己已經深深留戀這段沒有超凡力量的凡人歲月。

## 人物與關係重點
- **魚玄機**：以「個人自由意志」挑戰整個江左文壇的禮教與責任觀，避免第五篇空降。
- **顧淵**：內心開始出現「歸途」與「留戀」的真實掙扎。
