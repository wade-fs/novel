# 第七卷 ch006（全書 ch213）｜冰霜魔導的名字

> 所屬：第一篇｜魔法異界・初入艾瑟蘭（卷內 ch001–006｜全書 ch208–213）

- **出場人物**：顧淵、塞拉菲娜（遠景或短暫出場）、學院教授、學生。
- **場景**：奧術學院公開講堂、符文實驗區。
- **核心情節**：
   1. 顧淵旁聽一場符文理論公開課。
   2. 塞拉菲娜在課堂上提出一套與主流理論不同的符文解讀，引起教授爭論。
   3. 顧淵從符文排列中發現其與自身理解的天地運行規律有相通之處。
   4. 他提出一個不同於魔法師思路的問題，令塞拉菲娜注意到這名陌生旁聽者。
   5. 兩人尚未真正建立關係，只留下下一次交流的契機。
- **爽點與情感落點**：知識交鋒的初步火花，不急著製造愛情。
- **伏筆**：塞拉菲娜研究的符文中，出現與遠古封印有關的異常結構。
- **萬界樓回饋**：收錄第一批奧術符文資料；修復度仍以實際本源成果為準。

---

**第一篇收束**： 顧淵已進入艾瑟蘭的魔法文明，讀者認識了魔法日常、冒險者、公會與浮空學院。第二篇正式進入塞拉菲娜的故事。
