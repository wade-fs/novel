# 第七卷 ch016（全書 ch223）｜森林的分歧

> 所屬：第三篇｜精靈月曜・生命之樹（卷內 ch013–018｜全書 ch220–225）

- **出場人物**：顧淵、艾琳諾、精靈長老、自然派與守序派代表。
- **場景**：精靈議事庭、受污染森林。
- **核心情節**：
   1. 精靈族召開議事會，討論是否切斷部分森林與世界樹的連結。
   2. 一派主張犧牲受污染區域，保護世界樹核心；另一派認為這會破壞精靈祖先留下的生命循環。
   3. 艾琳諾反對在證據不足時作出不可逆決定。
   4. 顧淵提出先調查污染源，而不是立即犧牲森林。
   5. 議事會同意給予有限調查時間。
- **情感落點**：艾琳諾展現自己的判斷力，不是只會溫柔順從的祭司。
- **伏筆**：受污染區域的地下根系有人工刻痕，似乎曾被人為改造。
- **萬界樓**：記錄精靈族內部政治與生命循環分歧。
