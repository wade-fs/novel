# 第七卷 ch002（全書 ch209）｜以太與真元

> 所屬：第一篇｜魔法異界・初入艾瑟蘭（卷內 ch001–006｜全書 ch208–213）

- **出場人物**：顧淵、邊境村民、低階魔法師。
- **場景**：邊境村鎮、冒險者公會附近。
- **核心情節**：
   1. 顧淵進入村鎮，觀察魔法如何融入日常生活。
   2. 看見魔法燈、儲水符文、簡易治療術與魔法交通工具。
   3. 一名低階法師施法失敗，顧淵從旁觀察其魔力流動。
   4. 他嘗試以神識感知以太，發現以太並非單純的天地靈氣。
   5. 透過交談得知，魔法師通常需要精神引導、符文或媒介才能穩定施法。
- **爽點與情感落點**：顧淵不靠力量壓制，而是靠觀察與理解取得新知。
- **伏筆**：村民提到近期某些區域的魔法燈會無故熄滅，但被當成普通故障。
- **萬界樓回饋**：初步建立「以太與真元差異」資料。
