# 第七卷 ch024（全書 ch231）｜並肩之約

> 所屬：第四篇｜帝國暗流・聖殿騎士（卷內 ch019–024｜全書 ch226–231）

- **出場人物**：顧淵、菲奧娜。
- **場景**：帝國城牆、夜間巡防線。
- **核心情節**：
   1. 菲奧娜與顧淵回顧調查，承認自己起初過度懷疑他。
   2. 顧淵指出她的騎士信念值得尊重，但也提醒她不能只靠個人犧牲維持正義。
   3. 菲奧娜坦言，她不願成為只會服從命令的騎士。
   4. 兩人約定共同追查黑袍會，但各自保留原有責任。
   5. 菲奧娜取得一份遠古遺跡座標，線索指向南方沙漠。
- **情感落點**：從調查者與被調查者，轉為並肩合作的夥伴。
- **伏筆**：沙漠座標與塞拉菲娜、艾琳諾發現的符文線索相互呼應。
- **萬界樓**：帝國軍事魔法資料完成初步收錄。

---

**第四篇收束**： 三位正式女主各自的故事線均已建立。此時她們不必全部聚在一起，也不必立刻形成共同團隊。第五篇將把顧淵帶往另一種古老魔法文明，並安排克麗奧佩脫拉登場。
