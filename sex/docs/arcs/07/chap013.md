# 第七卷 ch013（全書 ch220）｜月曜森林

> 所屬：第三篇｜精靈月曜・生命之樹（卷內 ch013–018｜全書 ch220–225）

![第三篇｜精靈月曜・生命之樹](../../../images/07040-第三篇-精靈月曜.png)

**篇章目的**： 讓顧淵從奧術知識轉向生命與自然傳承。艾琳諾的故事核心不是「受傷後等待治療」，而是她如何在精靈族的責任、信仰與自身意願之間作出選擇。

- **出場人物**：顧淵、艾琳諾、精靈巡林者。
- **場景**：翠玉庭院外圍、月曜森林。
- **核心情節**：
   1. 顧淵依古代法師塔的資料前往精靈領地。
   2. 初入森林，感受到與以太魔網不同的生命脈動。
   3. 精靈巡林者對人族外來者保持警戒。
   4. 顧淵協助處理一處被污染的自然泉眼，但沒有強行改變當地自然循環。
   5. 艾琳諾以月曜祭司身分出面，詢問顧淵為何能感知森林生命。
- **情感落點**：艾琳諾對顧淵產生初步好奇，仍以祭司職責為先。
- **伏筆**：森林深處有些古樹的生命氣息正在無聲衰退。
- **萬界樓**：收錄精靈自然魔法與生命脈動資料。
