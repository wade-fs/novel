# 第七卷 ch029（全書 ch236）｜王冠之下

> 所屬：第五篇｜沙漠古國・失落秘法（卷內 ch025–034｜全書 ch232–241）

- **出場人物**：顧淵、克麗奧佩脫拉、女王近侍。
- **場景**：王宮花園、星象觀測台。
- **核心情節**：
   1. 女王帶顧淵參觀王宮中的古代星象觀測台。
   2. 兩人談論王朝興衰、帝國擴張與統治者的責任。
   3. 克麗奧佩脫拉透露，自己必須在王室傳統、外部強權與國內派系之間維持平衡。
   4. 顧淵不對她的政治選擇說教，也不承諾替她守住王國。
   5. 女王第一次在談話中不以外交辭令應對，而是坦承自己對未來的憂慮。
- **情感落點**：她開始把顧淵視為可以短暫卸下王冠、坦誠說話的人。
- **伏筆**：王室星象圖顯示古代泰坦封印曾與沙漠王國的祭司傳承相連。
- **萬界樓**：收錄王室星象圖與古代王權契約資料。
