# 第七卷 ch017（全書 ch224）｜根脈深處

> 所屬：第三篇｜精靈月曜・生命之樹（卷內 ch013–018｜全書 ch220–225）

- **出場人物**：顧淵、艾琳諾、精靈巡林者。
- **場景**：受污染森林地下根脈。
- **核心情節**：
   1. 顧淵與艾琳諾帶隊深入地下根脈。
   2. 發現死氣並非從外部侵入，而是沿著某種古老通道逆向流動。
   3. 艾琳諾以生命魔法穩定根脈，顧淵負責隔離異常能量。
   4. 兩人配合成功阻止一次局部污染擴散。
   5. 根脈深處出現疑似泰坦時代的封印痕跡。
- **情感落點**：兩人建立真正的合作默契，艾琳諾開始把顧淵視為可以共同承擔責任的人。
- **伏筆**：封印痕跡與塞拉菲娜研究的符文有相似結構。
- **萬界樓**：取得世界樹根脈樣本與封印資料。
