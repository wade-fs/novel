# 第七卷 ch015（全書 ch222）｜生命印記

> 所屬：第三篇｜精靈月曜・生命之樹（卷內 ch013–018｜全書 ch220–225）

- **出場人物**：顧淵、艾琳諾、精靈醫者。
- **場景**：月曜神殿、生命泉。
- **核心情節**：
   1. 顧淵注意到艾琳諾施展生命魔法後會出現短暫衰弱。
   2. 精靈醫者解釋，這是生命印記受到污染後的反噬。
   3. 艾琳諾不願將自己的問題公開，擔心影響祭司職責。
   4. 顧淵以修仙者角度分析，發現污染並非普通疾病，而是某種外來力量改變生命循環。
   5. 艾琳諾同意讓顧淵觀察印記，但要求研究結果先由精靈長老知悉。
- **情感落點**：顧淵尊重她的責任與界線，艾琳諾因此更願意信任他。
- **伏筆**：污染力量與失落法師塔資料中的死氣特徵相似。
- **萬界樓**：建立精靈生命印記研究檔案，暫不判定可治癒。
