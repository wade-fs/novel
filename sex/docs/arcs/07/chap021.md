# 第七卷 ch021（全書 ch228）｜失控的魔獸

> 所屬：第四篇｜帝國暗流・聖殿騎士（卷內 ch019–024｜全書 ch226–231）

- **出場人物**：顧淵、菲奧娜、帝國騎士小隊、受污染魔獸。
- **場景**：帝國城郊村落。
- **核心情節**：
   1. 菲奧娜帶隊調查魔獸異變，顧淵作為外部協助者同行。
   2. 魔獸襲擊村落，展現不符合自然習性的攻擊方式。
   3. 菲奧娜優先疏散村民，顧淵負責控制魔獸。
   4. 兩人合作避免村落遭到大規模破壞。
   5. 魔獸體內發現人工鍊金殘留物。
- **情感落點**：顧淵看見菲奧娜的責任感，菲奧娜也認可他不以力量凌駕平民安危。
- **伏筆**：鍊金殘留物帶有黑袍會標記。
- **萬界樓**：取得異變魔獸樣本與鍊金痕跡。
