# 第七卷 ch031（全書 ch238）｜王朝暗潮

> 所屬：第五篇｜沙漠古國・失落秘法（卷內 ch025–034｜全書 ch232–241）

- **出場人物**：顧淵、克麗奧佩脫拉、王室近衛、反對派貴族。
- **場景**：王都內城、王室議事廳。
- **核心情節**：
   1. 王室內部反對派企圖利用古代遺跡異常，削弱女王權威。
   2. 顧淵發現有人暗中挪用王室祭儀資源，試圖打開地下封印。
   3. 女王決定自行調查，不把所有事情交給顧淵。
   4. 顧淵協助辨認魔法痕跡，卻不介入她對貴族派系的處置。
   5. 兩人發現事件與黑袍會的遠古研究有間接關聯。
- **情感落點**：女王欣賞顧淵尊重她的統治權，而不是把她當成需要保護的弱者。
- **伏筆**：地下封印的能量流向泰坦遺跡。
- **萬界樓**：取得黑袍會在沙漠古國活動的線索。
