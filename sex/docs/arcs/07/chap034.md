# 第七卷 ch034（全書 ch241）｜女王的選擇

> 所屬：第五篇｜沙漠古國・失落秘法（卷內 ch025–034｜全書 ch232–241）

- **出場人物**：顧淵、克麗奧佩脫拉、王室近侍。
- **場景**：王宮星辰殿、王都外城。
- **核心情節**：
   1. 顧淵向女王說明泰坦遺跡的發現。
   2. 克麗奧佩脫拉決定將王室部分祭司力量投入維護古國封印，但不把全部國運押在顧淵身上。
   3. 她也作出自己的政治安排，面對王朝未來，不要求顧淵留下。
   4. 顧淵與她正式道別，兩人保留一段特殊而短暫的記憶。
   5. 顧淵離開沙漠，準備與塞拉菲娜、艾琳諾及菲奧娜交換資料。
- **情感落點**：克麗奧佩脫拉沒有被帶走，也沒有成為第四位長期女主；她選擇繼續自己的人生。
- **伏筆**：她交給顧淵的星辰符印，日後可能成為萬界樓辨識沙漠古國座標的媒介，但不等同於建立長期紅顏錨點。
- **萬界樓**：沙漠古國資料完整收錄；若 ch030 已符合雙修條件，此處只記錄後續穩定狀態，不重複計分。

**第五篇收束**： 克麗奧佩脫拉完成她的彩蛋人物弧線；沙漠古國不被顧淵收編，也不因他的離開而失去自主性。顧淵取得泰坦核心的重要資料，終於能把前三篇的線索串聯起來。
