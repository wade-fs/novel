# 第七卷 ch005（全書 ch212）｜浮空學院

> 所屬：第一篇｜魔法異界・初入艾瑟蘭（卷內 ch001–006｜全書 ch208–213）

- **出場人物**：顧淵、學院招生使者、學生與教授。
- **場景**：達拉然浮空群島、奧術學院外圍。
- **核心情節**：
   1. 顧淵抵達達拉然浮空群島，見識魔法文明的高階建築與交通方式。
   2. 了解奧術評議會並非單一學院，而是多所法師塔與研究機構組成。
   3. 學院正在舉辦公開課與跨校交流活動。
   4. 顧淵以外來研究者身分取得旁聽資格。
   5. 他發現魔法理論的研究方式與修仙宗門的傳承方式差異極大。
- **爽點與情感落點**：浮空群島的奇觀，以及顧淵以求知者身分進入全新知識領域。
- **伏筆**：學院公告提及一位年輕冰霜魔導士，近期正在研究失落符文。
- **萬界樓回饋**：初步建立達拉然座標與學院資料。
