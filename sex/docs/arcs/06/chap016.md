# 第016章｜木劍問父

- **所屬篇章**：第三篇《水月驚龍》（chap014～chap022）
- **地點**：滄瀾界・姑蘇郊外天劍別院（接至姑蘇行宮外院）
- **主要人物**：顧淵、洛寒衣、**洛行舟（阿舟・6歲）**
- **關鍵進度**：
  - **第二子正式登場**：**洛行舟（男・6歲・乳名阿舟）**首度與父親顧淵面對面相見。
  - **【用戶指定必留名場面】**完整呈現（方案 B：顧淵雖在第一篇便知有子、一路早做心理準備，真被兒子一句話問住仍一時語塞，引發洛寒衣經典調侃！）。
  - 萬界樓修復度：`725/10000`。

## 核心劇情
顧淵隨洛寒衣踏入滄瀾姑蘇郊外清幽的天劍別院。自第一篇聽聞「我有個兒子」以來，顧淵一路掛念至今，終於迎來父子正式相見之刻。院中梅樹下，六歲男孩洛行舟正握著一把磨得發亮的木劍、照著母親平日練劍的架勢反覆比劃——對六歲的阿舟而言，劍不是什麼高深大道，只是母親生活裡最熟悉的一部分。摔倒在青石上他也抿著嘴不肯哭。洛寒衣走過去將兒子帶到顧淵面前讓其叫人——縱使早有準備，顧淵仍被小男孩清亮的一問問得徹底語塞，成就全卷最動人又讓人忍俊不禁的名場面！

## 場景節拍
1. **模仿母親的木劍**：剛進別院，顧淵便見六歲男孩執木劍笨拙卻認真地學著洛寒衣收劍的姿態，輪廓像極了母親，眼神卻藏著一股與顧淵如出一轍的沉穩倔強；他未必多懂劍道，只是因為母親天天練劍，便也拿著木劍陪著模仿。
2. **【必留名場面】木劍問父**：洛寒衣按住男孩肩頭讓他叫人。小男孩拿著木劍，仰頭認真看了顧淵好一會兒，清亮問道：「**你就是我娘等了很久的那個人？**」早已在心裡演練過無數開場白的萬界樓主，竟一時徹底語塞、不知如何應答；洛寒衣在旁邊抱臂冷冷補上一句：「**怎麼？堂堂萬界樓主，連兒子都不知道怎麼應付？**」
3. **父子破冰**：顧淵深吸一口氣，蹲下身與六歲的阿舟平視，沒有擺父親架子，而是誠懇道了一句「對不起，讓你和你娘等太久了」，並親手替阿舟拍去膝頭灰塵、看出兒子幼年武道資質普通卻極重視守護身邊之人。
4. **冷面破功**：阿舟點點頭竟把木劍遞給顧淵想比劃兩招，洛寒衣看著笨拙卻認真陪兒子揮木劍的顧淵，眼底最後一絲防備與疏離悄然化開，轉身背對父子嘴角微微上揚。

## 人物與關係重點
- **洛行舟（阿舟・6歲）**：倔強、好勝、不服輸、摔倒不哭；起初只是因模仿母親生活才拿木劍，絕不寫成六歲悟劍道的小天才，為將來真正成長開創守護協同劍道留足空間。
- **洛寒衣**：經歷第一、二篇的相處確認後，這句冷冷的調侃既帶著三分小小報復，更藏著徹底放下戒心的釋然與傲嬌。

## 敘事原則與寫作提醒
- **原句精準保留**：必須完整呈現「你就是我娘等了很久的那個人？」與「怎麼？堂堂萬界樓主，連兒子都不知道怎麼應付？」兩句核心台詞。
