# 第016章｜木劍問父

- **所屬篇章**：第三篇《水月驚龍》（chap014～chap022）
- **地點**：滄瀾界・姑蘇郊外天劍別院（接至姑蘇行宮外院）
- **主要人物**：顧淵、洛寒衣、**洛行舟（阿舟・6歲）**
- **關鍵進度**：
  - **第二子正式登場**：**洛行舟（男・6歲・乳名阿舟）**首度與父親顧淵相見。
  - **【用戶指定必留名場面】**完整呈現，洛寒衣完成對顧淵當年不告而別的小小報復。
  - 萬界樓修復度：`725/10000`。

## 核心劇情
顧淵隨洛寒衣踏入滄瀾姑蘇郊外清幽的天劍別院。洛寒衣一路忍了整整兩篇、始終沒提前說破的「底牌」，終於在此刻揭曉——院中梅樹下，一名六歲小男孩正握著一把磨得發亮的木劍反覆劈刺，摔倒在青石上也抿著嘴不肯哭。洛寒衣走過去將兒子帶到顧淵面前，冷冷讓孩子叫人，成就全卷最動人又讓人忍俊不禁的父子初見！

## 場景節拍
1. **木劍少年**：剛進別院，顧淵便見六歲男孩執木劍練得滿頭大汗，輪廓像極了洛寒衣，眼神卻藏著一股與自己如出一轍的沉穩倔強。
2. **【必留名場面】木劍問父**：洛寒衣按住男孩肩頭讓他叫人。小男孩拿著木劍，仰頭認真看了顧淵好一會兒，清亮問道：「**你就是我娘等了很久的那個人？**」向來運籌帷幄的顧淵一時徹底語塞、不知如何應答；洛寒衣在旁邊抱臂冷冷補上一句：「**怎麼？堂堂萬界樓主，連兒子都不知道怎麼應付？**」
3. **父子破冰**：顧淵深吸一口氣，蹲下身與六歲的阿舟平視，沒有擺父親架子，而是誠懇道了一句「對不起，讓你和你娘等太久了」，並親手替阿舟拍去膝頭灰塵、看清兒子幼年武道資質雖普通卻有一股極韌的守護心志。
4. **冷面破功**：阿舟點點頭竟把木劍遞給顧淵想討教一招，洛寒衣看著笨拙卻認真教兒子握劍的顧淵，心底七年來最後一絲委屈悄然化開，轉身背對父子嘴角微微上揚。

## 人物與關係重點
- **洛行舟（阿舟・6歲）**：倔強、好勝、不服輸、摔倒不哭；造化賜福不顯於幼年資質，而在堅毅守護之心。
- **洛寒衣**：這場小小的報復極度契合她清冷傲嬌的性格，笑中帶淚、餘韻無窮。

## 敘事原則與寫作提醒
- **原句精準保留**：必須完整呈現「你就是我娘等了很久的那個人？」與「怎麼？堂堂萬界樓主，連兒子都不知道怎麼應付？」兩句核心台詞。
