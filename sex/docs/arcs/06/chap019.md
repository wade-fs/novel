# 第019章｜太湖破局

- **所屬篇章**：第三篇《水月驚龍》（chap014～chap022）
- **地點**：滄瀾界・太湖水會・蘆花暗寨
- **主要人物**：姬明月、西施、慕容玥、洛寒衣、顧淵、吳州暗派首領＆天行者供奉（反派）
- **關鍵進度**：
  - 四女各司其職徹底粉碎天行者與吳州主戰暗派的毀盟陰謀。
  - **姬明月 × 西施**正式建立政治與私人認可（朝廷不強求水月閣臣服，水月閣願於大局需要時相助）。
  - 截獲指向**九曜神域水曜神系**的跨界星石單據。
  - 萬界樓修復度：`725/10000`。

## 核心劇情
太湖水會當日，吳州主戰暗派與天行者武聖供奉依計發難，企圖刺殺越州使臣、嫁禍水月閣並引爆戰火。然而四女早已布下天羅地網——姬明月執掌朝綱調動天策禁軍鎖死政局、西施號令江南水網封堵暗寨退路、慕容玥當場拋出鐵證契約斷絕黑市銀號資金鏈、洛寒衣一劍霜雪鎮壓黑市武聖核心！一場席捲江南的動亂被四位奇女子乾脆俐落地聯手粉碎。

## 場景節拍
1. **水會發難**：吳州暗派與黑市死士於太湖水會突襲，場面一時大亂；顧淵隱身暗處盯防天行者可能動用的高維逃遁秘器，將正面舞台全數交給四女。
2. **四女合圍**：
   - **西施**施展《水月柔水劍意》借湖水卸開暗器救下越州使臣，反客為主揭穿刺客身分；
   - **姬明月**龍袍現身太湖樓船，以大乾監國之威當眾宣讀吳州逆臣罪證，穩住吳越十年盟約與兩州人心；
   - **慕容玥**聯手官府同步查封姑蘇黑市錢莊，讓幕後資助者一夜傾家蕩產；
   - **洛寒衣**孤劍衝入蘆花暗寨，十招內擊潰天行者雇傭的武聖供奉，截下欲逃的黑市管事。
3. **九曜單據**：顧淵出手破去黑市管事懷中一枚即將自燃的跨界空間符，從中取出一塊刻有「水曜・星運」印記的異界玉簡——三界異常正式與九曜神域串聯！
4. **雙姝相認**：風波落定，姬明月與西施並肩立於太湖樓船；女帝大氣表明不強求水月閣稱臣納貢，西施亦溫婉頷首許諾江南若有國難水月閣必不袖手，兩強真正惺惺相惜。

## 人物與關係重點
- **四女高光**：政治、江湖、商業、武力四位一體，展現《萬界風月樓》女性群像的極致魅力。

## 敘事原則與寫作提醒
- 戰鬥與權謀節奏明快爽利，強調四女彼此互補的信任成形。
