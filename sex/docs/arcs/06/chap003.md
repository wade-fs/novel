# 第003章｜青雲見微

- **所屬篇章**：第一篇《歸樓星霜》（chap001～chap008）
- **地點**：青玄界・青雲山・清虛小築
- **主要人物**：顧淵、柳清虛、**柳知微（微微・5歲）**、慕容玥（隨後跟來）
- **關鍵進度**：
  - **第一子正式登場**：**柳知微（女・5歲・乳名微微）**首度與父親顧淵相見。
  - 萬界樓修復度：`660/10000`。

## 核心劇情
顧淵隨柳清虛回到暌違已久的青雲山，還沒來得及細看宗門新貌，便在清虛小築的靈梅樹下遇見一名五歲女童。女童安靜乖巧、眉眼酷似母親、笑起來卻帶著顧淵獨有的神態——正是前卷因緣累積所結、柳清虛在青雲山悉心撫養長大的女兒「柳知微」。顧淵生平頭一回真正以父親身分面對站在眼前的親生骨肉，竟罕見地手足無措。

## 場景節拍
1. **梅下初見**：小院靜謐，五歲的柳知微正安靜蹲在石階旁看枯葉被微風吹動、注意到屋簷角一隻躲雨的小雀，對修煉毫無特別興趣；見陌生青衫男子走近，不哭不鬧，安靜抬眼打量。
2. **初為人父**：柳清虛輕聲介紹「微微，這是爹爹」。向來從容淡定的萬界樓主瞬間僵住，不知該彎腰抱起還是先遞見面禮，最後手忙腳亂從袖裡摸出一枚文瀾帶回的竹編小玩意，惹得微微唇角彎起、露出酷似顧淵的清淺笑意。
3. **平凡中的細心**：微微接過竹編玩意後，竟一眼注意到顧淵袖口微露的舊疤與他指尖沾著的一星墨跡，輕聲問「爹爹剛剛寫字了嗎？」顧淵微微一怔——女兒天生沒有突出靈根、也不像小修士，卻總能敏銳察覺大人常忽略的環境與生活小細節（造化天賦留待成長後漸顯）。
4. **乾娘搶娃**：隨後跟來青雲山的慕容玥見狀立刻撲上去抱起微微，又塞靈果又逗笑，得意炫耀「微微最喜歡玥姨了」，讓一向清冷的柳清虛也微不可察地蹙起柳眉、暗自吃了一回女兒與夫君的雙重小醋。

## 人物與關係重點
- **柳知微（微微・5歲）**：安靜、乖巧、很有主見、對修煉沒特別興趣；不早慧成小修士，而是真實可愛、細心敏感的五歲女童。
- **顧淵**：在文瀾學會敬畏凡人生命後，此刻第一次真正體會「血脈親情與為人父」的柔軟重量。
