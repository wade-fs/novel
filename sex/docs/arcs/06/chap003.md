# 第003章｜青雲見微

- **所屬篇章**：第一篇《歸樓星霜》（chap001～chap008）
- **地點**：青玄界・青雲山・清虛小築
- **主要人物**：顧淵、柳清虛、**柳知微（微微・5歲）**、慕容玥（隨後跟來）
- **關鍵進度**：
  - **第一子正式登場**：**柳知微（女・5歲・乳名微微）**首度與父親顧淵相見。
  - 萬界樓修復度：`660/10000`。

## 核心劇情
顧淵隨柳清虛回到暌違六年的青雲山，還沒來得及細看宗門新貌，便在清虛小築的靈梅樹下遇見一名五歲女童。女童安靜乖巧、眉眼酷似母親、笑起來卻帶著顧淵獨有的神態——正是柳清虛於卷四廣寒月宮破丹成嬰雙修後暗結造化、返山懷胎一年誕下的女兒「柳知微」。顧淵生平頭一回以父親身分面對親生骨肉，竟罕見地手足無措。

## 場景節拍
1. **梅下初見**：小院靜謐，五歲的柳知微正蹲在石階旁看著靈露滴落、指尖輕觸流轉的微弱靈氣；見陌生青衫男子走近，不哭不鬧，安靜抬眼打量。
2. **初為人父**：柳清虛輕聲介紹「微微，這是爹爹」。向來從容淡定的萬界樓主瞬間僵住，不知該彎腰抱起還是先遞見面禮，最後手忙腳亂從袖裡摸出一枚文瀾帶回的竹編小玩意，惹得微微唇角彎起、露出酷似顧淵的清淺笑意。
3. **造化微兆**：顧淵以破妄真視無意一瞥，發現女兒天生竟無特別突出的靈根，卻能憑純粹直覺敏銳察覺周遭天地靈氣最細微的流向變化，心中既驚且軟。
4. **乾娘搶娃**：隨後跟來青雲山的慕容玥見狀立刻撲上去抱起微微，又塞靈果又逗笑，得意炫耀「微微最喜歡玥姨了」，讓一向清冷的柳清虛也微不可察地蹙起柳眉、暗自吃了一回女兒與夫君的雙重小醋。

## 人物與關係重點
- **柳知微（微微・5歲）**：安靜、乖巧、觀察力強、很有主見；絕不寫成妖孽小天才，而是真實可愛的五歲孩童。
- **顧淵**：在文瀾學會敬畏凡人生命後，此刻第一次真正體會「血脈親情與為人父」的柔軟重量。

## 伏筆與下章銜接
