# 第006章｜紅帳算帳

- **所屬篇章**：第一篇《歸樓星霜》（chap001～chap008）
- **地點**：青玄界・東華仙城・千寶商樓頂層私院
- **主要人物**：顧淵、慕容玥
- **關鍵進度**：
  - 顧淵與慕容玥補回六年時光，熱情主動的深度溫存。
  - **萬界樓本源修復**：**+7**（累計：**685/10000**）。
  - 商道暗線浮現：北嶺靈草商路發現異常異界丹毒。

## 核心劇情
憋了一肚子醋意與思念的慕容玥，終於如願把顧淵「搶」回千寶商樓頂層私院。她先是拿著那柄背面暗刻「淵」字的玄金算盤，一邊跨坐膝頭撒嬌算著六年複利、一邊連哄帶逼問出文瀾薛濤箋的來歷；轉眼又攤開商盟密卷，點出青玄北嶺與長安西郊一帶近日頻現劣質異界丹毒。

## 場景節拍
1. **算盤討債**：紅燭暖閣內，慕容玥把「清虛姐生了微微、師尊獨佔了半宿」全記上帳，又嬌又賴地抱怨顧淵偏心，眼底卻是滿溢的依戀與慶幸。
2. **紅箋商眼**：慕容玥細賞顧淵贈與把玩的兩張薛濤紅箋，嘆服異界女子以詩社串聯女商的巧思，笑言將來去滄瀾江南說不定能做成一筆風雅大買賣。
3. **紅帳補債**：慕容玥不肯再等片刻，主動勾頸獻吻、明豔熱烈地拉顧淵共入紅帳；從強勢索求到軟語求饒，將六年積攢的思念盡數傾瀉，紫氣東來、玄金微鳴（**+7 → 685**）。
4. **北嶺密報**：事後慕容玥慵懶枕在顧淵臂彎，恢復女財閥的犀利本色——遞上密帳指出北嶺近半年流入一批來源不明的偽劣靈草丹丸，連長安西郊貂蟬的清心閣都曾收治受害散修。

## 人物與關係重點
- **慕容玥**：既要寫出她吃醋、撒嬌、補回時間的鮮活女人味，絕不能弱化她執掌萬界商道的精明頭腦。

## 敘事原則與寫作提醒
- **雙修場景規格**：走「熱情主動 ＋ 風情萬種」路線，畫面香豔流暢、節奏起伏分明、篇幅飽滿，與柳、沈二女形成鮮明對比。

## 伏筆與下章銜接
- 顧淵收下北嶺密報，想起樓中還有一位心結未解的白衣劍仙，當夜返回萬界樓星台尋洛寒衣。
