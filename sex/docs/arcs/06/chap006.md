# 第006章｜紅箋密報

- **所屬篇章**：第一篇《歸樓星霜》（chap001～chap008）
- **地點**：青玄界・東華仙城・千寶商樓頂層私院
- **主要人物**：顧淵、慕容玥
- **關鍵進度**：
  - 商樓輕快日常＋吃醋撒嬌＋主線切入（刻意不硬塞雙修，避免第一篇連續流水帳）；萬界樓修復度維持 `680/10000`。
  - **商道暗線浮現**：北嶺靈草商路發現異常異界丹毒，直指長安西郊清心閣曾收治受害散修。

## 核心劇情
憋了一肚子醋意與思念的慕容玥，把顧淵直接「搶」回千寶商樓頂層私院。她拿著背面暗刻「淵」字的玄金算盤，跨坐膝頭又嬌又賴地算著久別複利、細賞顧淵帶回的文瀾薛濤紅箋；撒嬌歸撒嬌，她隨即恢復萬界大掌櫃的犀利本色，攤開密卷點出青玄北嶺頻現劣質異界丹毒的異常，臨別前只熱情吻住他、揚眉約定「這筆債記在帳上，等查完案子本姑娘要你連本帶利補回來！」

## 場景節拍
1. **算盤討債**：暖閣內，慕容玥把「清虛姐生了微微、師尊獨佔了半宿」全記上帳，又鬧又撒嬌地抱怨顧淵偏心，展現有底線卻鮮活生動的吃醋爭寵。
2. **紅箋商眼**：慕容玥把玩顧淵送來的兩張薛濤紅箋，嘆服異界女子以詩社串聯女商的巧思，笑言將來赴滄瀾江南定能開出一條風雅大商路。
3. **北嶺密報**：收起玩笑，慕容玥攤開商盟帳冊指出北嶺近日流入一批來源不明的偽劣靈草丹丸，連長安西郊貂蟬的清心閣都曾收治中毒散修——疑似有跨界黑市染指青玄。
4. **俏皮索約**：兩人正欲深吻之際商樓夥計急報軍商來信，慕容玥只好氣呼呼咬了他唇角一口，笑著立下「辦完正事可別想跑」的俏皮債約，輕快打破前兩章的沉靜節奏。

## 人物與關係重點
- **慕容玥**：既寫出吃醋、撒嬌、靈動有趣的女人味，更突出她執掌萬界商道、推進全卷三界暗線的關鍵腦力。

## 敘事原則與寫作提醒
- 此章走**輕快日常＋微醋互動＋主線推進**路線，刻意不硬塞雙修，讓第一篇 8 章節奏有鬆有緊、絕不重複。

## 伏筆與下章銜接
- 顧淵收下北嶺密報，想起樓中還有一位心結未解、又剛告知自己有個六歲兒子的白衣劍仙，當夜返回萬界樓觀星台尋洛寒衣。
