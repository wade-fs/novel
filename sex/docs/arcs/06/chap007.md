# 第007章｜不再獨行

- **所屬篇章**：第一篇《歸樓星霜》（chap001～chap008）
- **地點**：萬界樓・觀星台 → 靜霜別院
- **主要人物**：顧淵、洛寒衣
- **關鍵進度**：
  - 顧淵與洛寒衣直面核心心結，重立「不再單方面替對方決定命運」之約。
  - 冰山融春、劍心重契，長篇深度雙修。
  - **萬界樓本源修復**：**+25**（累計：**710/10000**）。

## 核心劇情
萬界樓觀星台星霧如雪，洛寒衣抱劍獨坐。顧淵前來與她徹底攤牌——他沒有用大義或保護敷衍，而是誠實承認自己昔日習慣把一切扛在肩上、單方面把她推出星門其實是一種傲慢與不公。歷經文瀾四年學會尊重他人選擇的顧淵，鄭重許諾此後無論生死風暴皆與她共擔；七年冰封的委屈與思念在這一夜徹底決堤。

## 場景節拍
1. **星台對坐**：顧淵替獨飲寒酒的洛寒衣添杯，正面回應第一章的質問，坦承自己在文瀾界也曾因獨斷誤判付出慘痛代價，終於明白真正的珍視不是替她做決定。
2. **新約落定**：洛寒衣眼眶微紅卻仍倔強別過臉，問他「你發誓往後再遇險境，不許再推開我？」顧淵執起她握劍生繭的素手按在自己心口鄭重立誓，兩人七年心結開始真正鬆動。
3. **霜雪融春**：靜霜別院內，平日孤傲絕塵的天劍女武王難得卸下所有防備，由生澀微嗔到緊擁顧淵滿是舊疤的脊背；先天劍骨琉璃生輝、斷星劍在案頭輕吟共振，極致反差的深情交融長留於星夜之中（**+25 → 710**）。
4. **未盡之謎**：天明時分，洛寒衣唇角帶著難得一抹淺淡狡黠——雖然原諒了他一半，但她仍決定把「天劍山那位小驚喜」留到兩人回到滄瀾界再親自算總帳。

## 人物與關係重點
- **洛寒衣**：極致反差萌與武者尊嚴並存；心結雖大鬆，仍須後續共同經歷來徹底印證。

## 敘事原則與寫作提醒
- **雙修場景規格**：第一篇最高潮的情感長章！走「古風純粹 ＋ 霜雪融春 ＋ 劍心共振」路線，畫面感、情感張力與篇幅皆須拉滿。
