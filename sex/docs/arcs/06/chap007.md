# 第007章｜不再獨行

- **所屬篇章**：第一篇《歸樓星霜》（chap001～chap008）
- **地點**：萬界樓・觀星台 → 靜霜別院
- **主要人物**：顧淵、洛寒衣
- **關鍵進度**：
  - 顧淵與洛寒衣直面核心心結，重立「不再單方面替對方決定命運」之約。
  - 顧淵鄭重表態願承擔父親責任，與洛寒衣約定辦完長安之行便同返滄瀾正式見兒子洛行舟。
  - 冰山融春、劍心重契，長篇深度雙修；**萬界樓本源修復**：**+30**（累計：**710/10000**）。

## 核心劇情
萬界樓觀星台星霧如雪，洛寒衣抱劍獨坐。顧淵前來與她徹底攤牌——他沒有用大義或保護敷衍，而是誠實承認自己昔日習慣把一切扛在肩上、單方面把她推出星門其實是一種傲慢與不公。歷經文瀾四年學會尊重他人選擇的顧淵，鄭重許諾此後無論生死風暴皆與她共擔，亦誠摯表白自己想陪她回滄瀾、真正學會當阿舟的父親；長久冰封的委屈與思念在這一夜徹底決堤。

## 場景節拍
1. **星台對坐**：顧淵替獨飲寒酒的洛寒衣添杯，正面回應第一章的質問，坦承自己在文瀾界也曾因獨斷誤判付出慘痛代價，終於明白真正的珍視不是替她做決定。
2. **新約與父責**：洛寒衣眼眶微紅卻仍倔強別過臉，問他「你發誓往後再遇險境，不許再推開我？」顧淵執起她握劍生繭的素手按在自己心口鄭重立誓，並低聲詢問阿舟平日愛玩什麼；洛寒衣神色微暖，說起兒子愛拿木劍摔倒也不哭的模樣，兩人心結開始真正鬆動。
3. **霜雪融春**：靜霜別院內，平日孤傲絕塵的天劍女武王難得卸下所有防備，由生澀微嗔到緊擁顧淵滿是舊疤的脊背；先天劍骨琉璃生輝、斷星劍在案頭輕吟共振，極致反差的深情交融長留於星夜之中（**+30 → 710**）。
4. **赴滄之約**：天明時分，洛寒衣同意待先陪顧淵赴長安清心閣查完北嶺丹毒、再一同返回滄瀾界，正式讓阿舟見見這位「讓娘等了很久的爹」。

## 人物與關係重點
- **洛寒衣**：極致反差萌與武者尊嚴並存；既有對伴侶的堅持，也有對兒子的謹慎守護。

## 敘事原則與寫作提醒
- **雙修場景規格**：第一篇最高潮的情感長章！走「古風純粹 ＋ 霜雪融春 ＋ 劍心共振」路線，畫面感、情感張力與篇幅皆須拉滿。
