# 第002章｜久別利息

- **所屬篇章**：第一篇《歸樓星霜》（chap001～chap008）
- **地點**：萬界樓・本源核心大殿 → 靜室長廊
- **主要人物**：顧淵、慕容玥、柳清虛、沈玄清、洛寒衣
- **關鍵進度**：
  - 青玄三女全數與顧淵重逢，四人各自展現截然不同的反應。
  - 文瀾信物首次在舊女主眼前曝光，引發好奇與微妙吃味。
  - 萬界樓修復度：`660/10000`。

## 核心劇情
青玄三女接踵踏入萬界樓。慕容玥二話不說撲進顧淵懷裡又捶又紅了眼，喊著要算這許久以來的利息；柳清虛靜立階下，表面如掌門般沉靜無波，眼底卻壓著千言萬語；沈玄清只是多看了顧淵一眼，便最先察覺他眼底那抹與從前截然不同的凡塵沉厚與未癒心傷。

## 場景節拍
1. **撲懷算帳**：慕容玥直接撞進顧淵懷裡，邊罵他音訊全無邊紅了眼眶，伸手扯開他衣袖發現刀疤，頓時又氣又心疼。
2. **異界信物**：慕容玥眼尖翻出顧淵袖中散發芙蓉清香的十二月花信風「薛濤箋」與袖珍《金石總目》，嘴上酸溜溜追問哪方才女所贈，卻也瞬間敏銳嗅出異界文墨與女性商社的價值。
3. **靜默重逢**：柳清虛克制行禮後只輕聲道「回來就好」，並未當眾提及青雲山上的女兒，只柔聲邀他隨自己回青雲山一趟；一旁洛寒衣冷眼旁觀，嘴角微抿帶著幾分微醋。
4. **仙尊洞見**：沈玄清淡然頷首，看出顧淵疲憊與內在蛻變，主動替他擋下慕容玥連珠炮似的追問，讓他先隨清虛回青雲山歇息。

## 人物與關係重點
- **慕容玥**：允許合理吃醋與撒嬌鬧騰，但不降智、依舊精明靈動。
- **柳清虛**：克制內斂的大婦風範，把最重的話留回青雲山說。
- **沈玄清**：最穩、最懂分寸，一眼看出他歷過生死離別。

## 敘事原則與寫作提醒
- 四女同場必須各有性格語言，嚴禁寫成同一種溫柔模版。
- 顧淵不必急著炫耀或賣慘交代文瀾界，讓信物與傷痕自然吊起諸女好奇。

## 伏筆與下章銜接
- 柳清虛邀顧淵回青雲山「見一個等了他很久的人」，引出下章柳知微登場。
