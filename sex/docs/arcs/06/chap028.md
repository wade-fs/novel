# 第028章｜影月棋痕

- **所屬篇章**：第四篇《月宮論道》（chap023～chap030）
- **地點**：九曜神域・太微玉京・熒惑軍帳密室
- **主要人物**：顧淵、羲凰、赫拉迪雅、沈玄清、慕容玥
- **關鍵進度**：
  - 推進暗線 **`FB4-03`（羅睺影月神系）** 與 **`AL-01 / FB4-05`（天行者與棋算者三界串聯）**。
  - 正式確認青玄北嶺丹毒、滄瀾太湖黑市、九曜水曜暗庫為同一跨界利益網絡的三條支脈，且棋算者正盯緊萬界樓修復度。
  - 萬界樓修復度：`770/10000`。

## 核心劇情
熒惑軍帳密室內，五人攤開來自青玄、滄瀾與九曜的三份鐵證密帳逐一比對。慕容玥精準指出三界交易暗碼出自同一套「天行者」跨界結算系統，而水曜暗庫最底層的暗契上，赫然烙印著本已銷聲匿跡的「羅睺影月神系（`FB4-03`）」密紋！更令顧淵瞳孔微縮的是，一頁密卷空白處竟留有一枚冷靜克制的棋子暗印——棋算者仍在暗處注視著萬界樓的每一次修復。

## 場景節拍
1. **三界拼圖**：慕容玥將北嶺百草行丹毒單、太湖水寨走私帳、水曜暗庫星石清單並列桌案，三條看似無關的異常事件瞬間連成一張龐大的跨界利益網絡。
2. **羅睺餘波（`FB4-03`）**：羲凰與赫拉迪雅認出密契底紋屬於「羅睺影月神系」——昔日主動吸收信仰濁泥、與諸天蝕者存有隱秘通道的危險神系餘黨，竟正透過天行者走私跨界資源。
3. **棋算暗印（`AL-01`）**：顧淵以破妄真視察覺密契夾層裡藏著一枚無聲自毀前的棋子紋影，印證有人正利用萬界秩序的漏洞與資訊差，持續觀察萬界樓周邊諸界與修復度變化。
4. **分層戒備**：顧淵點明「天行者逐利、棋算者另有私謀、蝕者遵循自身規則」三方未必一體，切忌輕率混為一談；羲凰決定在神域嚴查水曜與羅睺餘黨，赫拉迪雅則大笑宣布「案子先交給手下盯著，今明兩夜咱們先把積了五年的帳算清楚！」

## 人物與關係重點
- **五人議事**：各展所長（慕容玥商帳、沈玄清陣理、羲凰神政、赫拉迪雅軍事、顧淵總籌），呈現極具質感的跨界同盟氣勢。

## 敘事原則與寫作提醒
- 嚴格遵守三層分離原則：本卷只確認棋算者在觀察與干預，絕不揭露其真身與終極目的。
