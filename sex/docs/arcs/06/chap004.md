# 第004章｜雪夜相依

- **所屬篇章**：第一篇《歸樓星霜》（chap001～chap008）
- **地點**：青玄界・青雲山・清虛小築
- **主要人物**：顧淵、柳清虛、柳知微（哄睡）、慕容玥（次日早晨）
- **關鍵進度**：
  - 顧淵與柳清虛情感重建與深度共修。
  - **萬界樓本源修復**：**+10**（累計：**670/10000**）。

## 核心劇情
哄睡五歲的微微後，青雲山外大雪紛飛。六年獨守宗門與育女的辛勞，柳清虛一句未訴，卻在燈影搖曳的安靜夜裡罕見主動靠進顧淵懷中。沒有盤問他在異界遇見過誰，她只用最安靜的依偎告訴他——她要的從不是他有多強，而是他真的停下來陪在身邊。

## 場景節拍
1. **並肩哄女**：兩人一同替微微掖好錦被，顧淵笨拙卻極溫柔地放輕腳步，柳清虛望著他柔和側臉，六年積壓的孤單悄然融化。
2. **難得主動**：燭火微暗，顧淵正欲歇息，平日端莊清冷的青雲掌門卻輕輕從背後環住他的腰，把微涼的額頭抵在他肩背火痕處，不說「我很想你」，只低聲喚了一句「顧淵」。
3. **雪夜溫存**：兩人在窗外落雪與室中梅香間水乳交融，《太上玄奼真經》與青蓮水火既濟徐徐流轉；柳清虛褪去掌門威儀、羞而不亂地迎合相許，至純陰陽本源反哺萬界樓（**+10 → 670**）。
4. **晨起爭寵**：次日清晨，慕容玥踩著雪印殺回小築，一眼看出柳清虛眉梢溫潤春色，頓時雙手插腰鼓起臉頰抗議「不公平」，嚷著今晚說什麼也要把樓主拉走，柳清虛難得含笑遞茶、不讓半分地反將她一軍。

## 人物與關係重點
- **柳清虛**：不要讓她突然變得話多；她的深情在於不追問、不索求，只在雪夜靠過來的那個動作。

## 敘事原則與寫作提醒
- **雙修場景規格**：極具畫面感與充裕篇幅，走「古風含蓄 ＋ 水火既濟」路線，細寫梅影、雪聲、肩背舊疤被柔指輕撫的細節，讓此情動人長留。

## 伏筆與下章銜接
- 白日裡顧淵處理青雲雜務之餘，心頭仍隱隱沉著文瀾四年失去蔡邕與周伯的餘痛；入夜後，他獨自走向後山古仙石窟。
