# 第014章｜女帝南巡

- **所屬篇章**：第三篇《水月驚龍》（chap014～chap022）
- **地點**：滄瀾界・大乾東南・姑蘇行宮＆太湖水岸
- **主要人物**：姬明月、大乾禁軍與暗衛（配角）
- **關鍵進度**：
  - 展現滄瀾界天地枷鎖碎裂後的數載自主演化（R24）：高武大爭時代繁榮，吳越十年停戰盟約進入後半段。
  - 引出太湖黑市資源異動與江南崛起的新勢力「越溪水月閣」。
  - 萬界樓修復度：`725/10000`。

## 核心劇情
滄瀾界天地枷鎖粉碎數載以來，武道宗師倍出、大乾國勢鼎盛。身兼大乾監國女帝與九曜天曜議席的姬明月，將四歲愛女姬明珩暫安置於姑蘇行宮，親率精銳微服南巡太湖。她敏銳察覺吳州主戰暗派正勾連不明來歷的太湖黑市船隊，且東南武林之中，一座名為「水月閣」的江南新勢力正悄然左右著越州商路與江湖秩序。

## 場景節拍
1. **滄瀾新象**：大乾京師與江南水路商帆雲集，呈現天地枷鎖碎裂數載後滄瀾界波瀾壯闊的新局勢。
2. **女帝南巡**：姬明月立於姑蘇畫舫船頭，翻閱天策衛密報——吳州境內連月失蹤大批精鐵與高階靈藥，水路暗帳直指太湖深處。
3. **水月之名**：密報特別提及越州越溪「水月閣」：數年間由一位名為施夷光的武道大宗師一手創立，既護持吳越十年停戰盟約，又數度截斷不明黑市商船，朝廷招安卻始終婉拒依附。
4. **微服訪閣**：姬明月鳳眸微冷，不願江南留有不受掌控的變數，決定明日微服親赴越溪水月閣，親自掂量這位江南奇女子的深淺。

## 人物與關係重點
- **姬明月**：高冷、理智、極具帝王格局；獨自監國並悉心撫養明珠，威儀更勝往昔。

## 敘事原則與寫作提醒
- 此章從姬明月獨立視角切入，充分貫徹「女主不是陪襯、原世界自主演化」。
