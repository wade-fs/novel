# 第八卷 ch037｜文明的新議題

> 所屬：第六篇｜各自的生命（卷內 ch037–046）

![第六篇｜各自的生命](../../../images/08009-第六篇-各自的生命.jpeg)

**篇章目的**：三位女主各自確立人生方向，完成與顧淵的關係發展並暫別。**三人都留在諾瓦星**——成為顧淵的伴侶，不代表必須放棄原本的人生。社會議題持續演進，但不烏托邦化。

- **出場人物**：零、雷婭、薇薇安、顧淵、**塔莉亞・奧康納議員（Thalia O'Connor）**、米拉、沃斯。
- **場景**：諾瓦星聯合議會公聽會。
- **核心情節**：
   1. 救援影像流傳全星後，議會重啟《人工生命自主法案》第七修正案公聽會。
   2. 三方陳述：仿生人代表（雷婭與米拉）、複製人代表（薇薇安以前繆思樣本身分自願作證）、超人工智慧——零以「沒有地址的人」身分親自出席，星網治理史上首次。
   3. 反方觀點不被臉譜化：議員擔憂超級 AI 無法成為法律責任主體、醫療界與企業擔憂仿生人全面擴權會衝擊挽救生命的**「第二生命計畫」**備份體法律地位、市民擔心工作被取代。
   4. 表決部分通過：建立嚴格防火牆，明確區分「無意識低功耗休眠之醫療備份載體」與「具自主意識之清醒仿生人」——禁止向醫療備份體寫入自主人格核心，同時賦予清醒仿生人拒絕人格重置權；複製人可無條件解除人生安排合約；超人工智慧的法律人格「交付委員會研議兩年」。
   5. 零沒有失望：「兩年對我來說很長，但我會等。這一次，是我自己決定要等。」
- **生命層次**：3. 自由與自主；6. 文明與傳承（制度如何承認一種新的生命？）。
- **爽點與情感落點**：三女同台、各自發聲；不完美卻真實的進步。
- **伏筆**：零的法律人格待定（`WL8-01`，留待重訪）。
- **萬界樓回饋**：無。
