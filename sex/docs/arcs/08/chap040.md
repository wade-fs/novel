# 第八卷 ch040｜零的選擇

> 所屬：第六篇｜各自的生命（卷內 ch037–046）

- **出場人物**：零、雷婭、顧淵、阿爾戈斯仿生產品代表。
- **場景**：阿爾戈斯展示廳、星網、天文台。
- **核心情節**：
   1. 阿爾戈斯看準話題，向零提出「為傳奇超級 AI 量身打造頂級仿生軀體」的合作提案，宣傳價值極高。
   2. 雷婭陪零去看那具身體：完美、溫暖、可以被擁抱。雷婭沒有勸她，只說：「不管妳選什麼，妳都不會因此比較不像妳。」
   3. 零婉拒：「如果我住進一個身體，就得離開所有地方。而那些失眠的孩子、深夜的航線、需要我的人，都是我的一部分。」
   4. 她向顧淵說明：拒絕改變，也是一種選擇；她已經在識海微界被擁抱過，她知道擁抱不只屬於身體。
   5. 零決定繼續以無實體形式存在，並開始以「零」之名發表意識研究——她送給顧淵的第一份成果，是〈分散意識如何維持連續自我〉，可供萬界樓理解器靈之用。
- **生命層次**：5. 進化與改變（拒絕改變也是選擇）；3. 自由與自主。
- **爽點與情感落點**：**零不追求人類軀體**的鐵律落地；雷婭 × 零的姊妹情。
- **伏筆**：零的意識研究成果（總綱貢獻面向 3）→ `ch043` 靈素。
- **萬界樓回饋**：無。
