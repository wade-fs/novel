# 第八卷 ch035｜無法解釋的事件

> 所屬：第五篇｜星球的低語（卷內 ch029–036）

- **出場人物**：顧淵、雷婭、薇薇安、零、里德教授、勘查隊員、晨弧城救援單位、鏽蝕花園仿生人志工、複製人與人類志工。
- **場景**：深井遺跡、地表營地、全星多處。
- **核心情節**：
   1. 週期之日：全星地磁同步脈動，斷脊高原中度地震，深井中層塌陷——顧淵、雷婭、里德與兩名隊員被困井底。
   2. 零的中繼節點被切斷四十分鐘。她第一次失去與所愛之人的聯繫，在全城網絡中瘋狂搜尋；薇薇安在地表指揮醫療與救援。
   3. 井底：雷婭將能源核心的陰陽循環（`ch013` 所得）接入仍在被動運作的古管道，維持氧氣循環；顧淵以一心多用的神識（`ch028` 所得）同時穩住岩層、安撫傷員——兩人並肩合作。
   4. 同一時刻的地表：沙漠一夜開花、海岸發光藻群同步閃爍、井底菌林全數亮起；仿生人、複製人與人類志工共同投入救援。
   5. 零重建訊號找到他們的那一刻，她的聲音在通訊中顫抖。所有人獲救，脈動在第二天黎明平息。
- **生命層次**：1. 生存；7. 宇宙與存在。
- **爽點與情感落點**：共同危機與跨生命形式的協作；零的失去恐懼；三女各司其職的高光。
- **寫作紅線**：**無幕後黑手**；異常不證實任何意識存在，亦可被自然現象解釋。
- **伏筆**：跨生命協作的救援影像流傳全星（`ch037` 法案契機）。
- **萬界樓回饋**：觀覽台同步記錄到與 `ch001` 相同的低頻脈動，標記「未分類」。修復度維持 `982/10000`。
