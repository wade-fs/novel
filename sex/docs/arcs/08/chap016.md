# 第八卷 ch016｜原始基因

> 所屬：第三篇｜複製人生（卷內 ch014–020）

- **出場人物**：顧淵、薇薇安、**伊芙（Eve，薇薇安的同源複製姊妹・第五號）**、羅莎醫生。
- **場景**：中央培育中心評估室外、伊蓮娜・凡斯紀念館。
- **核心情節**：
   1. 薇薇安主動邀顧淵陪她去評估：「我想有人在門外等我一次。」
   2. 在紀念館，顧淵看見已故傳奇生態學家**伊蓮娜・凡斯（Elena Vance）**的肖像——與薇薇安容貌近乎相同。
   3. 薇薇安坦白：她是**繆思計畫（Project Muse）**第七號，以伊蓮娜基因為主體修正培育；她沒有伊蓮娜的記憶與人格，但所有人看她時，都在看伊蓮娜。
   4. 遇見同源姊妹伊芙：她已欣然接受計畫安排成為生態調節局研究員，不只生活平穩，更真誠感謝培育機構讓她享有最好的教育、醫療與無須奔波的保障——她不是受害者，也不認為薇薇安的反抗適合自己，雙方無須說服彼此。
   5. 薇薇安：「我不恨她，也不恨伊蓮娜。我只是不知道，如果把伊蓮娜從我身上拿走，還剩下什麼。」
- **生命層次**：2. 繁衍與延續；6. 文明與傳承（基因的延續，是否等於人的延續？）。
- **爽點與情感落點**：身世揭露，但不落入二元對立的複製人悲劇；伊芙讓「接受安排」也成為值得尊重的選項。
- **伏筆**：
   - 伊蓮娜的生態研究筆記（`ch033`）。
   - 伊蓮娜晚年曾研究「地底週期脈動」。
- **萬界樓回饋**：無。
