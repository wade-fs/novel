# 第八卷 ch020｜複製人生

> 所屬：第三篇｜複製人生（卷內 ch014–020）

- **出場人物**：顧淵、薇薇安。
- **場景**：伊巴拉診所屋頂菜園、舊港區公寓。
- **核心情節**：
   1. 薇薇安在羅莎醫生的診所轉為正式醫師，用第一筆薪水買了真正的牛排，堅持親手做晚餐給顧淵。
   2. 晚餐後她主動表白：「我想要一個由我自己決定的未來，而我希望你在裡面——不管你會停留多久。」她明白顧淵終將離開，仍選擇此刻。
   3. 顧淵坦白萬界樓與雙修的本質，說明她可以拒絕、可以暫緩；薇薇安笑說她早就決定了——「這不是我第一個自己做的決定，但是我最想做的那一個。」
   4. **長篇親密場景**：自然生物生命的體溫、緊張、害羞與信任；她的快速修復體質與純陽本源緩緩共鳴；生活般的溫柔與依戀；事後相擁，談起她想要的那種家。
   5. 共鳴中萬界樓本源意外流入她被設計的代謝基因，悄然撫平加速代謝的枷鎖——她在隔日的例行檢查中才發現；而她選擇他時並不知道。
- **親密與共鳴**：第一次自願雙修；主動性 **D 型**（女主主動告白）。
- **獎勵判定**：
   - **薇薇安**：解除人為設計的壽命上限，回歸與自然出生者相同的有限壽命（**不是永生**）；快速修復能力轉為可控，不再以透支細胞為代價。
   - **顧淵**：對生物造化的體悟，深化心念共鳴中的「情感共鳴」層次，並強化自身肉體自癒。
- **生命層次**：2. 繁衍與延續；4. 死亡與有限性——「和所有人一樣有限，而這份有限是我的。」
- **爽點與情感落點**：薇薇安成為第二位正式女主；愛先於獎勵，獎勵不是條件。
- **萬界樓回饋**：修復度 `936 → 960/10000（9.60%）`（**+24**）；記錄「人工培育生命陰陽共鳴」。
