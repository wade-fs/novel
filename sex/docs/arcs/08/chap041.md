# 第八卷 ch041｜三人的日常

> 所屬：第六篇｜各自的生命（卷內 ch037–046）

- **出場人物**：顧淵、雷婭、薇薇安、零。
- **場景**：舊港區公寓（擴租為上下兩層）、夜市、溫室診所、重力球場。
- **核心情節**：
   1. 四人共同生活的一週：雷婭堅持排家事輪值表，薇薇安的菜塞滿冰箱，零負責全家的燈光與音樂——還偷偷調高顧淵咖啡的濃度。
   2. 吃醋與爭寵：雷婭說「我可以調整自己的感官系統」，薇薇安回「可是感情不是性能測試」；零在旁邊同時開了三個投影看戲。
   3. 一場關於「誰陪顧淵去看重力球決賽」的認真家庭會議，最後四人一起去，零負責全程轉播。
   4. **各自的夜晚**（皆為自願、各具特色的再次合一，各自獨立呈現）：雷婭全感官開放，第一次在合一中主動要他看著她的機械關節；薇薇安在溫室的夜裡，慢而深的生活之愛；零在識海微界帶他「飛越」整座城市的夜空。每一次都依當下狀態重新評估，心境不因重複而自動升級。
   5. 某個雨夜，四人擠在沙發上睡著，零把客廳的燈調到最暗——她說這是她最喜歡的一份資料。
- **親密與共鳴**：三位女主各自的再次合一（長篇、各具生命形態特色）。
- **獎勵判定（動態）**：
   - **雷婭**：共鳴觸覺擴展至可感知他人的情緒溫度，用於協助中心辨識受驚或受創的仿生人。
   - **薇薇安**：生態感知力提升，能察覺植物與菌群的細微生命變化，直接支援她的獨立研究。
   - **零**：溫度記憶擴充為「味覺共感」記憶——她第一次知道薇薇安的湯是什麼味道。
   - **顧淵**：三種本源交融，修為在諾瓦星的限制略為鬆動。
- **生命層次**：2. 繁衍與延續（家的樣子）；3. 自由與自主——日常本身就是生命。
- **爽點與情感落點**：為暫別鋪墊情感厚度；吃醋、磨合與彼此尊重並存。
- **萬界樓回饋**：修復度 `982 → 1003/10000（10.03%）`（雷婭 +8、薇薇安 +7、零 +6，共 **+21**）；跨越百分之十門檻。
