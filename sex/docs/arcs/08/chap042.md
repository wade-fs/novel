# 第八卷 ch042｜不同的生命

> 所屬：第六篇｜各自的生命（卷內 ch037–046）

- **出場人物**：顧淵、雷婭、薇薇安、零、老伍、諾特、米拉、伊芙、馬庫斯、里德、晨弧城市民。
- **場景**：晨弧城中央廣場・**星燈節（眾生之夜）**。
- **核心情節**：
   1. 諾瓦星年度「星燈節」：每位市民點亮一盞燈，代表一個生命——今年是人工生命首次獲准以自己的名字點燈。
   2. 三女共同籌辦：雷婭的協助中心組織仿生人燈隊，薇薇安的溫室提供花燈，零負責全城的光影秀。
   3. 雷婭致詞；薇薇安與伊芙並肩點燈；零在天幕上寫下每一個新登記的名字——包括米拉，以及「雷蒙」。
   4. 全卷配角齊聚：老伍請整條街吃麵，里德帶著退休後的笑容出現，馬庫斯替伊蓮娜點了一盞燈。
   5. 光影秀最後一幕，是一盞沒有名字的燈緩緩沉向地底方向——零說：「給所有我們不知道的生命。」
- **生命層次**：1～7 全層次匯流。
- **爽點與情感落點**：全卷情感高潮；三女共同事件的最終呈現。
- **伏筆**：無名之燈（利維坦留白的溫柔處理）。
- **萬界樓回饋**：無。
