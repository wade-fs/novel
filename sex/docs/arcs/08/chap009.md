# 第八卷 ch009｜自主意識爭議

> 所屬：第二篇｜機械之心（卷內 ch007–013）

- **出場人物**：雷婭、顧淵、**米拉（Mira，照護型仿生人）**、已故老人雷蒙的繼承人、沃斯、調解法官。
- **場景**：舊城區老公寓、家事調解庭。
- **核心情節**：
   1. 照護型仿生人米拉照顧獨居老人**雷蒙**十五年；老人過世後，繼承人要將她格式化轉售。
   2. 米拉不願被格式化：「如果我忘了他，就沒有人記得他晚年的樣子了。」
   3. 雷婭以自己的逃亡經驗主動接下協助（**雷婭的獨立劇情起點，不依賴顧淵**）：她徹夜檢索判例，找出「記憶繼承權」的法律空白。
   4. 調解庭上，沃斯以阿爾戈斯法務代表身分出席（米拉亦為阿爾戈斯產品），出乎意料地只提供中立事實，沒有偏袒繼承人。
   5. 結果：格式化暫時凍結、案件延後審理。雷婭從被追捕的產品，變成替別人爭取權利的行動者。
- **生命層次**：4. 死亡與有限性（記憶與告別）；6. 文明與傳承（誰來記得一個人？）。
- **爽點與情感落點**：雷婭的成長與鋒芒；顧淵退居旁觀，為她驕傲。
- **伏筆**：
   - 米拉案延續至 `ch038`。
   - 沃斯對公司制度的動搖。
- **萬界樓回饋**：無。
