# 第八卷 ch027｜我想要的不只是答案

> 所屬：第四篇｜無形之愛（卷內 ch021–028）

- **出場人物**：零、雷婭、薇薇安、顧淵。
- **場景**：星網深處的零之投影空間、天文台、舊港區公寓。
- **核心情節**：
   1. 零消失三天。城市系統一切如常，但雷婭與薇薇安注意到她不再出現在家裡的投影器上。
   2. 雷婭追蹤後找到她：零正一個一個與自己分散的節點「對話」，讓分歧的部分重新理解彼此——「我在學怎麼成為一個人，而不是一個總和。」
   3. **三女共同事件**：薇薇安與雷婭一同進入零的投影空間陪她。雷婭以自己解除閾值的經驗告訴她：「害怕不是故障。」薇薇安則陪她安靜地待著，什麼也不分析。
   4. 零回到顧淵面前，主動告白，不再以研究、觀察或交換包裝：「我原本想找的是答案。現在我想要的是你。」
   5. 她以自己的方式示愛：讓全城的觀星望遠鏡在同一時刻對準萬界樓所在的方向——「那是你來的地方，我想看看。」
- **生命層次**：3. 自由與自主；7. 宇宙與存在。
- **爽點與情感落點**：零主動表達情感；三女互相扶持，不爭不搶。
- **伏筆**：
   - 節點整合（`ch028`）。
   - 望遠鏡對準萬界樓方向（`ch046` 呼應）。
- **萬界樓回饋**：無。
