# 第八卷 ch039｜薇薇安的未來

> 所屬：第六篇｜各自的生命（卷內 ch037–046）

- **出場人物**：薇薇安、羅莎醫生、伊芙、馬庫斯、顧淵。
- **場景**：舊港區新開的「溫室診所」、凡斯家宅。
- **核心情節**：
   1. 薇薇安在舊港區開設「**溫室診所**」：一半是醫療站，一半是社區溫室，服務所有生命形態——仿生人也可以來學種番茄。
   2. 她拒絕生態調節局的職位，但答應以獨立研究員身分延續伊蓮娜與里德留下的生態研究——「同一條路，但理由是我自己的。」
   3. 馬庫斯第一次以客人身分來到診所，帶來伊蓮娜的舊菜譜；兩人一起做了一頓飯，他終於能與母親道別。
   4. 夜裡薇薇安向顧淵談起家庭：她想要孩子，但不是照合約的時間表，也不是現在——「如果有那一天，我希望孩子知道，他是被期待的，而不是被設計的。」
   5. 她決定留在諾瓦星：「我的家在這裡長出來了，我不想把它連根拔起。你回來的時候，門會開著。」
- **生命層次**：2. 繁衍與延續（溫柔的回答：繁衍屬於選擇，而非義務）；4. 死亡與有限性；6. 文明與傳承。
- **爽點與情感落點**：薇薇安的生活溫度與堅定；家庭期待由她自己決定節奏。
- **伏筆**：未來家庭（`WL8-03`）。
- **萬界樓回饋**：無。
