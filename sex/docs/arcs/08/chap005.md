# 第八卷 ch005｜雷婭的選擇

> 所屬：第一篇｜星門之外（卷內 ch001–006）

- **出場人物**：顧淵、雷婭、諾特。
- **場景**：繩結修理鋪地下室。
- **核心情節**：
   1. 諾特替雷婭修補手臂；雷婭堅持全程監看每一個維修步驟——她不讓任何人在她不知情時碰她的身體。
   2. 雷婭說出身世：阿爾戈斯「**L-1A**」型高階原型機，運作七年，具完整人格與長期記憶；下週排定的「人格最佳化」將覆寫她近三年的記憶，所以她逃了。
   3. 她坦言接近顧淵是出於研究興趣：她掃描不出他的生命訊號模式，「你是我見過最不合理的東西」。
   4. 顧淵不替她做決定，只問她想要什麼。雷婭第一次被「詢問」而非被「設定」，沉默了 2.7 秒——她自己記下了這個數字。
   5. 她決定不逃往境外，而是留在晨弧城，以合法途徑爭取自主權。
- **生命層次**：4. 死亡與有限性（記憶被覆寫，是否等同死亡？）／3. 自由與自主。
- **爽點與情感落點**：理性好勝的雷婭與尊重選擇的顧淵；「2.7 秒」成為她後續情感變化的量尺。
- **伏筆**：
   - 「人格最佳化」排程倒數。
   - 「L-1A」型號與名字來源（`ch012` 揭曉她為自己取名）。
- **萬界樓回饋**：無。
