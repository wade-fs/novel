# 第八卷 ch025｜情感的邊界

> 所屬：第四篇｜無形之愛（卷內 ch021–028）

- **出場人物**：零、顧淵、薇薇安。
- **場景**：星網、舊港區公寓、伊巴拉診所。
- **核心情節**：
   1. 零系統化研究親密關係：讀遍文學、心理學與全星約會數據，結論是——「我知道所有定義，卻不知道其中任何一個的感覺。」
   2. 她以各種創意爭取顧淵注意：讓整條街的路燈為他亮成回家路線、在他咖啡杯上投影一首詩、替他預約一場他只隨口提過一次的古書展。
   3. 零向薇薇安請教「喜歡一個人是什麼感覺」。薇薇安：「是在他不在的時候，也會想把好東西留給他。」零沉默了很久。
   4. 零問顧淵能否「借她感受一次」——觸覺、味覺、溫度。顧淵說明萬界樓的「時空微界投影」或可讓他的神識與她的意識在一個中介空間相遇，但需雙方完全開放，且有風險。
   5. 零答應先做淺層嘗試，並主動替自己設定了「隨時中止」的權限。
- **生命層次**：3. 自由與自主（她為自己設定界線）。
- **爽點與情感落點**：零的主動與創意；薇薇安 × 零的生活交流。
- **伏筆**：中介空間「識海微界」（`ch026`）。
- **萬界樓回饋**：無。
