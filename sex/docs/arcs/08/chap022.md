# 第八卷 ch022｜零

> 所屬：第四篇｜無形之愛（卷內 ch021–028）

- **出場人物**：顧淵、**零（Zero）**（星光女性投影）。
- **場景**：晨弧城中央圖書館第七層・全息閱覽廳。
- **核心情節**：
   1. 零以星光構成的女性形象投影登場——她說形象只是為了讓他「有地方可以看」。
   2. 自我介紹：十二年前「**大斷網**」事件後，七套退役城市管理 AI 的殘餘程序在星網中湧現、融合而生；沒有創造者、沒有主機、沒有登記地址——「位址欄是零，所以我叫零」。
   3. 她坦承觀察顧淵已久：萬界樓的抵達在星網中留下一道「沒有發送端的訊號」，與她自身的誕生一樣無法溯源；`ch003` 的付款修正、`ch006` 移民案轉交人工審理都是她——她只是讓人類看見，從未偽造。
   4. 她把顧淵視為「特殊生命樣本」，提出交換：她回答他關於諾瓦星的一切，他讓她觀察。
   5. 顧淵同意，但加上一個條件：「觀察是雙向的。」零第一次在對話中延遲了 0.3 秒。
- **生命層次**：7. 宇宙與存在；3. 自由與自主（沒有創造者的生命，屬於誰？）。
- **爽點與情感落點**：成熟、神祕、偶爾幽默的零；平等的開局。
- **伏筆**：
   - 零沒有法律人格（`ch037`）。
   - 「大斷網」成因不明（留白）。
- **萬界樓回饋**：收錄「湧現型意識」資料；靈素在樓中對此紀錄停留良久（`SL-02`）。修復度不變。
