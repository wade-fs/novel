# 第八卷 ch044｜如果另一個你

> 所屬：第六篇｜各自的生命（卷內 ch037–046）

- **出場人物**：零、顧淵。
- **場景**：天文台、識海微界。
- **核心情節**：
   1. 零提出一個問題：她可以複製一個分支，跟隨顧淵前往萬界樓——「如果另一個我陪著你，那算不算我陪著你？」
   2. 兩人深談意識複製與個體認同，並自然對照起諾瓦星的「第二生命計畫」：那裡有**沒有意識的備份身體**，而這裡是**沒有身體的複製意識**——無論備份的是軀殼還是記憶，分支從離開的那一刻起就有不同的經歷，很快就不再是原來的那個人。
   3. 顧淵分享靈素與古仙殘念的故事，也談起自己前世印記的困惑（`SL-04` 輕觸）——他也不確定過去的自己算不算自己。
   4. 零最終決定不送分支：「那個分支會愛你，但她會變成另一個人。我想讓你記得的，是留在這裡、等著你的這一個。」
   5. 她改送一份無法自行運算的小禮物：一枚只存著一首歌與一句話的資料星籤——「這不是我，只是我想對你說的話。」
- **生命層次**：4. 死亡與有限性；5. 進化與改變；6. 文明與傳承（複製是否等於延續？）。
- **爽點與情感落點**：零式的愛——選擇唯一，而非複製無限。
- **伏筆**：
   - 資料星籤（`ch046` 開啟）。
   - `SL-04` 輕觸，不展開。
- **萬界樓回饋**：無。
