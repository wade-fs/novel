# 第八卷 ch007｜仿生人的世界

> 所屬：第二篇｜機械之心（卷內 ch007–013）

![第二篇｜機械之心](../../../images/08005-第二篇-機械之心.jpeg)

**篇章目的**：以雷婭的自主權為主軸，同時讓她擁有一段不依賴顧淵也能成立的個人劇情（米拉案）。感情從研究興趣走向信任與親密，於 `ch013` 確認關係；**她不必成為人類，也不必放棄機械身體**。

- **出場人物**：顧淵、雷婭、諾特、「鏽蝕花園」仿生人社群成員。
- **場景**：**鏽蝕花園（Rust Garden）**——舊工廠改建的仿生人社群中心、仿生人酒吧。
- **核心情節**：
   1. 諾特帶二人走進鏽蝕花園：仿生人自建的社群，有以電磁頻率譜寫的音樂、廢件雕塑、屬於他們自己的婚禮儀式。
   2. 仿生人的多元分化：並非單一受壓迫群體——雷婭在此（或社群論壇）遇見一位經濟富裕、生活安定的高階商務仿生人，對方雖仍受部分法律條款限制，卻**主動拒絕申請自主意識認證**：「我現在有體面收入、頂規維護與安穩生活，為什麼要為了抽象的自由去承擔失去保障的風險？」兩人理念分歧，對方不被雷婭說服，反而讓顧淵與雷婭直面「自由與承擔代價能力」的現實差距。
   3. 雷婭與鏽蝕花園舊型機同樣格格不入——身為高階原型機，她被部分舊型機視為「公司的寵兒」；她的驕傲讓她不願解釋。
   4. 酒吧的「感官調頻」聚會（類似品酒），雷婭第一次嘗試未經最佳化的原始味覺，嗆得皺眉，卻沒有關掉。
   5. 顧淵與社群老人閒談，發現他們的煩惱與凡人無異：房租、孤獨、怕被遺忘；言談間老仿生人半帶苦澀地提起內環富人區「醫療休眠庫」的傳聞，雷婭聽見後神色微不可察地冷了一瞬。
- **生命層次**：6. 文明與傳承——仿生人已有自己的文化；3. 自由與自主。
- **爽點與情感落點**：諾瓦星的生活感；雷婭的驕傲與藏在驕傲下的孤單。
- **伏筆**：
   - 社群中流傳照護型仿生人米拉的案件（`ch009`）。
   - 內環「醫療休眠庫」傳聞（`ch008` 揭開「第二生命計畫」）。
- **萬界樓回饋**：無。
