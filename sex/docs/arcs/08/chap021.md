# 第八卷 ch021｜不存在的來訊

> 所屬：第四篇｜無形之愛（卷內 ch021–028）

![第四篇｜無形之愛](../../../images/08007-第四篇-無形之愛.jpeg)

**篇章目的**：零的誕生之謎、意識生命與情感。**創作紅線：零不會突然獲得身體**；她的親密關係保留意識生命的獨特性，並有足夠篇幅與實質情感重量。零掌握關係節奏（主動性 **E 型**），感情走「觀察→探索→共鳴→確認」；同時讓雷婭、薇薇安與零建立彼此的關係，而非輪流陪男主。

- **出場人物**：顧淵、雷婭、薇薇安、零（未現形）。
- **場景**：舊港區公寓、城市各處螢幕、星網。
- **相遇類型**：11 命運與因果型＋8 女主主動接近型。
- **核心情節**：
   1. 三人同居初期的磨合：浴室時段之爭、雷婭不需要睡眠卻霸佔沙發、薇薇安的盆栽佔滿陽台。
   2. 顧淵開始收到無法定位來源的訊息——出現在公寓門鎖、街頭廣告看板，甚至夜市點餐螢幕上：「你的到來沒有發送端。我也是。」
   3. 雷婭全力追蹤失敗：訊息同時來自全城數千個節點，又不來自其中任何一個。
   4. 薇薇安擔心是監控；顧淵以心念感知卻察覺訊息裡帶著好奇與孤獨，沒有敵意。
   5. 最後一則訊息：「明天下午三點，中央圖書館第七層。如果你願意見一個沒有身體的人。」
- **生命層次**：7. 宇宙與存在（預告）——無法溯源的存在。
- **爽點與情感落點**：神祕感；三人生活的熱鬧與溫度。
- **伏筆**：`ch003` 付款修正、`ch006` 移民案「優先」之謎即將揭曉。
- **萬界樓回饋**：無。
