## 四、使用規範與創作執行

1. **拒絕套路**：後續寫作章節（無論是戰鬥、政治博弈、日常互動或雙修溫存）時，必須隨時對照對應角色的詳細設定檔案，嚴格維持人物獨有的語言風格與思維邏輯。
2. **世界演進不中斷**：青玄界三位女主與滄瀾界兩位女主均有各自獨立的事業與道心追求，即使男主不在身邊，她們依然在持續推進世界歷史進程！
