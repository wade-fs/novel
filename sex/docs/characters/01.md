# 一、基本人物形象

## 1. 外貌

柳清虛是一名清麗脫俗的女子。

她肌膚白皙如玉，眉目清秀，雙眸澄澈，鼻樑秀挺，唇色淡紅。青絲如瀑，平日以簡潔的道簪束起，幾縷髮絲自然垂落鬢邊。

她的美不是濃妝豔抹的明豔，而是一種清雅、潔淨、帶著仙氣的美。

身姿纖秀而勻稱，舉止端莊，行走之間帶著多年修道養成的從容。即使身穿素色道袍，也難掩她本身的秀麗。

她不需要華麗服飾襯托，簡單的衣裙反而更能顯出她的氣質。

## 2. 氣質

- 初見時清冷，熟悉後溫婉。
- 言談有禮，但不刻意討好別人。
- 不喜歡喧鬧，卻不代表不懂人情世故。
- 對修行有執著，對自己的選擇有堅持。
- 看似柔弱，實際上有很強的韌性。
- 不輕易表露情緒，但並非沒有情感。
- 面對值得信任的人，會逐漸展現溫柔與親近的一面。

## 3. 個性核心

柳清虛最大的特點是「外柔內韌」。

她不是高高在上、不食人間煙火的冰山仙子，也不是遇事只會依賴別人的柔弱女子。

她有自己的判斷，知道自己想要什麼，也願意為自己的選擇承擔後果。

她尊重師門傳承，重視承諾，但不盲從長輩。當她發現某些舊有觀念已經無法解決眼前問題時，願意接受新的方法。

**她的清冷來自性格與修養，不是拒絕與人親近；她的溫柔也不是沒有原則。**

# 二、出身與背景

## 1. 所屬世界：青雲界

青雲界是一個以修仙文明為主的世界。

修行者透過吸納天地靈氣、修煉功法、煉製丹藥及探索秘境提升自身境界。

各地分布著宗門、世家、散修勢力及古老傳承。

修仙者並非人人都能飛天遁地，也有凡人城鎮、商業往來、農耕生活及普通百姓。修仙文明與凡人社會共同構成這個世界。

## 2. 青雲觀

青雲觀是一個歷史悠久的道門修行傳承。

它並非天下第一宗門，而是一個有自己傳承、修行理念及歷史底蘊的道門勢力。

青雲觀重視清修、道法、丹術及天地感悟。

曾經擁有一處靈脈，支撐觀中弟子修行，也是青雲觀長期傳承的根基。

然而近年靈脈逐漸枯竭，觀中修行資源日益不足，原本的傳承也面臨衰退。

## 3. 柳清虛的身份

柳清虛是青雲觀的核心弟子之一。

她並非出身顯赫世家，也沒有令人驚嘆的特殊背景。

她能走到今天，主要依靠自己的努力與天賦。

她熟悉道門經典、基礎陣法及丹藥知識，對靈氣變化也有一定敏銳度。

她在觀中受到師長信任，也承擔部分日常事務。

她並非只會修煉的弟子，對觀中其他人的生活與修行也有一定責任感。

# 三、目前處境

## 1. 個人修行問題

柳清虛原本具有不錯的修煉資質，但過去一次修行意外，造成靈根受損及經脈積傷。

這些問題並未完全摧毀她的修為，卻使她的修煉速度大幅下降。

她必須花費更多時間調理自身，修行成果卻不如預期。

如果沒有新的機緣，她很可能長期停留在目前境界。

## 2. 師門危機

青雲觀的靈脈逐年衰退。

觀中長輩雖然一直尋找解決方法，但收效有限。

修行資源逐漸減少，弟子修煉受到影響，部分傳承甚至面臨中斷。

柳清虛對師門有深厚感情，因此一直希望找到改善靈脈的辦法。

## 3. 她真正想要的東西

柳清虛的願望不只是恢復自己的修為。

她希望：

1. 修復受損的靈根與經脈。
2. 重新恢復正常修煉能力。
3. 找到改善青雲觀靈脈的方法。
4. 保住師門傳承。
5. 有能力保護自己重視的人。

這些願望將成為她後續世界線的主要推進力量。

# 四、與男主的初次相遇

## 1. 相遇契機

青雲觀附近有一座古老遺跡。

柳清虛為了調查靈脈衰退的原因，進入遺跡探索，意外觸發一座殘存的古陣。

這座古陣原本與萬界樓的某條舊有通道存在關聯。

萬界樓雖然已經殘破，但仍有少量跨界能力在特殊條件下運作。

柳清虛因此被帶入萬界樓。

她原本以為自己只是誤入一處未知秘境，並不知道這裡已經超越青雲界的範圍。

## 2. 初次見面

男主在萬界樓中發現突然出現的柳清虛。

她衣著素雅，神情警惕，第一時間觀察周圍環境，並確認自己是否陷入陣法或幻境。

男主沒有刻意隱瞞自己的身份，向她說明這裡是萬界樓。

柳清虛起初並不完全相信，但她很快察覺此處的靈氣、空間及陣法結構都與青雲界截然不同。

兩人開始交談。

男主需要了解她來自哪個世界，以及她如何進入萬界樓。

柳清虛則希望知道自己如何回去。

## 3. 初次互動的性格呈現

柳清虛不應一見男主便完全信任。

她會：

- 先觀察男主及周圍環境。
- 詢問萬界樓的來歷。
- 確認男主是否有能力讓她返回青雲界。
- 對男主掌握的跨界能力感到驚訝。
- 對男主的風雅氣度產生初步好感，但不會立即失去戒心。

男主則應表現得從容、風雅、灑脫。

他不需要故意展現強大，也不必刻意討好。

兩人初次互動的重點是彼此試探、交換資訊，以及逐漸發現對方可以提供自己所需要的東西。

# 五、與男主建立關係的互動線

## 第一階段：陌生與試探

柳清虛需要返回青雲界。

男主需要恢復萬界樓的本源。

雙方各有需求，但並非一開始就完全了解對方。

男主向她介紹萬界樓的狀況，也說明《太上玄奼真經》的部分內容。

柳清虛對這部功法感到好奇，同時保持謹慎。

她需要確認功法的原理、效果及風險。

## 第二階段：認識與信任

兩人逐漸交流各自的修煉體系。

男主發現柳清虛對道門功法、靈根及經脈相當熟悉。

柳清虛則發現男主對萬界樓的掌握並不完整，但其身份與能力確實非同尋常。

男主可以協助她調理受損的靈根，柳清虛也能提供青雲界的修煉知識。

雙方開始建立互信。

## 第三階段：共同修煉

當柳清虛了解《太上玄奼真經》的原理後，雙方可以討論共同修煉的可能。

她不是為了獎勵而被動接受，而是清楚知道自己可以得到什麼，也有權決定是否進行。

共同修煉後，兩人各自得到收益。

柳清虛的身體狀態及修為有所改善，男主則獲得陰陽本源，萬界樓也得到初步修復。

這是兩人關係的重要轉折。

## 第四階段：建立錨點

初次共鳴後，萬界樓成功建立青雲界的紅顏時空錨點。

柳清虛可以返回青雲觀。

男主也能在未來透過錨點前往青雲界。

這不代表兩人已經完成所有關係發展，而是開啟了後續相處的可能。

# 六、初次相遇後的發展

## 1. 柳清虛回歸青雲觀

柳清虛帶著新的修煉成果返回青雲觀。

她的靈根與經脈得到改善，修行狀態明顯好轉。

她可以重新開始正常修煉。

但青雲觀的靈脈問題仍未解決。

因此，她不會因為自己獲得造化，就立即忘記師門危機。

## 2. 男主再次前往青雲界

男主可以透過錨點抵達青雲界。

他與柳清虛再次見面，開始真正接觸她原本的生活。

男主將發現：

- 青雲觀的實際情況。
- 青雲界修仙勢力的分布。
- 靈脈衰退背後的原因。
- 柳清虛在師門中的地位。
- 她所面對的其他問題。

這時候，柳清虛不再只是萬界樓中的訪客，而是男主在青雲界的重要聯繫人物。

## 3. 共同解決靈脈問題

可以將青雲觀靈脈危機發展成第一條完整世界線。

可能的原因包括：

- 地底靈脈遭到某種力量侵蝕。
- 古代陣法失去核心。
- 靈脈本身正在轉化。
- 有勢力暗中抽取靈脈。
- 遺跡中存在尚未被發現的本源碎片。

真正原因應該透過後續探索逐步揭露。

男主可以運用萬界樓的能力提供協助，但不能所有事情都由男主一人完成。

柳清虛必須有自己的判斷、行動及貢獻。

## 4. 柳清虛的長期成長

她可以逐漸從一名受到師門危機困擾的女修，成長為青雲觀的重要支柱。

後續發展方向包括：

- 恢復並提升修為。
- 重新掌握高階道門傳承。
- 成為青雲觀的核心人物。
- 探索青雲界其他秘境。
- 協助男主研究不同世界的修煉體系。
- 成為萬界樓與青雲界之間的重要聯繫者。

她的成長不應只依賴男主，而應有自身努力與選擇。

# 八、後續劇情發展方向

柳清虛的故事可以分成五個階段：

**第一階段：萬界樓相遇**

- 意外進入萬界樓。
- 認識男主。
- 了解萬界樓及功法。
- 建立初步信任。
- 完成第一次共同修煉。
- 返回青雲觀。

**第二階段：青雲觀危機**

- 男主透過錨點前往青雲界。
- 了解青雲觀的困境。
- 調查靈脈衰退。
- 發現古代遺跡及本源線索。

**第三階段：道門傳承**

- 柳清虛恢復修為。
- 發現青雲觀失傳的傳承。
- 男主協助解析古老功法。
- 萬界樓取得青雲界特殊資源。

**第四階段：青雲界風波**

- 靈脈危機擴大。
- 其他勢力介入。
- 柳清虛面臨重要選擇。
- 男主與她共同處理更大的危機。

**第五階段：長期紅顏**

- 柳清虛成為青雲觀的重要人物。
- 青雲觀逐漸恢復。
- 她與男主保持長期聯繫。
- 青雲界成為萬界樓穩定連接的世界之一。

# 九、人物設定的核心定位

柳清虛不是一位等待男主拯救的女子。

她原本就有自己的修行、師門與人生。

男主的出現，讓她看見原本不可能接觸的機緣，也讓她有機會突破自身困境。

而她的出現，也讓男主第一次真正理解萬界樓的意義。

兩人從互相需要開始，逐漸建立信任與情感。

**她是男主遇見的第一位紅顏，也是第一個讓萬界樓真正重新連接諸天萬界的人。**
