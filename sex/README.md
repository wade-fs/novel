# 《萬界風月樓》

以諸天萬界為舞台、以萬界樓為核心、以男女主角親密共鳴與雙修為本源動力的長篇玄幻爽文。

---

## 卷目結構

- **第一卷：仙門歸來・青玄風雲**（第 001 章 ～ 第 016 章，共 16 章）
  - 顧淵宿慧初醒於萬界樓，與青雲掌門柳清虛初遇並重塑道基，回歸山門肅清門戶，救助師尊沈玄清與千寶商樓慕容玥，立威東華。
- **第二卷：諸天第一步・滄瀾風雲**（第 017 章 ～ 第 052 章，共 36 章）
  - 穿過二號星門初履滄瀾武道界，結識冷傲劍仙洛寒衣與監國帝女姬明月；破魔網、平宮亂、斬黑天魔皇，碎天地枷鎖。
- **第三卷：諸天回首・青玄歸途**（第 053 章 ～ 第 088 章，共 36 章）
  - 回歸青玄界，重啟九霄秘境，破獲天行者走私暗網與九幽老魔之患；五女同殿立盟，解鎖三號星門，啟程九曜神域。
