# 《萬界風月樓》第七卷女主設定檔案｜艾琳諾・晨星（精靈族・月曜主祭）

> **人物一句話定位**：外柔內剛、心懷森林與生命的精靈月曜祭司；從數十年默默獨自承擔族群重擔的守護者，走向學會為自己選擇幸福、並與顧淵並肩守住世界樹命脈的長期伴侶。  
> **所屬世界**：艾瑟蘭・北方精靈林海（翠玉庭院／月曜森林）  
> **人物模型**：**溫柔守護型 ＋ 共同患難型 ＋ B 型（善意帶戒心 → 理解陪伴 → 情感依靠 → 溫柔接納）**。  
> **與男主關係**：第七卷正式長期伴侶、凝成紅顏道印「**月曜星葉印**」、持有萬界樓跨界星墜（保留後續入樓、家庭與後代空間）。

## 一、基本人物形象與外貌特質

* **外貌特質**：
  * 身姿纖細優雅，一頭柔順如月華絲綢般的淺金色長髮垂落腰際，露出一對溫潤秀氣的精靈尖耳（動情羞怯時耳尖極易泛紅）。
  * 眉眼柔和清澈如林間澄湖，翡翠般雙眸蘊含精靈族特有的空靈與悲憫，眼底卻沉澱著遠超外表的堅韌與主見。
  * **日常裝束**：公開祭儀時著流瀑般的月白與翠金交織祭司長袍、額戴銀葉月冠；林間探查時換上翡翠銀紋輕裝；私密月夜時則著素雅淡銀絲綢寢裙，披散淺金長髮，宛若月下綻放的銀月蘭。
* **氣質內核**：
  * **「溫柔不是軟弱，守護者首先也是一個活生生的人。」**
  * 絕非只會等待救援的柔順花瓶，在精靈議事庭面對數百年資歷長老時亦能據理力爭、冷靜分析因果。

## 二、性格反差與專屬味道

* **對外姿態（翠玉庭院月曜祭司）**：
  * 十二歲起便因百年最純淨的月曜生命親和被選入神殿，長年壓抑個人喜怒哀樂，將「月曜祭司艾琳諾」排在「艾琳諾自己」之前；哪怕生命印記遭逆流死氣反噬劇痛，仍微笑隱瞞以安族心。
* **對顧淵的真實反應**：
  * **細膩依戀與偶爾的小任性**：唯有在顧淵面前，她才敢承認自己也會疲憊、孤單與害怕失去；確立關係後，會帶著淡淡小任性輕點顧淵下巴，要求他無論去多少個遙遠世界都不許忘記這片森林、不許久不回訊。
  * **三女互動中的從容氣度**：面對塞拉菲娜的微醋調侃，不退縮亦不尖銳，以溫柔大氣的微笑輕鬆接招，展現成熟穩重的包容度。

## 三、修為、傳承與大道反哺成果

* **傳承體系**：精靈自然生命魔法（非強制操控以太，而是與萬物生命建立雙向共鳴）。
* **核心印記**：**「月曜生機無瑕印」**（原為月曜生命印記，因世界樹死氣逆流浮現三道灰暗裂紋；於第七卷 `ch036` 月露靜榭雙修中徹底淨化重鑄，對世界樹本源承載力提升兩倍，對外來死氣具備天然純陽抗性，踏入高階生命共鳴境）。
* **紅顏道印與信物**：凝成萬界樓正式紅顏道印**「月曜星葉印」**；原贈顧淵親手凝聚的**月葉吊墜**作為千里心念信物，卷末獲贈萬界樓跨界星墜。

## 四、第七卷感情與成長軌跡

1. **月曜初遇（ch013～015）**：顧淵以柔和不傷水脈之法隔離自然泉眼灰霧，引發艾琳諾好奇；她為顧淵作有限擔保留駐庭院，並在嚴守族群優先底線下讓顧淵觀測受污染的生命印記。
2. **議事力爭與地下護根（ch016～017）**：於精靈議事庭堅定反對不可逆的「斷根術」，與顧淵深入霧葉林區地下根脈聯手遏止死氣潮汐、發現泰坦遠古封印，首次體會「身邊有人共同承擔」的踏實。
3. **月下心語（ch018）**：觀月平台卸下數十年孤獨，被顧淵「守護者也有選擇自己人生的權利」深深觸動，立志主動追查世界樹根部真相。
4. **四方會議與月露相許（ch035～036）**：於達拉然四方會議定下「二十人入林、不奪核心」的精靈底線；極北決戰前夜於月露靜榭主動向顧淵表白，以「艾琳諾自己」的身分選擇雙修共鳴（萬界樓修復 **`+30 → 850/10000`**），徹底淨化生命印記。
5. **星樹新生與主祭新職（ch038～040）**：以無瑕印記千里坐鎮世界樹生命端接引順流，見證世界樹重煥生機；出任翠玉庭院「自然與守序協調主祭」，留守精靈林海守護新局。

## 五、親密互動與雙修模式特性

* **主要適用模式**：**溫柔空靈月華模式（古風含蓄 ＋ 自然木火生春共鳴）**。
* **互動細節**：月華銀紗、銀月蘭清香、敏感易紅的精靈尖耳；從生澀微顫到徹底舒展的柔美反差，雙修時銀綠生命清輝與純陽道韻交織令窗外靈植抽枝綻蕾，兼具治癒美感與深沉依戀。
