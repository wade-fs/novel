# 《萬界風月樓》第七卷女主設定檔案｜菲奧娜・格里芬（星輝帝國・聖殿女騎士長）

> **人物一句話定位**：出身騎士世家、鐵血護民的星輝帝國聖殿女騎士長；在「服從腐朽軍令」與「忠於騎士榮譽」之間堅守獨立判斷，從戒備審查官走成能託付後背、直球主動選擇愛情的英武伴侶。  
> **所屬世界**：艾瑟蘭・星輝帝國（獅鷲堡／帝都聖殿騎士團）  
> **人物模型**：**立場對立／調查轉並肩型 ＋ D/E 型（懷疑調查 → 合作磨合 → 欣賞信任 → 坦率主動選擇）**。  
> **與男主關係**：第七卷正式長期伴侶、凝成紅顏道印「**聖輝長劍印**」、持有萬界樓跨界星墜（保留後續入樓、家庭與後代空間）。

## 一、基本人物形象與外貌特質

* **外貌特質**：
  * 身姿挺拔修長、英氣勃發，一頭如秋日烈陽般耀眼的栗金色長髮常高高束成俐落馬尾，琥珀色眼眸清亮坦蕩如鷹隼。
  * 擁有常年習武鍛鍊出的極致黃金比例健美身段，肌膚泛著如秋陽蜂蜜浸潤過的象牙脂玉光澤，充滿健康蓬勃的生命張力。
  * **日常裝束**：戰陣時披白銀鑲金聖殿騎士輕甲、左肩搭赤紅戰披、腰懸聖輝精鋼長劍；夜巡換輕便深藍皮甲；私下卸甲著雪白亞麻騎士襯衫、披散栗金長髮時，英武明媚與野性魅惑兼具。
* **氣質內核**：
  * **「吾劍所向，非為權貴之私，唯護黎民之安、真理之光。」**
  * 直率坦蕩、從不扭捏算計；有勇有謀，拒絕盲從權貴，也不因一時血氣拖累部下發動愚蠢兵變。

## 二、性格反差與專屬味道

* **對外姿態（北境聖殿女騎士長）**：
  * 紀律嚴明、身先士卒。灰溪村魔獸異變襲村時第一時間橫馬掩護兩百餘百姓撤離；面對北境軍務副大臣霍爾頓強壓結案，冷靜忍辱借道帝都恩師破局。
* **對顧淵的真實反應**：
  * **爽朗直球、常居主動**：對比艾琳諾的溫婉與塞拉菲娜的嘴硬，菲奧娜愛恨最分明、最不繞彎子。花廊裡大方調侃傲嬌的塞拉菲娜，獅鷲堡觀星閣裡直接仰頭飲酒、親自按住顧淵心口，明確宣示「今夜不是以騎士長身分，而是以菲奧娜這個女人的身分坦蕩選擇你」。
  * **戰場與私下的黃金反差**：戰場上一人鎖死十丈石橋擋住百名死士，私下親密時既會豪爽反客為主，也在純陽與聖光徹底交融的熾熱中展現直白熱烈的柔情。

## 三、修為、武技與大道反哺成果

* **戰鬥體系**：星輝帝國高階魔法騎士戰技（以精鋼武技、強悍氣血與光系附魔戰甲結合，重戰場陣型協同與意志增幅）。
* **修為進境**：初登場為四階頂尖聖殿騎士長；第七卷 `ch040` 獅鷲堡觀星閣雙修後，徹底焚洗多年戰傷與死氣殘留，凝成**「聖輝獅鷲不滅戰體」**，晉升**五階聖騎士巔峰**（無需甲冑外置增幅即可聖光護體，對一切暗影與死氣侵蝕具天然淨化抗性）。
* **紅顏道印與信物**：凝成萬界樓正式紅顏道印**「聖輝長劍印」**；卷末獲贈萬界樓跨界星墜，貼身佩於銀甲內側。

## 四、第七卷感情與成長軌跡

1. **問詢試探與校場互敬（ch019～020）**：因顧淵無咒施法報告展開接觸，訓練場七連魔導劍技試探未果，反因顧淵點出騎士戰場體系的獨特價值而由懷疑轉為平等尊重。
2. **灰溪救民與黑袍工坊（ch021～022）**：與顧淵完美配合保住全村兩百餘百姓零亡，高度認可他「不以力量凌駕平民安危」之品格；聯手搗毀真理黑袍會地下活體工坊，查獲帝國權貴免檢貨單。
3. **騎士抉擇與並肩之約（ch023～024）**：遭霍爾頓子爵強令結案時堅守底線且不陷部下於叛亂，借顧淵靈氣拓印鐵證密呈帝都亞瑟大騎士長；夜巡城牆坦率致歉並立下並肩之約，破譯交付南方沙漠遺跡座標。
4. **四方立誓與石橋血戰（ch035～038）**：持帝都全權軍令在達拉然壓住帝國文官促成聯盟；極北泰坦核心失控之際，以聖輝鋒矢陣與一己之軀死守懸空石橋，替核心同伴守住生路。
5. **制度改革與觀星坦率相許（ch039～040）**：配合帝都肅清霍爾頓腐敗集團，擢升北境代理大隊長推動騎士改革；獅鷲堡觀星閣卸甲直球表白、金陽聖輝雙修成不滅戰體（萬界樓修復 **`+30 → 910/10000`**）。
