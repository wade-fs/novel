# 第002章｜雲京風雨

- **所屬篇章**：第一篇《焚書亂世》（chap001～chap008）
- **時間**：第一年秋
- **地點**：雲京市井、白玉書院外圍
- **主要人物**：顧淵
- **關鍵進度**：
  - 心念共鳴：第一階「情緒感知」（察覺市井百姓與士子的壓抑與恐懼）。
  - 典籍工程：尚未開始（目睹文化清洗前兆）。

## 核心劇情
顧淵在雲京市井求生，逐漸察覺大胤王朝已處於崩潰邊緣。權臣藉清查異端之名大肆查抄書院、士族與民間藏書。顧淵目睹白玉書院遭到封鎖，意識到這場政治清洗並非單純針對官員，而是有計畫地摧毀大胤的文化傳承。

## 場景節拍
1. **市井求生**：顧淵在雲京茶肆、書坊間打零工謀生，透過日常交談拼湊大胤末年的時局。
2. **禁書風聲**：書坊陸續關門、儒生低語避禍，權臣以「清查異端」為名收繳私史與藏書。
3. **白玉書院被封**：顧淵行經白玉書院外，親眼看見官兵封鎖街巷、盤查進出書生，書院內外氣氛緊繃。
4. **看穿清洗本質**：顧淵透過觀察與市井消息，明白這場查抄針對的是記憶與話語權，而非單純貪墨或黨爭。

## 人物與關係重點
- **顧淵**：展現失去力量後依然敏銳的觀察力與冷靜判斷，對這個王朝的命運產生最初的關注。

## 敘事原則與寫作提醒
- 透過市井細節（茶肆談資、書坊收攤、告示、官兵神情）呈現亂世氛圍，不靠旁白硬塞世界觀。

## 伏筆與下章銜接
- 白玉書院的封鎖與蔡氏父女的名聲被市井提及，引出下一章顧淵因意外踏入書院。
