# 第003章｜蔡氏父女

- **所屬篇章**：第一篇《焚書亂世》（chap001～chap008）
- **時間**：第一年秋
- **地點**：白玉書院
- **主要人物**：顧淵、蔡邕、蔡琰、周伯
- **關鍵進度**：
  - 人物登場：大儒蔡邕、第一女主蔡琰（字文姬）、老僕周伯正式登場。
  - 心念共鳴：第一階「情緒感知」。

## 核心劇情
顧淵因意外事件進入白玉書院，結識當世大儒蔡邕與其女蔡琰。蔡琰才學出眾，熟悉經史、音律與典籍整理，卻因王朝動盪而不得不承擔遠超其年齡的責任。蔡邕看出顧淵雖然來歷不明，卻有不同於尋常人的沉穩與觀察力。

## 場景節拍
1. **意外入書院**：顧淵在書院外圍因一場突發盤查或搬運典籍的意外，順手相助而進入白玉書院。
2. **初見蔡琰**：蔡琰正在典籍室中冷靜指揮抄錄與分類，氣度清雅卻帶著不容置疑的條理與擔當。
3. **拜見蔡邕**：蔡邕與顧淵簡短交談，察覺他雖無功名背景，卻言行沉穩、不卑不亢，留他在書院暫避並協助雜務。
4. **周伯照料**：老僕周伯忠厚細心，默默打點蔡府與書院日常，對蔡琰如視己出。

## 人物與關係重點
- **蔡琰**：第一女主初登場即展現獨立思考與歷史責任感，不是等待被救的柔弱閨秀。
- **蔡邕**：溫潤厚重的長者形象，為後續的託付與犧牲奠定情感重量。
- **顧淵**：在書院找到暫時落腳處，開始與蔡氏父女建立初步信任。
