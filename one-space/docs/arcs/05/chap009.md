# 第009章｜關卡盤查

- **所屬篇章**：第二篇《孤舟南渡》（chap009～chap016）
- **時間**：第一年冬
- **地點**：陳留道沿途關卡
- **主要人物**：顧淵、蔡琰、周伯
- **關鍵進度**：
  - 顧淵成長：從「失去」進入「依靠」，承認自己缺乏亂世凡俗生活經驗。

## 核心劇情
南下道路戒備森嚴，沿途官兵與地方勢力反覆盤查流民、商旅及士族。顧淵原本習慣獨自解決問題，如今卻不得不承認自己缺乏亂世生活經驗，開始依靠蔡琰對地方風俗與人情世故的理解。

## 場景節拍
1. **寒冬關卡**：陳留道上風雪漸起，關卡層層設防，盤查過往車馬與書箱。
2. **顧淵碰壁**：顧淵試圖以冷靜說理與常規方式應對盤查，反因不熟悉地方暗規與口音禮數而險些引起懷疑。
3. **蔡琰解圍**：蔡琰從容出面，以士族禮數、地方掌故與恰到好處的應對化解守關吏員的刁難。
4. **心態轉折**：顧淵第一次坦然承認，在這個沒有超凡力量的世界裡，自己必須向蔡琰學習與依靠。

## 人物與關係重點
- **顧淵與蔡琰**：打破「男主單方面保護女主」的套路，展現蔡琰在世故與學識上的主導力。

## 敘事原則與寫作提醒
- 細寫亂世關卡的真實生態（路引、抽稅、地方宗族口吻），讓凡俗世界立體可信。

## 伏筆與下章銜接
- 過關後糧草與通行憑證仍捉襟見肘，下一章兩人將在實際危機中形成真正的互補。
