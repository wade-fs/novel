# 第046章｜紅箋與遠行

- **所屬篇章**：第六篇《素琴歸途》（chap041～chap048）
- **時間**：第四年冬
- **地點**：江左詩社、清議堂、瀾江渡口
- **主要人物**：顧淵、薛濤、上官婉兒、魚玄機
- **關鍵進度**：
  - 群像收束（薛濤、上官婉兒、魚玄機線）：三人各自確立獨立人生去向，並留下與顧淵重逢的約定。

## 核心劇情
薛濤正式接掌江左女性詩社，讓女性文人、商旅與地方社群建立長期交流網絡。上官婉兒選擇留在江左，繼續參與朝局清議與宮廷史料整理。魚玄機則決定雲遊四方，不願將自己的未來固定在任何一座城市或任何一種身份中。四人各自留下與顧淵重逢的約定。

## 場景節拍
1. **薛濤掌詩社**：薛濤在紅箋工坊與詩社小院送別顧淵，溫潤微笑，贈以一匣親製紅箋，約定日後重逢再煮茶對酌。
2. **上官婉兒留江左**：上官婉兒立於卷宗案前，冷靜告知自己將留在江左繼續整理宮廷秘檔、參與清議，讓權力不再能輕易抹去真相，並與顧淵約定來日再見。
3. **魚玄機雲遊四方**：江畔渡口，魚玄機背著行囊與酒葫蘆，笑著向顧淵揮手——她不屬於任何城市或身分，要去看看更廣闊的天地，若有緣自會在江湖某處重逢。
4. **各自延伸的人生**：顧淵看著她們各自奔赴自己選擇的道路，心中唯有敬意與溫暖。

## 人物與關係重點
- **三才女去向**：薛濤守護交流、上官婉兒守護真相、魚玄機守護自由，無一人因顧淵離去而停滯。

## 敘事原則與寫作提醒
- 嚴格遵守敘事原則第10條：「離別必須尊重選擇，不替任何才女決定未來。」
