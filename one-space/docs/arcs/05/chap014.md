# 第014章｜史書之外

- **所屬篇章**：第二篇《孤舟南渡》（chap009～chap016）
- **時間**：第二年春
- **地點**：瀾江岸邊渡口客棧
- **主要人物**：顧淵、蔡琰
- **關鍵進度**：
  - 顧淵成長：從「依靠」邁向「理解」，真正看懂蔡琰的史觀與志業。

## 核心劇情
顧淵不理解蔡琰為何放棄部分珍本，蔡琰則認為王朝興亡不能只靠帝王將相的記錄理解。兩人展開第一次深入的史觀對話：若史書只記得權力與勝敗，那麼普通人的生活是否就不值得留下？顧淵開始理解蔡琰守護的並不只是書，而是那些沒有機會為自己留下姓名的人。

## 場景節拍
1. **烘烤殘卷**：脫險後兩人在岸邊小棧生火烘乾受潮的地方簿冊，清點損失。
2. **史觀爭論**：顧淵坦言若論價值與籌碼，珍本顯然更能換取江左士族的支持；蔡琰平靜反駁，珍本尚有士族爭藏，而災荒與徭役簿冊一旦焚毀，便再無人記得百姓如何活過這場亂世。
3. **核心叩問**：「若史書只記得權力與勝敗，那麼普通人的生活是否就不值得留下？」
4. **真正理解**：顧淵沉默良久，第一次從骨子裡理解蔡琰守護的不是死物，而是無數無名之人的存在證明。

## 人物與關係重點
- **顧淵與蔡琰**：思想層面的首次深度碰撞，奠定兩人長期相知的根基。

## 敘事原則與寫作提醒
- 允許兩人立場有真實分歧（顧淵偏務實戰略，蔡琰重歷史責任），不要讓任何一方顯得膚淺。
