# 第012章｜山河有據

- **所屬篇章**：第二篇《孤舟南渡》（chap009～chap016）
- **時間**：第二年早春
- **地點**：瀾江沿岸、古渡口
- **主要人物**：顧淵、蔡琰
- **關鍵進度**：
  - 三錨點：**空間錨**正式起步（結合輿圖、地理志、實地考察與歷史變遷）。

## 核心劇情
顧淵發現文瀾界的山川、河道與古籍記載並非完全一致。他開始理解，地圖不是世界本身，必須結合實地考察、地方記錄與歷史變遷才能建立可靠定位。空間錨由此起步。

## 場景節拍
1. **河道改道之謎**：客船途經一處古渡，顧淵發現實際江岸與《九州地理志》相差數十里。
2. **蔡琰點撥**：蔡琰指出數十年前大水改道、州縣遷徙，古籍未及修訂，唯有對照地方碑記與船夫口述方知實情。
3. **觀念轉變**：顧淵領悟「地圖不是世界本身」，過去靠神識俯瞰萬界的習慣在此行不通，必須腳踏實地以凡人視角丈量山河。
4. **空間錨起步**：顧淵開始逐日記錄星象方位、水文地貌與州縣沿革，空間錨由紙面落實到真實大地。

## 人物與關係重點
- **顧淵**：從「俯瞰世界」轉向「走進世界」，心境進一步沉澱。

## 敘事原則與寫作提醒
- 空間錨的建立必須合乎凡俗地理與考據邏輯，不要寫成玄幻陣法感應。

## 伏筆與下章銜接
