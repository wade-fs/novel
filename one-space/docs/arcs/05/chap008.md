# 第008章｜離開雲京

- **所屬篇章**：第一篇《焚書亂世》（chap001～chap008）
- **時間**：第一年秋末
- **地點**：雲京城外官道、南下渡口
- **主要人物**：顧淵、蔡琰、周伯
- **關鍵進度**：
  - 第一篇收束：顧淵失去原有力量，蔡琰失去父親與家園；兩人因共同承擔文化傳承建立最初信任。

## 核心劇情
蔡琰決定帶著史稿與殘存典籍南下。顧淵沒有承諾能保護她一生，只承諾會與她一起走完眼前這段路。兩人帶著周伯離開雲京，正式踏上亂世南渡之途。

## 場景節拍
1. **南下決意**：蔡琰權衡局勢，決定帶著《大胤史稿》、焦尾琴與殘存典籍南下江左，尋找能保存文脈之地。
2. **克制的承諾**：蔡琰詢問顧淵的去向，顧淵坦誠自己一無所有，不許下「護你一生」的空話，只承諾陪她走完眼前這段南下之路。
3. **揮別雲京**：三人雇車裝箱，在秋風冷雨中離開雲京，回望遠處仍未散盡的煙塵。
4. **踏上南途**：陳留道在前方展開，真正的亂世流亡才剛剛開始。

## 人物與關係重點
- **顧淵與蔡琰**：彼此平等、克制而真誠的起點——不是英雄救美後的依附，而是兩個失去一切的人結伴同行。

## 敘事原則與寫作提醒
- 本章作為第一篇收束，節奏由緊繃轉為蒼涼而堅定，為第二篇《孤舟南渡》鋪墊。
