# 第015章｜焦尾夜雨

- **所屬篇章**：第二篇《孤舟南渡》（chap009～chap016）
- **時間**：第二年春
- **地點**：瀾江舟中（或江畔雨夜）
- **主要人物**：顧淵、蔡琰
- **關鍵進度**：
  - 心念共鳴：進入第二階「情感共鳴」（能感受熟悉之人的情緒方向，但仍不知道完整想法與具體原因）。

## 核心劇情
夜雨中，蔡琰彈奏焦尾琴。顧淵的心念共鳴進入第二階「情感共鳴」，能感受到熟悉之人的情緒方向，卻仍不知道完整想法與具體原因。他感受到蔡琰外表平靜下的孤獨與悲傷，卻沒有試圖用能力探究她不願說出的往事。

## 場景節拍
1. **夜雨撫琴**：春雨打在船篷上，蔡琰取出焦尾琴，輕撥琴弦，曲調沉鬱克制，似追憶故人與故土。
2. **第二階覺醒**：顧淵靜聽琴音，心念共鳴自然過渡至第二階「情感共鳴」，不再只是模糊波動，而是能辨認出熟悉之人的情緒方向——平靜背後的深沉孤獨與哀傷。
3. **克制與尊重**：顧淵沒有追問、也沒有試圖用能力窺探她未曾言明的傷痛，只為她添了一盞溫茶，安靜陪她聽完一曲。
4. **琴音微暖**：察覺他的靜默陪伴，蔡琰指下尾音稍緩，緊繃多日的肩頭微微放鬆。

## 人物與關係重點
- **顧淵**：展現對他人隱私與內心邊界的尊重，確立「共鳴不是窺探」的倫理底線。

## 敘事原則與寫作提醒
- 嚴格遵守第二階限制：只能感受情緒方向，不能讀出具體記憶或台詞。

## 伏筆與下章銜接
- 經此一夜，兩人距離拉近，在接下來的航程中迎來更坦誠的交心。
