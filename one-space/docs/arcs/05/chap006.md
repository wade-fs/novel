# 第006章｜火中取書

- **所屬篇章**：第一篇《焚書亂世》（chap001～chap008）
- **時間**：第一年秋
- **地點**：白玉書院、蔡府火場
- **主要人物**：顧淵、蔡琰、蔡邕、周伯
- **關鍵進度**：
  - 典籍工程第一階段：**搶救**完成（救出《大胤史稿》、部分孤本及重要地方簿冊）。
  - 重大犧牲：蔡邕為保護史稿與掩護眾人撤離而遭殺害，確認身亡。

## 核心劇情
書院與蔡府接連起火。顧淵、蔡琰與周伯冒險搶救《大胤史稿》、部分孤本及重要地方簿冊，完成典籍工程的第一階段「搶救」。蔡邕為保護史稿與掩護眾人撤離而遭殺害，確認身亡。蔡琰失去父親，也失去原本熟悉的生活。

## 場景節拍
1. **火場搶書**：濃煙與烈火中，顧淵、蔡琰與周伯合力將《大胤史稿》、焦尾琴、部分孤本與地方簿冊搶運出屋。
2. **最後一別**：蔡邕在正廳阻攔追兵，與蔡琰隔火相望，以眼神示意她快走。
3. **蔡邕蒙難**：追兵痛下殺手，蔡邕倒在火光與殘簡之中，確認身亡。
4. **強行帶離**：蔡琰悲痛欲絕，顧淵與周伯護著她與書箱衝出火場，退入城外暗處。

## 人物與關係重點
- **蔡邕**：確認身亡，不可留復活懸念；其死亡成為貫穿全卷的精神重量。
- **蔡琰**：一夜之間失去父親與家園，卻仍緊抱史稿與焦尾琴。

## 敘事原則與寫作提醒
- 蔡邕之死不可工具化，要寫出真實的悲痛與不可逆的失去。
- 顧淵親眼見證凡人在刀兵下的無力，深化「失去力量」的切膚之痛。

## 伏筆與下章銜接
- 天明火熄，眾人在城外廢墟或破廟落腳，面對滿目瘡痍與殘存典籍。
