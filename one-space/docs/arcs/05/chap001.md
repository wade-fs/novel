# 第001章｜墜入文瀾

- **所屬篇章**：第一篇《焚書亂世》（chap001～chap008）
- **時間**：第一年秋
- **地點**：雲京郊外荒野 → 雲京城外
- **主要人物**：顧淵
- **關鍵進度**：
  - 能力狀態：修為、法寶、破綻真視、萬界樓系統全面失聯（絕靈封空）。
  - 心念共鳴：第一階「情緒感知」啟動（僅能感受情緒波動，不知道原因）。
  - 萬界樓本源：0（本源受損，完全失聯）。

## 核心劇情
顧淵在跨界返程途中遭遇空間亂流，意外墜入文瀾界的大胤王朝。此界絕靈封空，沒有任何修煉體系，他原有的修為、法寶與萬界樓系統全面失聯，只剩下一具凡人軀殼與微弱的跨界殘留——心念共鳴。他必須第一次依靠凡人的身體、觀察力與求生本能度過眼前危機。

## 場景節拍
1. **空間亂流墜界**：顧淵在返程途中被亂流拋入文瀾界，重重跌落荒野，察覺體內靈力盡失、萬界樓毫無回應。
2. **凡軀初試**：試圖感應天地靈氣與儲物空間皆告失敗，連傷口與飢寒都必須以凡人方式面對。
3. **情緒波動初現**：行至官道附近，遇見逃難流民與巡哨兵卒，隱約感受到周遭焦躁、恐懼與戒備的情緒波動，卻完全無法分辨背後原因。
4. **步入雲京**：顧淵收斂異樣，靠觀察衣著、口音與市井秩序混入雲京，展開凡俗亂世求生。

## 人物與關係重點
- **顧淵**：從「掌控萬界的樓主」瞬間跌回一無所有的凡人，開始面對「失去」的第一課。

## 敘事原則與寫作提醒
- 嚴格維持純凡俗亂世基調，無修仙、無武功、無系統面板特效。
- 心念共鳴第一階只能提供模糊的情緒波動，絕不能讓顧淵憑此直接推理出政治局勢或敵人身分。
