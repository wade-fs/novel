# 第020章｜言外之意

- **所屬篇章**：第三篇《江湖文瀾》（chap017～chap024）
- **時間**：第二年夏末
- **地點**：江左渡口夜巷／茶室
- **主要人物**：顧淵、上官婉兒
- **關鍵進度**：
  - 心念共鳴：正式進入第三階「心念感知」（能察覺言行與內心狀態可能不一致，但不知道對方隱瞞的具體內容）。

## 核心劇情
顧淵的心念共鳴進入第三階「心念感知」，能察覺言行與內心狀態可能不一致，但不知道對方隱瞞的具體內容。他與上官婉兒互相試探，兩人都意識到對方並非表面上那麼容易理解。上官婉兒開始欣賞顧淵的謹慎，但也警告他不要把感知當成判斷。

## 場景節拍
1. **私下會面**：顧淵與上官婉兒就典籍轉移路線與宮廷秘檔安全展開私下商談。
2. **第三階覺醒**：對話間，顧淵清晰察覺上官婉兒平靜言辭與內心戒備、猶豫之間的不一致，卻完全無法知道她究竟隱瞞了什麼具體內容。
3. **雙向試探**：顧淵點到為止，不強行追問；上官婉兒敏銳反擊，試探顧淵的來歷與真正意圖。
4. **關鍵警告**：上官婉兒欣賞顧淵的克制與謹慎，卻冷靜告誡他：「察覺別人有所隱瞞很容易，但若把察覺當成答案，遲早會害死自己與身邊的人。」

## 人物與關係重點
- **顧淵與上官婉兒**：建立最初的智性互信，為日後政治合作與情感線埋下伏筆。
