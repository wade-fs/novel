# 第024章｜紅箋來信

- **所屬篇章**：第三篇《江湖文瀾》（chap017～chap024）
- **時間**：第二年秋末
- **地點**：江左外圍渡口 → 江左腹地安全院落
- **主要人物**：顧淵、蔡琰、薛濤
- **關鍵進度**：
  - 人物登場：核心才女之一、江左女性詩社領袖**薛濤**正式登場（篇末破局埋線）。
  - 第三篇收束：顧淵學會心念感知也付出代價；薛濤的出現開啟女性文社群像新可能。

## 核心劇情
危難之際，薛濤以「薛濤箋」傳訊，暗中安排人手、住處與書箱轉移。薛濤是江左女性詩社的領袖，長期經營文人、商旅與地方女性之間的交流網絡。她沒有直接介入政治爭論，卻能在危機時刻提供實際援助。

## 場景節拍
1. **紅箋傳訊**：一紙清雅的松花紅箋（薛濤箋）送入蔡琰手中，信中不談高論，只給出精確的轉移路線、暗號與落腳處。
2. **暗度危局**：依信行事，沿途有女商、船娘、茶肆掌櫃等看似尋常的市井女性接力掩護，將書箱與兩人安穩送入江左腹地。
3. **初見薛濤**：在清幽小院中見到薛濤。她溫潤從容、通達人情，不問政治是非，只淡然道：「書要有人藏，人也要有處安身。」
4. **新局初開**：歷經雲京之火與渡口之痛，眾人終於在江左獲得一處真正能喘息與重建的落腳之地。

## 人物與關係重點
- **薛濤**：溫潤成熟、擅長人際網絡與實際協調，與上官婉兒的冷峻權謀形成鮮明對比。

## 敘事原則與寫作提醒
- 本章為第三篇收束，由悲痛低谷過渡到希望與沉澱，自然銜接第四篇《亂世流年》。
