# 第018章｜宮廷女史

- **所屬篇章**：第三篇《江湖文瀾》（chap017～chap024）
- **時間**：第二年夏
- **地點**：江左渡口城鎮、茶樓／私宅
- **主要人物**：顧淵、蔡琰、上官婉兒
- **關鍵進度**：
  - 人物登場：核心才女之一、大胤宮廷女史**上官婉兒**正式登場。

## 核心劇情
攜帶宮廷秘檔南逃的女史上官婉兒登場。她掌握大量朝廷內部檔案，知道權臣如何篡改詔令、操縱史官及處置反對者。她不輕易相信蔡琰，也不願讓宮廷秘檔落入任何一個士族集團手中。

## 場景節拍
1. **秘檔風聲**：江左各方勢力暗中尋找南逃的宮廷女史，謝清之亦有意招攬。
2. **初見上官婉兒**：顧淵與蔡琰在隱蔽處與上官婉兒會面；她衣飾樸素卻眉目冷峻，言辭犀利、戒心極重。
3. **宮廷真相**：上官婉兒點出權臣篡改詔令、清洗史官的內幕，恰好與蔡邕《大胤史稿》中的數處留白互相印證。
4. **互相防備**：上官婉兒拒絕交出秘檔，直言她既不信江左士族，也尚未決定是否信任蔡琰。

## 人物與關係重點
- **上官婉兒**：理性、冷靜、深諳政治生存法則，與蔡琰的史家理想形成鮮明對照。

## 敘事原則與寫作提醒
- 保持上官婉兒的獨立立場與政治判斷力，不要讓她一見顧淵就心生好感。

## 伏筆與下章銜接
- 謝清之得知上官婉兒現身，三方圍繞史料與政治後果的清議即將展開。
