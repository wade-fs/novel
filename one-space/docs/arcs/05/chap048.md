# 第048章｜素琴歸途

- **所屬篇章**：第六篇《素琴歸途》（chap041～chap048）
- **時間**：第四年冬末
- **地點**：瀾江渡口 → 跨界通道 → 萬界風月樓
- **主要人物**：顧淵、蔡琰
- **關鍵進度**：
  - 全卷收束：蔡琰留守江左完成志業，顧淵帶著四載記憶返回萬界樓，銜接第六卷《諸女相逢・萬界情緣》。
  - 通道限制：跨界通道雖重新接通，仍受文瀾界絕靈封空與萬界樓現有能力限制，不能任意往返（為日後重返「5+N」埋下伏筆）。

## 核心劇情
蔡琰選擇留在江左，完成《大胤史稿》、書院與典籍傳承的志業。顧淵尊重她的選擇，不要求她放棄人生陪自己離開。兩人留下信物與重返文瀾界的約定。跨界通道重新接通，但仍受限制不能任意往返。顧淵帶著四載記憶與對凡人生活的理解，重新返回萬界樓，銜接第六卷《諸女相逢・萬界情緣》。

## 場景節拍
1. **渡口送別**：冬雪微晴，蔡琰懷抱焦尾琴送顧淵至瀾江渡口。她溫和而堅定地選擇留在江左，完成《大胤史稿》與書院傳承。
2. **信物與約定**：顧淵尊重她的選擇，兩人交換信物，約定待他日通道穩固、文脈初成，必再重返文瀾界。
3. **素琴送歸**：蔡琰於渡口輕撫焦尾琴，琴聲清越如水。跨界通道在微光中緩緩開啟——雖受絕靈封空與現有能力限制尚無法任意往返，卻已足夠送顧淵歸樓。
4. **重返萬界樓**：顧淵帶著四載春秋的凡塵記憶，以及五段仍將繼續延伸的人生，步入光門，重返萬界風月樓，銜接第六卷《諸女相逢・萬界情緣》。

## 人物與關係重點
- **全卷主旨收束**：顧淵帶走的不是五位女性，而是五段仍將繼續延伸的人生，以及從「掌控萬界」到「理解凡人」的真正成長。
