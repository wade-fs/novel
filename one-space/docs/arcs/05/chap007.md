# 第007章｜廢墟清點

- **所屬篇章**：第一篇《焚書亂世》（chap001～chap008）
- **時間**：第一年秋
- **地點**：雲京城外廢墟／荒寺
- **主要人物**：顧淵、蔡琰、周伯
- **關鍵進度**：
  - 典籍現狀：大量藏書焚毀，四千卷計畫僅存部分核心資料，完成初步分類與封存。

## 核心劇情
蔡琰強忍喪父之痛，清點搶救出的殘存典籍。她發現大量珍貴藏書已經焚毀，原本四千卷的典籍計畫只剩部分核心資料。顧淵協助分類、編號與封存，讓她不至於在悲痛中失去最後的秩序。

## 場景節拍
1. **殘灰與餘溫**：蔡琰回到或遠望已成焦土的書院方向，壓下情緒，開始逐箱清點搶救出的典籍。
2. **清點之痛**：焦痕斑斑的書卷中，許多孤本已成灰燼，四千卷藏書僅存核心殘卷與《大胤史稿》。
3. **重建秩序**：顧淵沒有說空洞的安慰，而是默默拿來紙筆、麻繩與油布，陪她一卷卷分類、編號、防潮封存。
4. **無聲支撐**：周伯備好熱水與乾糧，三人在殘破屋簷下度過喪父後的第一個夜晚。

## 人物與關係重點
- **顧淵與蔡琰**：兩人最初的信任不是來自甜言蜜語，而是來自危難中共同維持秩序的默契。

## 敘事原則與寫作提醒
- 用克制、細膩的筆觸寫悲傷（例如蔡琰手指沾滿灰燼卻仍工整寫下編號），避免過度煽情。

## 伏筆與下章銜接
- 雲京已不可留，官兵仍在搜捕餘黨，蔡琰必須決定接下來的去向。
