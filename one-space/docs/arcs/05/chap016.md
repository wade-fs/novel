# 第016章｜舟中相知

- **所屬篇章**：第二篇《孤舟南渡》（chap009～chap016）
- **時間**：第二年春末
- **地點**：瀾江客船（近江左渡口）
- **主要人物**：顧淵、蔡琰、周伯
- **關鍵進度**：
  - 第二篇收束：顧淵從獨自掌控轉向相互依靠，蔡琰從單獨承擔轉向願意信任他人；兩人情愫暗生但未急於定義關係。

## 核心劇情
兩人在長途南渡中逐漸熟悉彼此的習慣與性格。蔡琰開始願意向顧淵談論父親、典籍與自己的未來；顧淵也第一次向她承認，自己曾經擁有遠超凡人的力量，如今卻不知道何時才能恢復。兩人情愫暗生，但尚未急於定義關係。

## 場景節拍
1. **舟中日常**：數月同行，兩人已熟悉彼此作息、茶水濃淡與校書習慣，相處自然溫和。
2. **蔡琰敞開心扉**：蔡琰第一次平靜談起父親蔡邕生前趣事與自己對《大胤史稿》的長遠打算。
3. **顧淵坦白來歷**：顧淵沒有全盤托出萬界樓細節，卻真誠承認自己曾擁有遠超凡人的力量，如今一無所有，也不知道何時才能找回歸途。
4. **不言而喻的默契**：蔡琰沒有追問奇異之處，只道眼前路長，彼此同行便好。遠處江左渡口燈火漸近。

## 人物與關係重點
- **顧淵與蔡琰**：情感自然沉澱，克制而深厚，不急於告白或親密。

## 敘事原則與寫作提醒
- 本章為第二篇收束，氛圍溫潤含蓄，與第三篇即將到來的政治風波與悲劇形成對比。
