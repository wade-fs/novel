# 第036章｜婉兒之心

- **所屬篇章**：第五篇《朔漠風雲》（chap033～chap040）
- **時間**：第四年秋初
- **地點**：江左秘檔居所
- **主要人物**：顧淵、上官婉兒
- **關鍵進度**：
  - 情感與雙修：顧淵與上官婉兒在充分理解心意與關係邊界後，自願建立親密關係。
  - **萬界樓本源修復**：**+25**（本卷累計：**80**）——恢復部分跨界訊號辨識能力。

## 核心劇情
上官婉兒協助顧淵識破士族妥協派的真正盤算。兩人在長期合作中逐漸建立信任。上官婉兒不再只是冷靜的宮廷女史，也願意讓顧淵看見自己長年隱藏的疲憊與不安。在充分理解彼此的心意與關係邊界後，兩人自願建立親密關係。

## 場景節拍
1. **識破盤算**：上官婉兒精準點出妥協派哪幾家與北岸暗通款曲，以及他們打算在談判前夜動手的政治邏輯。
2. **卸下鎧甲**：燈下整理完密報，長年活在宮廷傾軋與戒備中的上官婉兒難得流露疲憊，坦言自己早已習慣不相信任何人，卻在顧淵身上看見難得的克制與尊重。
3. **理性與深情**：兩人坦誠確認彼此心意與關係邊界——不彼此束縛，卻願在此刻真實相擁。在完全自願的前提下，兩人共度良宵。
4. **本源反哺**：陰陽共鳴注入枯竭大陣（+25，本卷累計 80），萬界樓恢復部分跨界訊號辨識能力。

## 人物與關係重點
- **上官婉兒**：從冷峻防備到卸下心防的政治知己，情感表達克制而深沉。

## 敘事原則與寫作提醒
- 突出「強強互信、卸下防備」的張力，避免將上官婉兒寫成依附男主的小女人。
