# 第八卷 ch002｜諾瓦星

> 所屬：第一篇｜星門之外（卷內 ch001–006）

- **出場人物**：顧淵、晨弧城市民、夜市麵攤老闆**老伍**。
- **場景**：首都**晨弧城（Arclight）**外環舊港區、廢棄航運塔、軌道電梯遠景、夜市。
- **核心情節**：
   1. 顧淵落在舊港區一座廢棄航運塔頂；真元如沉入深水，飛行與大範圍神識幾乎失效，連御物都吃力。
   2. 城市全景：直入雲層的軌道電梯、懸浮交通流、全息廣告，人類、仿生人與複製人並肩通勤，彼此早已習以為常。
   3. 沒有身分晶片寸步難行：無法付款、無法搭車，還被自動治安無人機標記為「未登錄個體」。
   4. 夜市麵攤老伍見他餓著，請他一碗合成麵（真正的小麥很貴），閒聊中帶出諾瓦星的物價、重力球賽、「記憶劇場」等日常娛樂與飲食文化。
   5. 顧淵以心念共鳴感知城市情緒——人群中有些清晰的喜悅與疲憊，來自他無法分辨是否為人類的存在。
- **生命層次**：1. 生存——在一個沒有身分就無法存在的社會裡，「活著」需要什麼？
- **爽點與情感落點**：不靠力量，靠一碗麵與一份人情認識世界；諾瓦星不只有科技，也有煙火氣。
- **伏筆**：
   - 治安無人機的「未登錄個體」標記。
   - 麵攤旁仿生人修理鋪的手寫招牌「繩結修理（Knot's）」。
- **萬界樓回饋**：記錄諾瓦星環境法則（靈氣稀薄、電磁場密集、超凡力量受限）。修復度不變。
