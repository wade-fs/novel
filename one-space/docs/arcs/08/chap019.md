# 第八卷 ch019｜自己的選擇

> 所屬：第三篇｜複製人生（卷內 ch014–020）

- **出場人物**：薇薇安、馬庫斯、伊芙、基金會董事會、顧淵、雷婭。
- **場景**：凡斯生命基金會董事會議室、伊芙的公寓、舊港區公寓。
- **核心情節**：
   1. 薇薇安親自到董事會宣告解除培育合約：拒絕局長職位、拒絕生育配對方案；依《培育合約法》，她將失去基金會資助與住所。
   2. 董事會以「違約將公開妳的樣本缺陷」施壓。薇薇安：「那就公開吧。我的身體不是祕密，也不是你們的。」
   3. 伊芙私下來找她，坦言羨慕卻不想改變；兩人第一次以姊妹、而非樣本的身分相擁——互相尊重不同的選擇。
   4. 最終表決時，馬庫斯投下反對施壓的一票，並以私人名義撤除計畫中的生育配對條款；他終於叫她「薇薇安」。
   5. 她搬出基金會宿舍，暫住顧淵與雷婭的公寓。雷婭表面不爽，實際上替她整理好房間並調好溫度：「生物體的舒適溫度區間是我查的，不代表我在乎。」
- **生命層次**：3. 自由與自主。
- **爽點與情感落點**：**薇薇安的獨立劇情高潮**（顧淵只在場，不出手）；雷婭口是心非的可愛醋意。
- **伏筆**：
   - 加速代謝基因仍在體內。
   - 三人同居生活（`ch021`、`ch041`）。
- **萬界樓回饋**：無。
