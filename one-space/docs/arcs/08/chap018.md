# 第八卷 ch018｜被安排的人生

> 所屬：第三篇｜複製人生（卷內 ch014–020）

- **出場人物**：薇薇安、雷婭、顧淵、羅莎醫生、凡斯生命基金會營運總監。
- **場景**：伊巴拉診所、基金會資料庫（合法調閱）、穹頂夜景下的屋頂菜園。
- **核心情節**：
   1. 薇薇安依複製人法定的「自身培育檔案調閱權」申請完整檔案；雷婭以米拉案練就的法律檢索能力協助——**雷婭與薇薇安第一次合作**，理性與感性的初次摩擦與彼此欣賞。
   2. 計畫全貌揭露：第七號的人生被預定為接任行星生態調節局局長、繼承凡斯專利，並須在三十歲前完成「生育配對方案」以延續優化基因；背後牽涉基金會與生態企業的專利利益。
   3. 更深一層：為控制複製人，所有繆思樣本皆植入加速代謝基因，**設計壽命約四十五年**（薇薇安現年二十六歲）。
   4. 薇薇安沒有崩潰。她坐在屋頂菜園說，有限的人生她可以接受——「我不能接受的，是連有限的時間都被別人安排好了。」
   5. 顧淵沒有提出任何以萬界樓救她的方案，只陪她坐到天亮。
- **生命層次**：2. 繁衍與延續；3. 自由與自主；4. 死亡與有限性——三層交織的重擊。
- **爽點與情感落點**：顧淵的克制即是尊重；雷婭與薇薇安「不同但互補」的初次並肩。
- **寫作紅線**：**不得將雙修寫成延壽的交換條件**；顧淵不以萬界樓能力作為說服或誘因。
- **伏筆**：壽命上限（`ch020` 意外緩解，非交易）。
- **萬界樓回饋**：無。
