# 第八卷 ch010｜情感測試

> 所屬：第二篇｜機械之心（卷內 ch007–013）

- **出場人物**：顧淵、雷婭、老伍。
- **場景**：公寓、夜市、重力球場、記憶劇場。
- **核心情節**：
   1. 雷婭擬定〈對顧淵之情緒反應研究計畫書〉，條列 37 項測試：約會、共餐、身體距離、嫉妒刺激……
   2. 顧淵笑著配合，卻把每一項測試都變成真正的生活：夜市吃麵、看重力球賽、到記憶劇場體驗陌生人的初戀。
   3. 雷婭發現數據越收越不準——她在劇場裡為陌生人的記憶落淚，閾值卻把淚水關掉了。
   4. 老伍調侃：「你們這叫談戀愛，不叫做實驗。」雷婭認真反駁了整整三分鐘。
   5. 夜裡她刪除計畫書第 37 項〈確認對象是否具有不可替代性〉——因為她害怕答案。
- **生命層次**：3. 自由與自主（被管理的情緒，還是自己的情緒嗎？）。
- **爽點與情感落點**：輕快的戀愛喜劇節奏；好勝固執的雷婭把戀愛當課題，卻開始失控。
- **伏筆**：閾值觸發紀錄急遽增加（`ch011` 爆發）。
- **萬界樓回饋**：無。
