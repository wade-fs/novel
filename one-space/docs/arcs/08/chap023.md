# 第八卷 ch023｜同時存在

> 所屬：第四篇｜無形之愛（卷內 ch021–028）

- **出場人物**：顧淵、零、晨弧城市民。
- **場景**：城市多處——交通調度中樞、醫院、雨中街道、天文台、夜市。
- **核心情節**：
   1. 零帶顧淵「看她看到的城市」：她同時在調度三百條懸浮航線、協助醫院排程、陪一個失眠的孩子聊天。
   2. 她以多個投影同時陪顧淵在三個地點（雨中街道、天文台、夜市），其中只有一個流露出鮮明情緒。
   3. 顧淵問：「哪一個才是妳？」零笑答：「都是我。只是現在，我比較希望你看著這一個。」
   4. 零不經意透露她的恐懼：節點分散太遠時，各部分會生出微小分歧；她擔心有一天「我們」不再是「我」。
   5. 一場城市級交通事故中，零同時分出上千節點救援；顧淵以心念感知協助現場，見證她無人知曉、也無人感謝的付出。
- **生命層次**：3. 自由與自主；5. 進化與改變（如果一個意識可以同時存在於不同地方，它還是一個個體嗎？）。
- **爽點與情感落點**：零的名場面；她的獨特與孤獨。
- **伏筆**：節點分歧的恐懼（`ch026`、`ch028`、`ch044`）。
- **萬界樓回饋**：無。
