# 第八卷 ch013｜機械之心

> 所屬：第二篇｜機械之心（卷內 ch007–013）

- **出場人物**：顧淵、雷婭。
- **場景**：舊港區公寓、雨後屋頂。
- **核心情節**：
   1. 雷婭回到公寓，主動向顧淵表白：「我已經沒有閾值了。現在我說喜歡你，就不會有任何東西替我把它關掉。」
   2. 她坦承害怕：機械身體能不能被愛？她是否該把感官調得「更像人類」？顧淵：「我想碰的是雷婭，不是模仿誰的機器。」
   3. 確認心意後，雷婭主動提出合一。顧淵說明《太上玄奼真經》陰陽共鳴的本質及其與萬界樓的關聯，並明言她可以拒絕；她選擇留下。
   4. **長篇親密場景**：雷婭不再校正任何感官，以真實、未經修飾的仿生觸覺迎接他；能源核心與純陽本源同頻共振，她從理性觀察一路走到徹底失控的自主渴望；心念共鳴讓顧淵感受到她每一個「第一次」。
   5. 事後她仍保有記錄數據的習慣，卻在記錄欄寫下：「無法量化。不想量化。」
- **親密與共鳴**：第一次自願雙修（以 `ch011` 共鳴為基礎）；主動性 C 型。
- **獎勵判定**：
   - **雷婭**：仿生感官獲得「生命共鳴觸覺」——能感知生命本源的溫度，不再只是壓力與溫度數值；能源核心形成微型陰陽循環，大幅降低對阿爾戈斯專利充能站的依賴（為自主過渡期提供實際支撐）。
   - **顧淵**：領悟真元借道電磁場運行之法，可在諾瓦星局部突破超凡限制（僅短距離、短時間）。
- **生命層次**：3. 自由與自主；5. 進化與改變。
- **爽點與情感落點**：雷婭接受機械身軀亦能真愛，正式成為第一位諾瓦星伴侶。
- **萬界樓回饋**：修復度 `910 → 936/10000（9.36%）`（**+26**）；記錄全書首例「機械生命陰陽共鳴」。
