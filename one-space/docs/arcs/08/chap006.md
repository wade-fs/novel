# 第八卷 ch006｜暫居諾瓦

> 所屬：第一篇｜星門之外（卷內 ch001–006）

- **出場人物**：顧淵、雷婭、移民署人類職員、（幕後）零。
- **場景**：晨弧城移民署、舊港區出租公寓。
- **核心情節**：
   1. 顧淵依罕用的「星際漂流者臨時身分條款」（第十三條）申請合法身分，正常排程需三個月。
   2. 他的案件被系統「意外」標記，轉由一位人類職員親自審理並當日核准——職員自己也說不清案件為何會跳到她桌上。
   3. 雷婭在法律上仍是公司財產，無法簽約租屋；顧淵以新身分承租舊港區小公寓，雷婭以「持續研究顧淵」為由暫時同行，並堅持用修理零件打工賺的錢付一半房租。
   4. 阿爾戈斯正式向法院遞交回收申請，聽證日期定在三週後；人格最佳化因法律程序暫停。
   5. 夜裡雷婭站在陽台觀察城市，第一次說出「我」，而不是「本機」。
- **生命層次**：1. 生存——合法存在的條件；3. 自由與自主。
- **爽點與情感落點**：從同行到同居的過渡；兩人的生活感開始建立。
- **伏筆**：
   - 移民案被「優先」（`ch022` 揭曉為零——她只是讓人類審理員看見這件案子，不曾偽造任何文件）。
   - 三週後的回收聽證（`ch012`）。
- **萬界樓回饋**：顧淵取得合法身分，臨時落點轉為穩定單向錨點。修復度不變。
