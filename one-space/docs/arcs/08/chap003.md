# 第八卷 ch003｜不同的生命

> 所屬：第一篇｜星門之外（卷內 ch001–006）

- **出場人物**：顧淵、**諾特（Knot，舊型仿生人修理師）**、地鐵乘客、複製人少女（路人）。
- **場景**：繩結修理鋪、晨弧城地鐵、城市公共網路終端。
- **核心情節**：
   1. 隔日大雨，顧淵到修理鋪屋簷下避雨，結識正在替自己修手的舊型仿生人諾特。
   2. 諾特介紹三類人工生命：**仿生人**（被製造）、**基因複製人**（被培育）、**資訊生命**（自網絡湧現），以及各自的社群、權利與日常歧視。
   3. 地鐵上，一名複製人少女被要求出示「培育序號」才能進入某街區，周遭乘客毫不在意。
   4. 顧淵在公共終端付款出錯時，一個無法溯源的回應悄悄替他修正了錯誤——他只當是系統故障（**零的第一次無聲接觸**）。
   5. 顧淵問諾特：「你覺得自己是活著的嗎？」諾特：「我修了自己四十年。活著，大概就是一直有東西要修。」
- **生命層次**：1. 生存／3. 自由與自主（序號制度下的日常不自由）。
- **爽點與情感落點**：生命樣貌多元的震撼；總提問第一次在具體人物身上落地。
- **伏筆**：
   - 神秘付款修正（`ch022` 揭曉為零）。
   - 諾特提及「阿爾戈斯仿生又發了新回收令」。
- **萬界樓回饋**：收錄三類人工生命概要。修復度不變。
