# 第八卷 ch017｜不是替代品

> 所屬：第三篇｜複製人生（卷內 ch014–020）

- **出場人物**：薇薇安、**馬庫斯・凡斯（Marcus Vance，伊蓮娜之子、凡斯生命基金會主席）**、顧淵。
- **場景**：凡斯家宅、伊蓮娜舊書房。
- **核心情節**：
   1. 馬庫斯邀薇薇安「回家」吃晚餐——他每年都這麼做，讓她坐在母親生前的位子上。
   2. 薇薇安第一次帶顧淵同行。馬庫斯對外人充滿戒備，卻在顧淵沉默的傾聽下吐露：母親早逝，他用三十年資助計畫，只想再聽母親說一句話。
   3. 晚餐中馬庫斯不自覺叫了她一聲「媽」，空氣凝結。薇薇安溫柔而清楚地說：「我是薇薇安。我可以陪你懷念她，但我不能成為她。」
   4. 顧淵在書房中以**深層共鳴**感受到馬庫斯的喪母創傷，明白他不是惡人，只是困在一場遲遲無法完成的告別裡。
   5. 回程路上薇薇安哭了一場，第一次靠在顧淵肩上。
- **生命層次**：4. 死亡與有限性（告別）；2. 繁衍與延續。
- **爽點與情感落點**：薇薇安溫柔中的堅定；兩人關係從信任走向依戀。
- **伏筆**：基金會帳目中出現「生育配對方案」字樣（`ch018`）。
- **萬界樓回饋**：無。
