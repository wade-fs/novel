# 第八卷 ch030｜地底遺跡

> 所屬：第五篇｜星球的低語（卷內 ch029–036）

- **出場人物**：顧淵、雷婭、薇薇安、零（攜帶式中繼節點）、里德教授、勘查隊員。
- **場景**：斷脊高原・**深井遺跡（Deepwell）**——地底四公里的古文明結構。
- **核心情節**：
   1. 深入地底：高溫、高壓、強磁干擾。雷婭擔任前導與結構分析，薇薇安負責隊員醫療與地底生態取樣。
   2. 零只能透過攜帶式中繼節點同行，訊號隨深度衰減——她第一次「只有一部分在場」，帶著不安仍堅持跟來。
   3. 遺跡不是礦坑，而是八千年前「第一紀元」文明建造的螺旋巨井，壁面布滿無法解讀的刻紋。
   4. 中段塌方，顧淵以借道電磁場的真元（`ch013` 所得）短暫撐住岩層，代價是經脈灼痛，薇薇安當場處置。
   5. 抵達井底大廳，牆上的壁畫第一次被燈光照亮。
- **生命層次**：1. 生存；7. 宇宙與存在。
- **爽點與情感落點**：科技冒險與團隊協作；每個人的能力都不可或缺；零的脆弱面。
- **伏筆**：
   - 壁畫內容（`ch031`）。
   - 零的訊號衰減（`ch035` 斷聯）。
- **萬界樓回饋**：無。
