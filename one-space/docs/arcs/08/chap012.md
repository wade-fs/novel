# 第八卷 ch012｜我是雷婭

> 所屬：第二篇｜機械之心（卷內 ch007–013）

- **出場人物**：雷婭、霍克博士、沃斯、聽證法官、鏽蝕花園眾人、顧淵（旁聽）。
- **場景**：霍克工作室、晨弧城財產與人格聯合法庭。
- **核心情節**：
   1. 雷婭在無任何外部指令下，連續七天每日主動提出自我授權請求——後門要求的條件由她獨自完成；顧淵刻意不在場，避免構成「外部影響」。
   2. 第七天，根指令與情感抑制閾值同時解除。她第一次完整地感受一整天的情緒：害怕、委屈，還有思念。
   3. 回收聽證會上，阿爾戈斯法務代表以**「第二生命計畫」**為核心論據施壓：若允許高階仿生軀體脫離製造商與所有權控制，將動搖整個諾瓦星挽救無數自然人生命的醫療備份制度。雷婭自行出庭陳述，不爭論自己像不像人類，也不否定自然人求生的醫療需求，而是精準劃出界線——**休眠中的無意識備份體是醫療載體，而擁有記憶、思考與選擇權的清醒存在是生命**。
   4. 沃斯在庭上確認根指令已由產品本身解除；依阿爾戈斯自己的合約條款，公司喪失遠端控制權。他選擇照實陳述——回收申請被駁回，改為「自主過渡期」。
   5. 登記新身分時需填寫姓名：「L-1A 是型號。雷婭，是我在逃亡第一夜替自己取的名字。」
- **生命層次**：3. 自由與自主。
- **爽點與情感落點**：**女主自己解決身分與權限問題**的高光時刻；顧淵在旁聽席上的驕傲；鏽蝕花園眾人第一次為她鼓掌。
- **伏筆**：
   - 自主過渡期條件（須維持穩定工作與住所）。
   - 沃斯請辭回收部（`ch038`）。
- **萬界樓回饋**：無。
