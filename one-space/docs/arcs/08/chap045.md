# 第八卷 ch045｜暫別

> 所屬：第六篇｜各自的生命（卷內 ch037–046）

- **出場人物**：顧淵、雷婭、薇薇安、零、老伍、諾特。
- **場景**：舊港區公寓、溫室診所、自主認證協助中心、夜市。
- **核心情節**：
   1. 顧淵坦白離開的時候到了：萬界樓還有許多世界與責任在等他。
   2. 三女各自以自己的方式確認留下——不是犧牲，而是選擇；沒有人要求對方放棄自己的人生。
   3. **各自的告別夜**（自願、溫柔、帶著不捨的再次合一）：雷婭不錄任何數據，只說「我要用不會被覆寫的地方記住你」；薇薇安在溫室裡與他談了一整夜的未來；零在識海微界讓他看遍她眼中的諾瓦星四季。
   4. 最後一頓晚餐在老伍的麵攤，四人加上整條街的熟人。
   5. 雷婭、薇薇安、零第一次三人單獨聚會（顧淵不在場），約定彼此照應：「他回來的時候，我們要讓他看到我們都過得很好。」
- **親密與共鳴**：告別前夜的再次合一（重情感、輕數值）。
- **獎勵判定（動態，小幅）**：
   - **雷婭**：能源循環完全自主（徹底擺脫企業專利充能協議限制），自主過渡期穩步邁向獨立。
   - **薇薇安**：獲得以植物萃取調和生命力的新療法靈感，用於溫室診所。
   - **零**：連續自我在遠距離節點也保持穩定。
   - **顧淵**：心念共鳴可隔著星門微弱感知三人安好。
- **生命層次**：3. 自由與自主；4. 死亡與有限性（有限的相聚才更珍貴）。
- **爽點與情感落點**：溫柔的暫別；三女結盟，彼此成為家人。
- **萬界樓回饋**：修復度 `1003 → 1012/10000（10.12%）`（雷婭 +4、薇薇安 +3、零 +2，共 **+9**）。
