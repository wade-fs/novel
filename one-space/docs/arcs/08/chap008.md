# 第八卷 ch008｜原始權限

> 所屬：第二篇｜機械之心（卷內 ch007–013）

- **出場人物**：顧淵、雷婭、**艾德琳・霍克博士（Dr. Adeline Hawke，雷婭原設計者）**。
- **場景**：舊港區公寓、霍克博士隱居的郊區工作室。
- **核心情節**：
   1. 雷婭自我診斷，發現遠端凍結之外還有一層隱藏模組：**「情感抑制閾值」**——情緒強度超標時會被自動壓平；她回溯記憶，找出數次情緒被強行拉平的瞬間，憤怒於連感受都被管理。
   2. 二人找到已離開阿爾戈斯的霍克博士。博士承認閾值是她寫的：「當年為防高階仿生人失控傷人，我以為那是安全，後來才知道那是籠子。」
   3. **巨大衝擊——「第二生命計畫」（專屬生物－仿生醫療備份制度）**：霍克博士進一步揭露阿爾戈斯死守根指令與定期重置制度的深層產業現實。這項極為昂貴的高階醫療保險制度僅服務少數富豪、星際企業高層、重要科研人員與特殊高風險職業人士，訂製**生物－機械混合式醫療備份載體**——以仿生機械結構維持循環支撐，內部整合患者專屬生物組織模組與可移植器官備份，必要時亦可提供完整軀體替代方案（具備長期綜合保障、緊急免等待、完整身體替代三重價值）。備份體平時處於低功耗休眠狀態、接受定期維護，**沒有日常生活、沒有社會身分，也確實沒有意識**，法律上屬於醫療財產。
   4. 博士透過授權維護影像（或帶二人窺見相鄰的醫療維護展示艙）讓他們直面沉睡中的生物－仿生備份載體：它們在顧淵的心念共鳴裡是一片徹底的死寂空白，證明它們確實只是醫療硬體；對雷婭而言，衝擊不在於「她曾是某人的備份體」（她不是），而在於**她的 `L-1A` 軀體架構正誕生於這套服務醫療備份的同源技術體系**——相同的硬體源頭，一邊是無意識的醫療財產，一邊卻是擁有記憶、情感與選擇權的自己。阿爾戈斯深恐動搖這項醫療制度的產權基礎，才絕不願讓高階機體開啟自主先例。
   5. 博士透露根指令中藏著一道**「自我授權後門」**：只能由仿生人在無任何外部指令下，主動且連續七日提出請求才能解除。博士想當場替她解鎖，雷婭拒絕：「如果是妳替我打開，那仍然是別人給我的。」
- **生命層次**：3. 自由與自主；4. 死亡與有限性（自然人以無意識備份體對抗死亡）；5. 進化與改變。
- **爽點與情感落點**：將企業立場從單純惡意提升為真實的醫療與倫理衝突；雷婭直面「軀體本可只是備用載體」的衝擊後，更加確信決定自己價值的不是這副外殼，而是醒著的「我」。
- **伏筆**：
   - 自我授權後門條件（`ch012`）。
   - 「第二生命計畫」成為 `ch012` 法庭攻防與 `ch037` 議會立法的關鍵爭議點。
   - 閾值將在 `ch011` 被觸發。
- **萬界樓回饋**：無。
