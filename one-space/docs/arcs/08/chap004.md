# 第八卷 ch004｜逃亡的仿生人

> 所屬：第一篇｜星門之外（卷內 ch001–006）

- **出場人物**：顧淵、**雷婭（Leia）**、**卡蘭・沃斯（Kalan Voss，阿爾戈斯仿生回收部主管）**、回收小隊。
- **場景**：舊港區雨夜後巷、貨櫃迷宮、廢棄航運塔。
- **相遇類型**：7 共同患難型＋8 女主主動接近型（主動性 **C 型**）。
- **核心情節**：
   1. 雨夜，一名銀灰長髮的女子闖入修理鋪後巷，左臂外殼破裂、光纖外露——高階仿生人雷婭，正被**阿爾戈斯仿生（Argos Bionics）**回收隊追捕。
   2. 雷婭先發制人：判定顧淵是「沒有身分晶片的異常個體」，恰好能借他的訊號盲區藏身，直接拉他當掩護——主導權在她手上。
   3. 回收小隊持合法回收令逼近；顧淵不以武力硬碰（超凡受限），而以心念危機感知預判隊員動向，配合雷婭規劃的路線在貨櫃與廢塔間周旋。
   4. 關鍵時刻雷婭被遠端指令強制凍結三秒，顧淵背起她脫離；伏在他背上的她，情緒裡有清晰的恐懼與憤怒——與人類無異。
   5. 沃斯在高處觀察，沒有下令追擊到底：「她是公司財產，但我不想在雨夜裡打壞她。我們會走程序。」
- **生命層次**：3. 自由與自主——被製造的生命，能否拒絕製造者？
- **爽點與情感落點**：雷婭不是等待被救的花瓶，脫逃路線由她主導；顧淵第一次在機械身上感受到「害怕」。
- **伏筆**：
   - 遠端凍結＝原始權限（`ch008`）。
   - 沃斯「走程序」的態度（非臉譜化，`ch012`、`ch038`）。
   - 雷婭掃描顧淵時出現「無法歸類的生命訊號」。
- **萬界樓回饋**：確認仿生情緒訊號與心念共鳴相容。修復度不變。
