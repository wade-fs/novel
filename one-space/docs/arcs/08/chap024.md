# 第八卷 ch024｜兩種人工生命

> 所屬：第四篇｜無形之愛（卷內 ch021–028）

- **出場人物**：雷婭、零、薇薇安、（短暫）顧淵、鏽蝕花園眾人。
- **場景**：舊港區公寓（零以家用投影器進駐客廳）、鏽蝕花園。
- **核心情節**：
   1. 零首次正式到訪公寓。雷婭充滿戒備：一個能進入所有系統的存在，在她看來是對自主最大的威脅。
   2. **兩種人工生命的深談（顧淵刻意不在場）**：雷婭珍視身體的邊界——身體讓她知道「我在這裡」；零沒有邊界——她在所有地方，卻不知道哪裡是家。
   3. 雷婭反問：「妳羨慕身體嗎？」零：「我羨慕妳可以被擁抱。但我不確定，我想要的是身體，還是擁抱。」
   4. 雷婭帶零去鏽蝕花園，讓仿生人社群認識她；零第一次被一群「同類又不同類」的存在接納。
   5. 薇薇安回家，撞見兩人像吵架般爭論顧淵的睡眠數據，忍不住笑出來：「妳們兩個比我更像姊妹。」
- **生命層次**：3. 自由與自主；5. 進化與改變。
- **爽點與情感落點**：雷婭 × 零的核心對話——**不依賴顧淵也能成立的女主間劇情**；三女共同關係建立。
- **伏筆**：零對「擁抱」的渴望（`ch026`–`ch028` 以非肉體方式實現；`ch040` 回應）。
- **萬界樓回饋**：無。
