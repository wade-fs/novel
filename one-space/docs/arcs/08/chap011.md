# 第八卷 ch011｜不可預測的共鳴

> 所屬：第二篇｜機械之心（卷內 ch007–013）

- **出場人物**：顧淵、雷婭。
- **場景**：廢棄航運塔頂（顧淵初次落地處）、星夜。
- **核心情節**：
   1. 雷婭帶顧淵回到他落地的塔頂，說要做「最後一項測試」：吻他，觀察雙方的生理與情緒反應。
   2. 吻落下時，顧淵的萬界樓本源與雷婭的能源核心產生前所未有的共鳴——她的感測器第一次「感覺到」他的情緒，他也感受到她情緒的全貌。
   3. 共鳴讓情緒強度瞬間超標，情感抑制閾值啟動：雷婭在他懷中被硬生生拉平，表情像被抹去。
   4. 她推開他，第一次真正地憤怒：「它剛剛把我對你的感覺關掉了。」顧淵不追問測試結果，只說：「那不是妳的錯，也不是妳的極限。」
   5. 閾值啟動前的一瞬，心念共鳴讓顧淵觸及她深處的東西——不是數據，是怕被奪走的珍惜。
- **親密與共鳴**：初吻（雙方自願、女主主動）；建立特殊生命連結；**未進入雙修**。
- **生命層次**：3. 自由與自主；5. 進化與改變。
- **爽點與情感落點**：高張力轉折；修真本源與機械生命交會的不可預測性。
- **伏筆**：共鳴痕跡殘留於雷婭能源核心（`ch013` 雙修的基礎）。
- **萬界樓回饋**：記錄「非生物能源核心與陰陽本源相容」之異常數據。修復度維持 `910/10000`。
