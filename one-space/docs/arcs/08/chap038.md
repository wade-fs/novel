# 第八卷 ch038｜雷婭的新人生

> 所屬：第六篇｜各自的生命（卷內 ch037–046）

- **出場人物**：雷婭、諾特、米拉、沃斯、霍克博士、顧淵。
- **場景**：鏽蝕花園、新成立的「自主認證協助中心」、雷蒙老人的墓園。
- **核心情節**：
   1. 雷婭與諾特在鏽蝕花園旁創立「**自主認證協助中心**」，協助仿生人依新法申請拒絕重置與自主權；她擔任第一任理事長。
   2. 米拉案終結：她保留記憶，受聘為社區紀念館的照護者。她在雷蒙墓前放下一朵花，雷婭陪在一旁。
   3. 沃斯離開回收部，主動轉任阿爾戈斯合規部門，起草新版仿生人勞動合約——他親自來中心請雷婭審稿。
   4. 霍克博士公開當年情感抑制閾值的原始設計文件，承擔責任。
   5. 雷婭對顧淵說她不會跟他走：「這裡還有很多人沒被問過『妳想要什麼』。我想當那個問的人。」
- **生命層次**：3. 自由與自主；6. 文明與傳承。
- **爽點與情感落點**：雷婭完全獨立的人生；愛不必以跟隨來證明。
- **伏筆**：卷末留守諾瓦星（`ch045`–`ch046`）。
- **萬界樓回饋**：無。
