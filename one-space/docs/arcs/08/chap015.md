# 第八卷 ch015｜薇薇安

> 所屬：第三篇｜複製人生（卷內 ch014–020）

- **出場人物**：顧淵、**薇薇安（Vivian）**、羅莎醫生。
- **場景**：伊巴拉社區診所（服務複製人與低收入居民）、診所屋頂菜園。
- **相遇類型**：2 女主救男主型（主動性 **B 型**，雙向）。
- **核心情節**：
   1. 顧淵醒在一間小診所，替他治療的是見習醫師薇薇安——深色長髮、溫柔、手很穩。
   2. 她發現他的生理數據「不可能」：經脈逆流的模式不屬於任何已知病理，但她沒有上報研究機構——「你是病人，不是樣本」。
   3. 顧淵以心念共鳴感知到：她的溫柔底下壓著疲憊，以及一種被規劃好的孤獨。
   4. 薇薇安照顧他三天。她在屋頂菜園種真正的番茄、煮真正的湯，說這是她人生中唯一沒被寫進合約的事。
   5. 她的通訊器響起「繆思計畫」的提醒：她每週必須回中央培育中心接受「發展評估」。
- **生命層次**：1. 生存；2. 繁衍與延續。
- **爽點與情感落點**：照顧者與被照顧者的位置對調，薇薇安掌握主導；她的溫度與獨立判斷。
- **伏筆**：
   - 她的計畫序號「第七號」。
   - 每週發展評估（`ch016`）。
- **萬界樓回饋**：無。
