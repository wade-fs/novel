* 消息傳回王家。  
* 王騰得知兩名執事一死一傷，怒不可遏。  
* 他認為柳清虛不可能在短時間內提升到這種程度，懷疑青雲觀使用了透支潛力的邪法。  
* 王氏三長老王海，金丹初期修為，則察覺柳清虛的氣息確實不同於一般築基修士。  
* 王海並不急著親自出手，而是提出動用王家底牌——**鎖靈烈陽陣**。  
* 此陣原本用於封鎖靈脈、截斷地氣，若布置在青雲山周圍，可逐步壓制護山大陣，並抽取山中靈氣。

* 王騰只知道家族要奪取青雲觀，並不完全清楚九幽濁魔煞的真正用途。

### **四、散修相助，青雲人心未散**

  1. 東側陣眼靈力輸送不均，容易被鎖靈烈陽陣干擾。  
  2. 西側陣旗年代久遠，陣紋已有裂痕。  
  3. 後山地脈節點受到外來煞氣侵蝕，與整座護山大陣形成不穩定的連結。

* 他準備利用王氏鎖靈烈陽陣與青雲觀護山大陣的衝突，反向引導部分煞氣。

## **第二輪整合後的長線因果**

這次最重要的調整，是讓五章的事件不再只是單純的宗門爭鬥，而是形成三層逐步揭露的陰謀。

## **青玄界事件的三層結構**

第一層・表面危機

**王氏逼婚、奪山、封鎖商道**

王騰以婚約為名逼迫柳清虛，王氏藉機奪取青雲觀山門與後山禁地。

第二層・真正陰謀

**王氏主導九幽濁魔煞事件**

王氏長期以特殊符籙與陣法侵蝕青雲觀靈脈，並利用九幽濁魔煞重創沈玄清，意圖控制後山某種力量。

第三層・全書主線伏筆

**萬界樓大劫的遺留力量**

九幽濁魔煞與沈玄清元嬰中的殘缺印記，涉及萬界樓大劫留下的古老力量。王氏可能掌握了部分秘密，卻未必真正理解其全貌。

## **需要特別鎖定的四項設定**

### **1\. 半步金丹的戰力定位**

| 對手 | 柳清虛的合理表現 |
| ----- | ----- |
| 普通築基中期 | 明顯壓制 |
| 普通築基後期 | 具有優勢 |
| 築基後期巔峰 | 可以取勝，但需要戰術與劍法 |
| 普通金丹初期 | 可以短時間抗衡，不能穩勝 |
| 金丹中期以上 | 不宜正面交戰 |

如此一來，第五章擊敗兩名築基執事、第六章斬殺王騰、第七章傷到王海，便有清楚的實力遞進。柳清虛不是突然擁有金丹境完整戰力，而是以特殊道基、劍法與臨場判斷跨越境界差距。

### **2\. 王氏主謀，但不能過早揭底**

王氏既然是九幽濁魔煞事件的主謀，便應當在前五章留下足夠線索，但不能讓王海在第五章就把整個計畫說得一清二楚。

建議分層揭露：

* **第三章**：孫道人身上的王氏血煞符。  
* **第四章**：黑色引煞符與青雲觀內奸網絡。  
* **第五章**：鎖靈烈陽陣與靈脈抽取的關係。  
* **第六章**：王氏高層動用家族底牌，證明其計畫早有準備。  
* **第七章**：沈玄清元嬰深處的殘缺印記，正式將事件連到萬界樓大劫。

王氏是主謀，但其所利用的力量可以遠超王氏本身的理解。這樣既保留王氏作為本篇主要敵人的份量，也能讓後續世界觀有繼續擴張的空間。

### **3\. 沈玄清不能只是等待被救的任務角色**

沈玄清與萬界樓大劫有關，這個設定值得保留她自身的故事線。

建議她甦醒後，能提供三項關鍵資訊：

* 當年她曾在後山禁地發現某種不屬於青玄界的遺物。  
* 她曾試圖封印或保護該遺物，因此遭到九幽濁魔煞侵蝕。  
* 她知道王氏背後有人或某種力量，但多年來無法查清真相。

這樣沈玄清不是單純的病人，而是掌握青玄界歷史秘密的重要人物。她的傷勢也不只是救治問題，而是解開萬界樓大劫線索的入口。

### **4\. 第二篇的核心不應只是救師雙修**

第七章的結尾可以保留「救師」的急迫感，但第二篇最好同時處理三個問題：

1. **救治沈玄清**：找出殘缺印記與九幽濁魔煞的真正關係，先解除致命威脅。  
2. **調查王氏**：查出王氏如何取得煞氣、如何操控靈脈，以及其背後是否另有協助者。  
3. **探索大劫遺物**：查明沈玄清所守護的東西，究竟與萬界樓遭逢的大劫有何關聯。

沈玄清必須先恢復意識、了解自己的狀況，才能自主決定後續的修煉方式與任何涉及親密關係的選擇。不能因為柳清虛急於救師，就替沈玄清作出決定。

## **第二輪整合結論**

建議採用

這五章的基本結構已經可以定稿為第一篇的前半段。

最重要的改進有三個：

* 柳清虛的成長有明確戰力上限，不會因為半步金丹就失去後續修煉空間。  
* 王氏從地方惡霸提升為有計畫、有技術、有長期布局的主要反派。  
* 沈玄清的傷勢成為萬界樓大劫主線的第一個實質入口，而不只是另一個需要男主救治的角色。

**我建議第二篇不要急著讓顧淵直接消滅王氏。** 王氏既然是主謀，就應該讓顧淵與柳清虛先掌握證據、查明煞源、找到地底遺物，再逐步拆解王氏的布局。這樣第一篇才不會在斬殺王騰後失去故事張力，萬界樓大劫的長線也能自然展開。
