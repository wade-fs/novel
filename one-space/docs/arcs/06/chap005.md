# 第005章｜無言撫髮

- **所屬篇章**：第一篇《歸樓星霜》（chap001～chap008）
- **地點**：青玄界・青雲後山・古仙石窟
- **主要人物**：顧淵、沈玄清
- **關鍵進度**：
  - **【必留名場面】**：顧淵深夜主動靠在沈玄清身邊，沈玄清無言撫髮接住他文瀾四年的重量。
  - **純情感留白章（不強塞雙修）**：徹底打破第一篇「一人一章輪流雙修」的流水帳節奏；萬界樓修復度維持 `680/10000`。

## 核心劇情
深夜，顧淵主動來到古仙石窟尋沈玄清。在所有女主之中，唯有這位閱歷超塵的太上仙尊最不需要他扮演強大與從容。他沒有開口訴苦，只是安靜在她身旁坐下，慢慢將頭靠向她肩頭；沈玄清什麼也沒問、什麼也沒分析，只是抬起溫潤玉手，極輕極穩地撫過他的長髮。兩人不急於完成肉體上的情感高潮，這份克制而深沉的靜夜陪伴本身便已勝過千言萬語。

## 場景節拍
1. **石窟夜色**：古仙石窟星圖微亮，沈玄清剛為他沏好一盞溫熱靈茶，便看見顧淵推門而入、眼底藏著一絲外人看不見的倦意。
2. **無言撫髮（必留核心戲）**：顧淵沒說話，在她身邊坐下慢慢靠了過去；沈玄清察覺他並未痊癒的凡塵重量——恢復修為不代表失去故人與別離文瀾的痛憑空消失——她隻字未問，只輕輕理好他衣袖、柔聲撫髮，讓他徹底鬆下心防。
3. **凡塵低語**：靜坐良久後，顧淵首次低聲提起文瀾界那位為護書犧牲的老僕周伯與白玉書院之火；沈玄清垂眸輕嘆「能記住凡人的名字，你這四年便沒有白走」，兩人相依靜坐至夜深，溫潤克制而不逾矩。
4. **九曜之約**：晨光微露時，沈玄清提及自己推演七界封魔陣（`SL-03`）遇瓶頸、亦已觸及元嬰大圓滿極限，若顧淵日後回訪九曜神域，她願同往一觀祭天壇與神道法則。

## 人物與關係重點
- **沈玄清**：成熟、穩重、深刻理解生命；她接住顧淵的脆弱，不急於推進高潮，展現最高級的留白與大氣。
- **顧淵**：徹底展現第五卷成長——學會「讓自己被接住」。

## 敘事原則與寫作提醒
- **純留白、不塞雙修**：這一章刻意不安排雙修，只寫「無言撫髮＋靜夜交心」，既保留最大情感重量，也讓第一篇節奏張弛有度、絕非流水帳。
