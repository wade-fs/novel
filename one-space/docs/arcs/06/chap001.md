# 第001章｜星門重啟

- **所屬篇章**：第一篇《歸樓星霜》（chap001～chap008）
- **地點**：萬界樓・本源核心大殿
- **主要人物**：顧淵、靈素、洛寒衣
- **關鍵進度**：
  - 顧淵重返萬界樓；因原本便非同時進出各界，三界各自物換星移。
  - **方案 B 落地**：洛寒衣質問過後，坦然告知顧淵「**我有個兒子**」，但暫時不帶孩子過來，先確認彼此關係並保護孩子。
  - 萬界樓修復度：`660/10000`（穩固）。

## 核心劇情
顧淵帶著文瀾四載的凡塵風霜重返萬界樓，修為與權限盡數回歸，卻刻意保留了肩背火痕與左臂刀疤。靈素傳訊三界後，一號星門率先洞開——率先踏入大殿的是手持斷星古劍的洛寒衣。她沒有撲入懷中，而是紅著眼將劍尖冷冷抵在顧淵胸口，質問他當年為何在空間亂流裡獨自推開自己；看見他袖口凡鐵刀疤情緒微震後，她沒有用隱瞞作為報復，反而直截了當地拋下一句令顧淵徹底怔住的真相——「我有個兒子。」

## 場景節拍
1. **歸樓守心**：顧淵整理袖中文瀾信物（焦尾舊弦、竹紙書籤、金石總目、紅箋匣、烏木印），不急跨界聯繫蔡琰，靜候三界星門回應。
2. **斷星抵胸**：星門白光驟亮，白衣勝雪的洛寒衣提劍步出，劍氣冷冽鎖定顧淵，開口只問「當年為何把我推出星門」。
3. **不許敷衍**：顧淵不再以「為了保護你」輕易搪塞，洛寒衣逼近半步，卻在看見他洗白粗布青衫袖口微露的凡鐵刀疤與氣質蛻變時，握劍的手微不可察地一顫。
4. **坦然告知有子（方案 B）**：洛寒衣收劍退開，既不肯像過去的顧淵那樣「替對方決定命運」、也無意用隱瞞來報復，遂冷靜直言：「我有個兒子，叫洛行舟，已經六歲了。」同時言明暫不帶孩子過來——她必須先確認兩人之間的關係與承諾，也不願讓阿舟突然面對一個陌生的父親。

## 人物與關係重點
- **顧淵**：褪去居高臨下的從容，聽聞自己竟有一個六歲兒子，震撼、愧疚與柔軟瞬間交織。
- **洛寒衣**：清冷直率、最厭惡替人做主；直接告知卻暫緩相見，既守住原則又保護孩子。

## 敘事原則與寫作提醒
- 開篇嚴禁急著長篇解釋文瀾界遭遇，先寫「他回來了」與人物最真實的情緒衝擊。
- 從第一篇就讓顧淵與讀者知道洛行舟的存在，為第三篇回滄瀾父子正式見面蓄滿期待。

## 伏筆與下章銜接
- 顧淵尚未從「已有六歲兒子」的震撼中完全回神，星門光影再閃，慕容玥、柳清虛與沈玄清相繼步入萬界樓大殿。
