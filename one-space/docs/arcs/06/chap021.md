# 第021章｜行宮卸防

- **所屬篇章**：第三篇《水月驚龍》（chap014～chap022）
- **地點**：滄瀾界・姑蘇大乾行宮・紫霄暖殿
- **主要人物**：顧淵、姬明月、姬明珩（已安睡）
- **關鍵進度**：
  - 顧淵與姬明月借文瀾上官婉兒信物論政、論明珠的造化承嗣與帝國未來。
  - 女帝卸下冠冕的深度智性戀與長篇雙修溫存。
  - **萬界樓本源修復**：**+25**（累計：**750/10000**）。

## 核心劇情
紫霄暖殿內龍涎香裊裊。安頓好四歲的明珠入睡後，姬明月屏退左右，與顧淵對弈論政。她翻看顧淵帶回的文瀾界烏木暗梅印（上官婉兒所贈）與大胤末年政局手記，以帝王眼光點評亂世士族與權力制衡，也首次向顧淵坦露獨自育女監國、既盼女兒成就大業又不願把她綁死在皇位上的複雜心境；卸下九五冠冕後，兩大強者在皇家深殿展開極致纏綿的智性與靈肉交融。

## 場景節拍
1. **異界論政**：姬明月摩挲著烏木暗梅印，對未曾謀面的大胤女史上官婉兒生出惺惺相惜的帝王讚賞，亦半開玩笑微醋道「顧樓主每去一界，總能招惹些世間最棘手的奇女子」。
2. **母心與帝心**：談及四歲聰慧卻未必喜權術的明珠，姬明月從帝國繼承與天下秩序的角度思索造化因緣——顧淵輕擁她坦言「明珠將來不必當女帝，她可以走出比皇位更寬廣的治世之路」，直擊女帝心防最柔軟處。
3. **冠冕卸防**：金簪散落、明黃外袍滑落肩頭；平日威壓天下的監國女帝在顧淵懷中徹底卸去所有防備，由強勢反客為主到鳳眸含波、汗透重裳，紫霄真龍氣運化作甘霖與《太上玄奼真經》共鳴，至純本源湧入萬界樓（**+25 → 750**）。
4. **私下索約**：溫存過後，姬明月慵懶倚在顧淵胸膛，抬指點著他左臂凡人刀疤，冷傲卻直白地要求他「下次離去前，記得先跟朕和明珠打聲招呼」。

## 人物與關係重點
- **姬明月**：絕不讓女帝突然變得柔弱討好；她的溫柔與吃醋永遠帶著帝王的坦蕩、驕傲與深情。

## 敘事原則與寫作提醒
- **雙修場景規格**：高冷女帝專屬「皇家奢靡 ＋ 智性交鋒 ＋ 極致卸防」長篇大戲，畫面感華貴張揚又極富情感張力。
