# 第030章｜赤煌熾誓

- **所屬篇章**：第四篇《月宮論道》（chap023～chap030）
- **地點**：九曜神域・熒惑赤煌神殿
- **主要人物**：顧淵、赫拉迪雅
- **關鍵進度**：
  - 顧淵與赫拉迪雅熾烈豪爽的戰後溫存共修（本卷鎖定四子，赫拉迪雅留待未來造化機緣）。
  - **萬界樓本源修復**：**+15**（累計：**800/10000｜8.00%**），正式達成【諸天神藏殿】第一重外殿開啟條件！
  - 第四篇《月宮論道》收束。

## 核心劇情
熒惑赤煌神殿烈酒飄香。赫拉迪雅與顧淵痛快對飲慶功，聽聞顧淵講起文瀾界那位不求歸屬、乘舟雲遊四海的自由女冠魚玄機，頓時豪爽拍案大笑「這凡人女子的脾氣倒合本座胃口！」轉眼她挑眉直白宣示主權，既不滿他久別不見、又爽快表達熾烈思念。卸下赤金神甲後，神火垂落星雨、戰意化作極致熱烈的靈肉交融，直接助萬界樓轟然跨越 **`800/10000`** 大關！

## 場景節拍
1. **烈酒直球**：赫拉迪雅單腳踩上長案舉樽暢飲，豪邁抱怨「清虛、寒衣、明月、羲凰連娃都抱上了，你小子欠本座的債打算怎麼還？」，有話直說、坦蕩又迷人。
2. **異界共鳴**：談起文瀾四年與魚玄機灑脫遠行，赫拉迪雅笑得赤髮飛揚，直言最欣賞顧淵從不試圖把女人關進金絲籠。
3. **神火不焚**：赤金戰甲卸落星毯，女武神強勢反撲將顧淵壓在星座之上，如熱烈雌豹般直率相邀；熒惑神火齊鳴而不焚、金紅星雨漫殿垂落，勢均力敵的熾烈交融與神魂誓約再度沸騰（**+15 → 800**）。
4. **八百破關**：極致陰陽共鳴湧入萬界樓，遠在星海深處的【諸天神藏殿】第一重外殿轟然發出太古鳴響！赫拉迪雅慵懶靠在顧淵懷裡挑眉大笑，順勢兌現卷四誓言——「擇日不如撞日，這趟本座親自跟你回萬界樓瞧瞧，順便跟青玄那幾位高手過兩招！」

## 人物與關係重點
- **赫拉迪雅**：熱情直白、豪爽吃醋卻大氣坦蕩，與前一章羲凰的靜謐莊重形成極致冷熱反差。
