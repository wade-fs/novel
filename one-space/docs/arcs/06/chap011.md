# 第011章｜藥理辨毒

- **所屬篇章**：第二篇《長安菊茶》（chap009～chap013）
- **地點**：青玄界・長安西郊清心閣 → 北嶺官道古驛
- **主要人物**：顧淵、貂蟬、洛寒衣
- **關鍵進度**：
  - 貂蟬憑醫道識破異界丹毒本質；洛寒衣循線鎖定北嶺暗樁。
  - 顧淵徹底踐行文瀾學到的「不以感知代判斷」實證作風。
  - 萬界樓修復度：`710/10000`。

## 核心劇情
貂蟬救下中毒採藥客，憑細緻藥理與《素月清心訣》辨明其毒並非青玄本土靈草所致，而是夾雜了異界殘丹廢渣偽裝成的廉價聚氣散。洛寒衣當夜御劍暗查北嶺車隊，鎖定一處打著「百草行」招牌的天行者外圍暗樁；面對可疑掌櫃，顧淵按捺直接出手與只憑心念感知的衝動，決定層層取證、連根拔起。

## 場景節拍
1. **銀針析毒**：貂蟬冷靜施針排毒，從藥渣裡篩出三粒極細微的暗灰晶屑；顧淵以破妄真視確認其含異界駁雜魔靈殘氣，與昔日黑市走私物如出一轍。
2. **血戒在心**：採藥客供出購藥行號與一名神色慌張的北嶺車夫；顧淵以心念共鳴察覺車夫滿心恐懼，卻立刻想起文瀾周伯的犧牲——絕不再把「恐懼」當成「有罪」，命人先查清車夫家眷是否受脅迫。
3. **劍影暗查**：洛寒衣欣慰看見顧淵的轉變，主動請纓夜探北嶺古驛，憑武王神識與無聲身法摸清「百草行」地窖暗倉與三名戴素面具的外圍執事。
4. **合圍佈局**：三人證實車夫確是受脅迫的無辜凡人，迅速擬定「救人質、奪密帳、端暗樁」三步實證之策。

## 人物與關係重點
- **顧淵**：具體呈現第五卷的思維成長，讓洛寒衣親眼看見他真的不再傲慢獨斷。
- **貂蟬**：以醫道專業成為破案關鍵核心，而非等待保護的花瓶。

## 敘事原則與寫作提醒
- 此章緊扣三界異常事件第一環（青玄線），為後續滄瀾與九曜的串聯打下堅實物證基礎。
