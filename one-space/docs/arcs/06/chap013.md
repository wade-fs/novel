# 第013章｜秋雨清心

- **所屬篇章**：第二篇《長安菊茶》（chap009～chap013）
- **地點**：青玄界・長安西郊・清心閣
- **主要人物**：顧淵、貂蟬、洛寒衣（翌晨啟程）
- **關鍵進度**：
  - 顧淵與貂蟬秋雨重契，貂蟬修為穩步邁向**築基中期**。
  - **萬界樓本源修復**：**+15**（累計：**725/10000**）。
  - 醫道初感造化因緣之奇（本卷鎖定四子，貂蟬留待未來機緣）。
  - 第二篇《長安菊茶》收束。

## 核心劇情
綿綿秋雨打在清心閣的白菊與竹簾上。久別重逢，貂蟬早已不是當初承天城裡需要藏身斂息的少女，而是心境澄明、能獨撐一方醫館的閣主。兩人圍燈煮茶、細數數載光陰與人間冷暖，在深厚理解與完全自願下重續白菊之約；共修之間，精於醫道的貂蟬隱約察覺兩人生命因緣深處似有一縷奇妙造化流轉，卻以醫者之心淡然珍藏。

## 場景節拍
1. **雨夜煮茶**：秋雨敲窗、藥香微暖，貂蟬替顧淵輕拭肩頭微濕水珠，坦誠訴說多年獨守清心閣的心境，也溫柔理解顧淵歷經文瀾後的沉靜滄桑。
2. **白菊重契**：紅燭竹簾之內，素衣輕解、秋菊暗香浮動；貂蟬從溫柔含蓄到踮腳主動相迎，純陽暖流與《素月清心訣》水乳交融，修為一舉穩固邁向築基中期，精純陰陽本源反哺古樓（**+15 → 725**）。
3. **醫者奇感**：事後相擁聽雨，貂蟬無意以醫道靈識探及顧淵脈象深處與天地共鳴的一縷溫和造化氣機，微笑輕語「公子身上的生命因緣，好像比從前更加厚重了呢」，為造化承嗣再埋一筆（不強行懷孕）。
4. **別菊赴瀾**：翌晨雨歇，貂蟬送顧淵與洛寒衣至白菊路口，與洛寒衣含笑約定他日再飲秋菊茶；顧淵與洛寒衣踏上赴滄瀾界之路，第二篇收官。

## 人物與關係重點
- **貂蟬**：溫潤獨立、醫者仁心，從生命與醫道視角為造化承嗣添上獨特切面。
