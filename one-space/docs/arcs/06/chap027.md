# 第027章｜財神配戰神

- **所屬篇章**：第四篇《月宮論道》（chap023～chap030）
- **地點**：九曜神域・太微玉京外城・水曜神系隱秘轉運庫
- **主要人物**：慕容玥、赫拉迪雅、水曜暗務執事（反派）
- **關鍵進度**：
  - 推進暗線 **`FB4-04`（水曜神系暗庫）**：揭破水曜部分神官暗通天行者倒賣神域星石與神格碎屑。
  - **慕容玥 × 赫拉迪雅**從作風摩擦到高度互補，建立深厚跨界信任。
  - 萬界樓修復度：`770/10000`。

## 核心劇情
太微玉京外城星港暗區，慕容玥與赫拉迪雅聯手追查水曜神系暗帳。兩人一開始作風南轅北轍——赫拉迪雅嫌查帳太磨蹭、恨不得直接提戟踹開水曜神殿大門；慕容玥卻笑眯眯拉住這位火爆戰神，提醒她「砸爛門抓不到帳本，倒會讓背後大魚全跑光」。經過一場精彩磨合，一商一武配合得天衣無縫，徹底端掉水曜暗庫！

## 場景節拍
1. **作風碰撞**：商盟暗閣內，赫拉迪雅拍案主張直接點兵圍庫，慕容玥拿著算盤寸步不讓講清「截斷資金流與釣出神官主使」的利害，赫拉迪雅先愣後大笑「難怪顧淵被你吃得死死的，聽你的！」
2. **誘魚出洞**：慕容玥偽裝成攜帶滄瀾太湖「水曜・星運」玉簡的跨界大買家前去接頭，三言兩語套出水曜暗務執事親手簽押的跨界密契與暗庫位置。
3. **重戟鎮場**：交易暗庫門啟剎那，赫拉迪雅赤紅神甲從天而降，熒惑重戟一擊鎖死所有傳送陣法，神威壓得暗庫護衛與天行者聯絡人動彈不得。
4. **滿載鐵證**：慕容玥當場封存整整三箱跨界密帳、異界星石與神格碎屑，顧淵、沈玄清與羲凰適時趕至匯合，準備清點這批牽動三界的重磅證據。

## 人物與關係重點
- **慕容玥 × 赫拉迪雅**：展現性格碰撞與作風互補的絕佳化學反應，趣味與爽感兼具。

## 敘事原則與寫作提醒
- 此章高光完全屬於慕容玥與赫拉迪雅，顧淵只在尾聲匯合壓陣，突出女主群像的自主行動力。
