# 第031章｜星樓小聚

- **所屬篇章**：第五篇《神藏初啟》（chap031～chap035）
- **地點**：萬界樓・本源大殿 → 觀星茶閣
- **主要人物**：顧淵、靈素、赫拉迪雅、柳清虛、洛寒衣、沈玄清、慕容玥
- **關鍵進度**：
  - **新交會達成**：**赫拉迪雅 × 柳清虛**首次正式見面。
  - 自然小聚（不強湊 14 人全員同堂，姬明月、西施、貂蟬、羲凰各守本界，文瀾五女不實體跨界）。
  - 萬界樓修復度：`800/10000`（穩固，【諸天神藏殿】外殿正蓄勢待啟）。

## 核心劇情
萬界樓修復度跨過 `800/10000` 後星輝浩瀚。赫拉迪雅首次真身踏入萬界樓，正巧遇上前來與沈玄清商議跨界陣法的柳清虛，以及因斷星古劍異鳴赴約回樓的洛寒衣。五位風格截然不同的女子於觀星茶閣自然小聚——從各自世界的風土聊到顧淵第一次當爹手足無措的窘態，既有慕容玥與赫拉迪雅帶頭起鬨的鮮活日常，又有互相體諒的真摯默契，萬界樓首度洋溢出「家」的熱鬧溫度。

## 場景節拍
1. **戰神入樓**：赫拉迪雅環顧萬界樓蒼茫星海讚嘆連連，與溫婉清冷的青雲掌門柳清虛首次照面——一個豪邁如火、一個清潤如蓮，卻意外對彼此的擔當與氣度生出好感。
2. **調侃樓主**：慕容玥與赫拉迪雅一唱一和，把顧淵在青雲山手忙腳亂哄微微、在滄瀾被六歲兒子拿木劍問得啞口無言的糗事全抖出來，惹得柳清虛掩唇輕笑、洛寒衣耳根微紅卻難得嘴角上揚，連沈玄清都含笑點頭。
3. **微醋與默契**：席間難免夾雜幾句「下次先去誰那邊過冬」「微微和阿舟誰更黏人」的鮮活爭寵拌嘴，卻全守著底線、溫馨而毫不傷和氣，讓顧淵既哭笑不得又滿心溫暖。
4. **約戰演武**：赫拉迪雅見柳清虛元嬰氣機凝實、洛寒衣斷星劍意更勝往昔，戰意瞬間燃起，豪爽拍案約戰【萬法演武殿】——「光喝茶不過癮，咱們三套體系去演武殿過過招！」

## 人物與關係重點
- **五女群像**：徹底呈現「既有吃醋拌嘴、又有共同信任」的真實大家庭魅力。
