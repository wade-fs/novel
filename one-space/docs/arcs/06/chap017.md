# 第017章｜明珠與阿舟

- **所屬篇章**：第三篇《水月驚龍》（chap014～chap022）
- **地點**：滄瀾界・姑蘇大乾行宮偏殿
- **主要人物**：顧淵、姬明月、**姬明珩（明珠・4歲・小公主）**、洛寒衣、洛行舟（阿舟・6歲）、慕容玥
- **關鍵進度**：
  - **第三子正式登場**：**姬明珩（女・4歲・乳名明珠・大乾小公主）**首度與父親顧淵相見。
  - 滄瀾二子（拿木劍的阿舟 × 愛問問題又任性貪玩的小公主明珠）同場趣味互動；諸女展現有底線的吃醋與家庭熱鬧感。
  - 萬界樓修復度：`725/10000`。

## 核心劇情
顧淵攜洛寒衣與阿舟抵姑蘇行宮，剛見過久別重逢、威儀更勝往昔的大乾女帝姬明月，殿簾後便溜出一名穿著杏黃小襦裙、抱著錦鯉布偶的四歲女童——正是大乾**小公主**「姬明珩（乳名明珠）」（姬明月簡短道出「珩」為玉佩上端橫玉，取盼她溫潤持衡、不失清雅之意）。她絕不是四歲的縮小版女帝，而是聰明愛問問題、記憶力驚人，卻也會任性、貪玩、坐不住、拉著人耍賴撒嬌的鮮活小女孩，轉眼就和拿木劍的阿舟展開了一場既拌嘴又投緣的幼童互動。

## 場景節拍
1. **小公主盤問與耍賴**：四歲的小公主姬明珩好奇湊到顧淵跟前，連珠炮似的問「你真是我爹？」「你去過的地方有比太湖更大的魚嗎？」「那你今天不許走，要陪明珠放紙鳶！」，記性好得連宮女隨口說過的異界故事都背得一清二楚，又拉著顧淵衣袖任性耍賴，把剛適應當爹的顧淵逗得連連失笑。
2. **木劍遇明珠**：六歲的阿舟見明珠坐不住四處翻顧淵的袖囊，一本正經護著木劍皺眉說她太鬧騰；明珠毫不示弱鼓著臉反駁，還搶過他木劍比劃著玩，兩人從拌嘴到合夥纏著顧淵講故事，生動可愛。
3. **兩母微較勁**：姬明月與洛寒衣站在一旁，嘴上談著姑蘇政務，眼神卻暗暗較勁——一個微抬下巴維護女兒「明珠只是活潑聰慧」，一個淡淡回敬「阿舟可不會翻人袖子」；慕容玥在旁看熱鬧不嫌事大，順手把兩個孩子都哄去吃桂花糕、順道向顧淵索討補償。
4. **切入正題**：孩子交由宮女與天劍弟子帶至花園玩耍後，姬明月神色一肅，攤開太湖水路輿圖，正式提起越溪水月閣主西施與太湖黑市之局。

## 人物與關係重點
- **姬明珩（明珠・4歲・小公主）**：聰明、愛問問題、記憶與理解力驚人，同時保留四歲孩童真實的任性、貪玩與撒嬌，絕不寫成縮小版姬明月。
- **家庭氛圍**：具體貫徹「允許有底線的吃醋與暗中較勁，孩子遇到事所有人立刻同心」。

## 敘事原則與寫作提醒
- 統一稱呼為「**小公主**」（不稱郡主），自然帶出「明珩」二字的命名寓意；兩個孩子的戲份鮮活討喜、點到為止，後半章俐落切入滄瀾主線。
