# 第七卷 ch003（全書 ch210）｜魔法師的規矩

> 所屬：第一篇｜魔法異界・初入艾瑟蘭（卷內 ch001–006｜全書 ch208–213）

- **出場人物**：顧淵、冒險者公會接待員、年輕法師、傭兵。
- **場景**：城鎮冒險者公會、魔法用品商店。
- **核心情節**：
   1. 顧淵了解冒險者公會、魔法師協會與地方領主的權責。
   2. 看到魔法師依照環級、師承與學院背景受到不同待遇。
   3. 一名貴族法師以身分欺壓平民，顧淵不直接出手，而是觀察當地制度如何處理。
   4. 他發現魔法文明雖然發達，仍有階級、資源與教育不平等。
   5. 透過公會任務，取得前往帝國腹地的合法通行資訊。
- **爽點與情感落點**：顧淵以異界常識不足的外來者姿態學習，而非事事全知。
- **伏筆**：魔法師協會公告中，出現一則關於古代法師塔異常的懸賞。
- **萬界樓回饋**：收錄艾瑟蘭社會制度與魔法師階級資料。
