# 第七卷 ch010（全書 ch217）｜失落法師塔

> 所屬：第二篇｜奧術求知・冰霜魔導（卷內 ch007–012｜全書 ch214–219）

- **出場人物**：顧淵、塞拉菲娜、研究助手、遺跡守衛。
- **場景**：達拉然外圍的古代法師塔。
- **核心情節**：
   1. 塞拉菲娜邀請顧淵前往失落法師塔，驗證符文推論。
   2. 兩人破解外層結界，發現塔內保存大量古代研究紀錄。
   3. 遺跡守衛啟動，顧淵負責牽制，塞拉菲娜負責破解控制符文。
   4. 兩人首次展現真正的合作默契。
   5. 塔內資料顯示，古代魔法師曾研究世界樹以太循環。
- **情感落點**：由學術合作進入實際信任。
- **伏筆**：遠古符文中出現「根部封印」與「外來死氣」等模糊記載。
- **萬界樓**：取得古代符文拓本，作為後續研究素材。
