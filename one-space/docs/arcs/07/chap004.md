# 第七卷 ch004（全書 ch211）｜無咒施法

> 所屬：第一篇｜魔法異界・初入艾瑟蘭（卷內 ch001–006｜全書 ch208–213）

- **出場人物**：顧淵、地方法師、冒險者小隊。
- **場景**：城鎮外的魔獸出沒區。
- **核心情節**：
   1. 冒險者小隊遭遇魔獸襲擊，地方法師因精神干擾無法完成咒語。
   2. 顧淵出手，以東方術法迅速化解危機。
   3. 他沒有使用魔杖、咒語或魔法陣，令在場法師震驚。
   4. 當地法師試圖以魔法理論解釋顧淵的施法方式，卻找不到對應分類。
   5. 顧淵意識到，自己的力量在此界並非不能使用，只是缺乏當地的理論對照。
- **爽點與情感落點**：東方修仙手段首次在西方魔法文明中展現差異。
- **伏筆**：一名旁觀者將顧淵的施法方式記錄，準備送往奧術評議會。
- **萬界樓回饋**：建立「異界施法方式比較」研究條目。
