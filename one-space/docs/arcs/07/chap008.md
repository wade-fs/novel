# 第七卷 ch008（全書 ch215）｜冰霜魔導的傲氣

> 所屬：第二篇｜奧術求知・冰霜魔導（卷內 ch007–012｜全書 ch214–219）

- **出場人物**：顧淵、塞拉菲娜、研究助手、其他法師。
- **場景**：學院實驗室、魔法材料市場。
- **核心情節**：
   1. 顧淵參與塞拉菲娜的符文實驗。
   2. 塞拉菲娜對實驗精度要求極高，對助手與顧淵都毫不客氣。
   3. 顧淵指出她的魔力迴路有一處長期被忽略的偏差。
   4. 塞拉菲娜起初不服，經過驗證後發現顧淵的觀察正確。
   5. 她第一次承認顧淵不只是力量特殊，也具備值得交流的知識。
- **情感落點**：從質疑轉為尊重。
- **伏筆**：魔力迴路偏差可能是過去反噬留下的隱患。
- **萬界樓**：記錄魔力迴路與修仙經脈的差異。
