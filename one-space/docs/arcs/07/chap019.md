# 第七卷 ch019（全書 ch226）｜帝國的邀請

> 所屬：第四篇｜帝國暗流・聖殿騎士（卷內 ch019–024｜全書 ch226–231）

![第四篇｜帝國暗流・聖殿騎士](../../../images/07041-第四篇-帝國暗流.png)

**篇章目的**： 以帝國政治、騎士制度與禁忌鍊金事件，建立菲奧娜的獨立故事線。她的核心衝突是「忠於帝國」與「忠於騎士信念」未必永遠一致。

- **出場人物**：顧淵、菲奧娜、帝國使者。
- **場景**：星輝帝國邊境城、皇家騎士駐地。
- **核心情節**：
   1. 顧淵離開精靈庭院，前往星輝帝國尋找泰坦遺跡資料。
   2. 因先前在邊境展現過特殊施法方式，帝國方面邀請他接受調查。
   3. 菲奧娜以聖殿女騎士長身分負責接觸。
   4. 她不接受顧淵以「異界旅人」作為全部解釋，要求他說明來歷與目的。
   5. 顧淵願意配合有限調查，但不接受無條件拘束。
- **情感落點**：菲奧娜對顧淵保持警戒，兩人立場鮮明。
- **伏筆**：帝國近來有多起魔法生物異變事件。
- **萬界樓**：收錄帝國騎士制度與軍事魔法資料。
