# 第七卷 ch023（全書 ch230）｜騎士的抉擇

> 所屬：第四篇｜帝國暗流・聖殿騎士（卷內 ch019–024｜全書 ch226–231）

- **出場人物**：顧淵、菲奧娜、帝國高層、騎士團成員。
- **場景**：帝國聖殿、騎士團議事廳。
- **核心情節**：
   1. 菲奧娜將調查結果呈報，卻遭到上級要求暫停調查。
   2. 她發現部分權貴可能涉入黑袍會。
   3. 騎士團內部有人主張服從命令，有人支持繼續追查。
   4. 菲奧娜拒絕隱瞞證據，但也不貿然發動內鬥。
   5. 顧淵協助她保全證據，讓她有機會向更高層的正直派系求援。
- **情感落點**：菲奧娜展現獨立判斷，顧淵不替她決定。
- **伏筆**：黑袍會核心人物已前往遠古遺跡。
- **萬界樓**：記錄帝國政治勢力與黑袍會關聯。
