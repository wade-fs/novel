# 第七卷 ch020（全書 ch227）｜騎士的試探

> 所屬：第四篇｜帝國暗流・聖殿騎士（卷內 ch019–024｜全書 ch226–231）

- **出場人物**：顧淵、菲奧娜、皇家騎士。
- **場景**：帝國騎士訓練場。
- **核心情節**：
   1. 菲奧娜安排一場有限度的實力測試，確認顧淵是否具備威脅。
   2. 顧淵不以全力應戰，而是以技巧化解騎士攻勢。
   3. 菲奧娜察覺顧淵有意控制實力，對他的真實能力更加好奇。
   4. 她展示帝國魔法騎士的戰鬥方式，說明魔法與武技如何結合。
   5. 顧淵指出騎士體系重視戰場配合，與單純法師有不同價值。
- **情感落點**：從懷疑轉為初步尊重，但尚未建立私人信任。
- **伏筆**：訓練場一名騎士的裝備出現不正常的魔力侵蝕。
- **萬界樓**：收錄魔法騎士的體魄、意志與魔力運用資料。
