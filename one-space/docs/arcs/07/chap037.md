# 第七卷 ch037（全書 ch244）｜泰坦核心

> 所屬：第六篇｜星樹之劫・魔法新生（卷內 ch035–040｜全書 ch242–247）

- **出場人物**：顧淵、塞拉菲娜、菲奧娜、帝國騎士、奧術法師、龍族使者。
- **場景**：泰坦核心主遺跡。
- **核心情節**：
   1. 聯盟抵達泰坦核心主遺跡，發現黑袍會已先一步進入。
   2. 菲奧娜帶領騎士團阻止黑袍會外圍部隊。
   3. 塞拉菲娜破解核心控制符文，發現泰坦文明曾將世界樹與多個以太節點連成一套調節系統。
   4. 顧淵發現核心的問題不是能量不足，而是循環方向被扭曲。
   5. 黑袍會首腦啟動錯誤控制程序，造成遺跡全面失控。
- **爽點與情感落點**：各角色各司其職；顧淵展現實力但不搶走所有人的功勞。
- **伏筆**：黑袍會首腦可能也只是利用者，真正的異常力量來自封印深處。
- **萬界樓**：取得泰坦核心完整結構資料，但尚未恢復。
