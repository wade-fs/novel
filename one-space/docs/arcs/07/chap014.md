# 第七卷 ch014（全書 ch221）｜月曜祭司

> 所屬：第三篇｜精靈月曜・生命之樹（卷內 ch013–018｜全書 ch220–225）

- **出場人物**：顧淵、艾琳諾、精靈長老。
- **場景**：翠玉庭院、月曜神殿。
- **核心情節**：
   1. 艾琳諾帶顧淵進入精靈庭院，介紹精靈族的生命傳承。
   2. 顧淵發現精靈魔法不是單純控制能量，而是與自然生命建立共鳴。
   3. 艾琳諾展示月曜祭儀，說明祭司與世界樹之間的生命印記。
   4. 精靈長老對顧淵的來歷有所疑慮，要求他不得接近世界樹核心。
   5. 艾琳諾為顧淵作有限擔保，讓他能在庭院停留研究。
- **情感落點**：艾琳諾願意給予顧淵初步信任，但不因他的力量而盲目親近。
- **伏筆**：艾琳諾的生命印記偶爾出現灰暗紋路。
- **萬界樓**：收錄精靈生命印記的基本結構。
