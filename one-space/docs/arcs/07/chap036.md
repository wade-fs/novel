# 第七卷 ch036（全書 ch243）｜世界樹的傷口

> 所屬：第六篇｜星樹之劫・魔法新生（卷內 ch035–040｜全書 ch242–247）

- **出場人物**：顧淵、艾琳諾、塞拉菲娜、精靈守護者、奧術研究者。
- **場景**：世界樹根部、精靈禁區。
- **核心情節**：
   1. 聯盟進入世界樹根部，確認以太循環已出現結構性失衡。
   2. 塞拉菲娜破解古代符文，發現封印並非單純破損，而是被人為改寫。
   3. 艾琳諾以生命印記穩定根脈，承受巨大負荷。
   4. 顧淵協助隔離死氣，卻無法單獨恢復整個生命循環。
   5. 三人確認必須前往泰坦核心主遺跡，從源頭修正失衡。
- **情感落點**：艾琳諾不再只把自己當成犧牲品；她願意與同伴共同承擔。
- **伏筆**：世界樹根部的古老印記，與萬界樓某些禁制有更深層的結構相似。
- **萬界樓**：取得世界樹根部能量結構資料；不將短暫穩定誤算為完整修復。
