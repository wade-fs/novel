# 第七卷 ch035（全書 ch242）｜四方會議

> 所屬：第六篇｜星樹之劫・魔法新生（卷內 ch035–040｜全書 ch242–247）

![第六篇｜星樹之劫・魔法新生](../../../images/07043-第六篇-星樹之劫.png)

**篇章目的**： 收束世界樹危機，但不讓顧淵一個人包辦所有問題。三位正式女主必須各自完成自己的角色弧線，並在最終事件中發揮不可替代的作用。

- **出場人物**：顧淵、艾琳諾、塞拉菲娜、菲奧娜、奧術評議會代表、精靈長老、帝國使者。
- **場景**：達拉然浮空群島、跨勢力議事廳。
- **核心情節**：
   1. 顧淵將泰坦核心資料交給塞拉菲娜分析。
   2. 艾琳諾提供世界樹根脈與生命印記資料。
   3. 菲奧娜帶來黑袍會與帝國內部調查結果。
   4. 三條線索拼合，確認世界樹衰竭與泰坦核心失衡有關。
   5. 各勢力對是否聯合行動仍有分歧，尤其擔心遺跡力量被其他勢力掌握。
   6. 三位女主各自以自己的身分提出合作條件，促成暫時聯盟。
- **情感落點**：三人首次在同一事件中展現各自立場，彼此尚未必然熟悉。
- **伏筆**：黑袍會已取得部分核心控制資料，可能搶先啟動裝置。
- **萬界樓**：將三條研究線整合為泰坦核心研究檔案。
