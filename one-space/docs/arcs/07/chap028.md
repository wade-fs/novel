# 第七卷 ch028（全書 ch235）｜女王召見

> 所屬：第五篇｜沙漠古國・失落秘法（卷內 ch025–034｜全書 ch232–241）

- **出場人物**：顧淵、克麗奧佩脫拉七世、宮廷祭司、近衛。
- **場景**：王宮星辰殿。
- **核心情節**：
   1. 顧淵正式受到女王召見。
   2. 克麗奧佩脫拉以外交談判的方式試探他的來歷、目的與能力。
   3. 顧淵不願透露萬界樓的全部秘密，只說自己來自遙遠的異界文明。
   4. 女王發現顧淵對王位、財富與政治利益沒有明顯企圖。
   5. 她提出以古代遺跡資料交換顧淵的協助，雙方暫時達成合作。
- **情感落點**：女王對顧淵產生好奇，顧淵則欣賞她的智慧與從容。
- **伏筆**：女王提到一位曾與王室合作的外國統帥，暗示歷史上安東尼式的政治人物。
- **萬界樓**：收錄王室星辰秘法的有限資料。
