# 第七卷 ch027（全書 ch234）｜黃金王都

> 所屬：第五篇｜沙漠古國・失落秘法（卷內 ch025–034｜全書 ch232–241）

- **出場人物**：顧淵、王都守衛、宮廷官員、祭司。
- **場景**：沙漠古王國王都。
- **核心情節**：
   1. 顧淵抵達王都，見識金色石材建築、神殿、地下水道與星象高塔。
   2. 王都繁華之下，民眾對帝國勢力擴張與王位繼承問題各有憂慮。
   3. 顧淵發現王都的魔法結界由王室血脈與古代祭司共同維持。
   4. 宮廷官員得知他掌握遠古遺跡線索，安排他接受王室接見。
   5. 顧淵從旁觀察宮廷派系，察覺女王雖然掌權，卻受到多方勢力牽制。
- **爽點與情感落點**：王都奇觀與政治觀察，顧淵不急著介入。
- **伏筆**：王室結界有一部分能量正被地下某個封印吸走。
- **萬界樓**：建立古王國座標與文明資料。
