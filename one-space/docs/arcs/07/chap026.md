# 第七卷 ch026（全書 ch233）｜星辰祭司

> 所屬：第五篇｜沙漠古國・失落秘法（卷內 ch025–034｜全書 ch232–241）

- **出場人物**：顧淵、沙漠祭司、商隊成員。
- **場景**：沙漠綠洲、古代星象神殿。
- **核心情節**：
   1. 商隊在綠洲停留，顧淵接觸當地祭司。
   2. 祭司透過星盤預測沙暴與商道變化，展現與主流奧術不同的魔法方式。
   3. 顧淵發現星象魔法並非直接操控星辰，而是透過特定時間與星辰位置引導力量。
   4. 祭司對顧淵的東方修煉方式產生興趣，雙方進行有限交流。
   5. 祭司提及王室掌握一座不對外開放的古代星辰圖書庫。
- **情感落點**：顧淵以尊重態度接觸陌生傳承，不將其視為落後或異端。
- **伏筆**：星象圖中有一處異常星位，與泰坦遺跡座標吻合。
- **萬界樓**：收錄星象魔法與時序規律資料。
