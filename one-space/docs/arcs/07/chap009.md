# 第七卷 ch009（全書 ch216）｜學院競演

> 所屬：第二篇｜奧術求知・冰霜魔導（卷內 ch007–012｜全書 ch214–219）

- **出場人物**：顧淵、塞拉菲娜、學院學生、其他學派代表。
- **場景**：達拉然學院競演場。
- **核心情節**：
   1. 學院舉辦公開魔法競演，展示不同學派的法術。
   2. 顧淵觀察元素魔法、召喚術、結界術與符文術的差異。
   3. 塞拉菲娜參加高階符文展示，遭到另一派系的質疑。
   4. 她以精準控制證明自己的研究價值，但也暴露過度消耗精神力的問題。
   5. 顧淵沒有代替她出手，只在事後指出她的施法風險。
- **情感落點**：塞拉菲娜開始在意顧淵對自己的評價。
- **伏筆**：競演場地的魔網短暫紊亂，與邊境魔法燈故障出現相似徵兆。
- **萬界樓**：收錄多學派魔法資料。
