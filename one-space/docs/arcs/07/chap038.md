# 第七卷 ch038（全書 ch245）｜深淵逆流

> 所屬：第六篇｜星樹之劫・魔法新生（卷內 ch035–040｜全書 ch242–247）

- **出場人物**：顧淵、艾琳諾、塞拉菲娜、菲奧娜、黑袍會首腦、龍族力量代表。
- **場景**：泰坦核心深層、世界樹根脈投影區。
- **核心情節**：
   1. 核心失控引發深淵死氣逆流，世界樹與遺跡同時受到衝擊。
   2. 菲奧娜維持外圍防線，阻止黑袍會殘部破壞撤離通道。
   3. 塞拉菲娜破解核心符文，找出能夠重新導正循環的結構。
   4. 艾琳諾以生命印記連結世界樹，穩定生命端的能量。
   5. 顧淵以自身修行之道調和不同能量，避免核心再次崩潰。
   6. 黑袍會首腦企圖奪取核心，最終因錯誤控制而被核心反噬。
- **情感落點**：三位女主不再只是顧淵的同行者，而是能與他共同完成重大選擇的夥伴。
- **伏筆**：核心恢復後，出現一瞬間跨世界的空間波動。
- **萬界樓**：取得深淵死氣與泰坦核心的完整對照資料。
