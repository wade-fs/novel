# 第七卷 ch022（全書 ch229）｜真理黑袍會

> 所屬：第四篇｜帝國暗流・聖殿騎士（卷內 ch019–024｜全書 ch226–231）

- **出場人物**：顧淵、菲奧娜、帝國調查官、黑袍會成員。
- **場景**：帝國地下鍊金工坊。
- **核心情節**：
   1. 顧淵與菲奧娜追查鍊金殘留物，找到地下實驗場所。
   2. 發現黑袍會正在研究生命本源抽取。
   3. 實驗紀錄提及精靈純血與巨龍之魄。
   4. 菲奧娜震驚於實驗的殘酷，決定立即封鎖工坊。
   5. 黑袍會成員引爆部分實驗設備逃逸，留下不完整研究紀錄。
- **情感落點**：菲奧娜開始把顧淵視為共同調查者，而非單純被監視的外來者。
- **伏筆**：實驗紀錄暗示有人從帝國高層提供資源。
- **萬界樓**：收錄禁忌鍊金資料；不把研究成果直接轉成修復點數。
