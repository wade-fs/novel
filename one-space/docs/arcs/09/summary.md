## 一、核心主題與紅線速覽

- **全卷主題**：**「出生決定起點，選擇決定方向。」** 幽羅界奉行嚴密「天序」位階制度，力量可升、社會位置難改；全卷無絕對善惡陣營，統一稱為**「六種立場」或「利益網絡」**（守序派、改革派、奪權派、利用派、旁觀派、滲透網絡——不誤稱「六派勢力」，亦不寫成六個正式組織或軍隊：改革派欲「改變制度本身」、奪權派只欲「更換掌權者」，呼應「換了統治者，不等於換了命運」；利用派屬利益邏輯、滲透網絡屬無統一領袖的跨陣營行動方式）。
- **敘事視角**：**三人有限第三人稱視角**（**顧淵／閻玄霜／夜千羅**），打破單一男主壟斷。
- **萬界樓同步敘事與三處銜接（對齊第八卷＆第十卷）**：不另開搶篇幅的樓內主線，但延續第八卷結尾變化（二層解封、靈素初蛻、萬靈共鳴苑與星箋亭啟用），僅設三處克制銜接——① **出發前**：顧淵與靈素確認幽羅界道標訊號；② **中段**：靈素樓內日常與小變化片段（角色延續而非伏筆堆積）；③ **歸樓後**：道標物**先封存再由顧淵與靈素共同初步檢視**（不解鎖新區域、不增修復度、靈素不突然恢復記憶），僅讓顧淵意識到「萬界樓值得重新認識」，自然過渡第十卷。
- **不可提前揭露紅線（七條）**：不揭靈素太古真名與完整身世、不揭萬界樓終極本質、不解上任樓主與顧淵完整關係、不揭 `SL-01` 諸天蝕者真身與邏輯、不讓道標物解鎖終極功能、不讓靈素因道標物突然恢復完整記憶、不將蓋婭／利維坦永久留白帶入幽羅界主線。
- **三條不可犧牲原則**：
  1. 幽羅界不能因顧淵而被拯救（不推翻天序，不替原界完成改革）。
  2. 閻玄霜與夜千羅皆**留在幽羅界**繼續獨立人生，不隨顧淵離開。
  3. 兩女的改變皆須付出**真實代價且成長路徑保持差異**（不寫成同步自我犧牲模板：閻玄霜的核心是從家族利益執行者轉為能獨立承擔判斷後果的人，違令後失去部分家族信任與安全感；夜千羅的核心是放棄多年苦求的半合法「開紋薦舉契」並承擔過去交易的責任）。
- **收穫分層與修復度規則**：嚴格分開定義三類項目——① **一般探索／運轉資源**（探索、交易與事件所得，不等於修復度）；② **古代遺物／萬界道標物**（第七篇真相揭露前稱「古代遺物」，揭露後正式稱「萬界道標物」；歸樓後先封存再由顧淵與靈素共同初步檢視，不解鎖新區域、取得本身不增加修復度）；③ **修復點數（修復度）**（僅依既有萬分制自願雙修規則結算）。**本階段不先填寫預估修復度結果**，待雙修情節定案後再依原規則計算。
- **失蹤者核心因果（拒寫活人血祭套路）**：高門多道分流迴紋近身探查古代遺物反而遭強烈排異，低階單線序紋衝突面積小反能短暫撐住共鳴——幽羅界誤讀為「低階重塑序紋的升階秘法」，高門遂包裝「升階試煉」誘騙／招攬低位階充當**替高層試錯的活體樣本**（制度性試錯）；同時將曾經手古代遺物流轉鏈的各階知情者／鑑定師劫走逼問或封口（流轉封口）。

## 二、八篇劇情主軸速覽（彈性章數參考，合計約 43–52 章）

1. **第一篇《異界來客》（建議 5–6 章）**：出發前與靈素於觀覽台確認幽羅界道標訊號（銜接①）；顧淵降臨幽羅界普通城鎮，與機靈的利用派情報掮客**夜千羅**展開交易。夜千羅以低階「單線序紋」強煉缺了鎮煞引與分流法的高純凝煞髓導致逆衝（《逆行的修為》），權衡四層現實約束後主動向顧淵提出雙修交易，借《太上玄奼真經》前四篇既有迴路洩壓（僅為《乾坤互補》前置現象）。危機化解而位階未變；**事後夜千羅主動重新評估顧淵的價值**（非愛上或信任，而是發現這筆交易結果超出她原先估算，確立兩人自首篇起即為雙向博弈而非單向救助或修煉素材）。兩人自情報交易觸及跨位階連環失蹤案，顧淵感應到與萬界樓目標之關聯。
2. **第二篇《旁觀者的委託》（建議 4–5 章）**：旁觀派高門閻氏重要成員**閻玄霜**奉命查核失蹤案是否波及家族情報，透過管道接觸活躍的夜千羅，兩女以「高門身分資源 vs 地下人脈情報」首度交鋒。顧淵意外成為交易樞紐，引來閻玄霜對其外來身分的警覺。
3. **第三篇《失蹤者的名單》（建議 5–6 章）**：三人暫時合作調查，發現失蹤者橫跨高低位階，包含受騙、自願與追逐升階機會者；夜千羅發現自己過去按合理判斷賣出的情報（某類人出沒地點、資源流向或自認過期之舊檔；明知有風險卻不知落到誰身上）恐連累失蹤者，閻玄霜發現閻氏早握名單卻秘而不宣，顧淵則察覺失蹤地點與萬界樓異常反應相符——三人各有隱瞞，尚未互信。
4. **第四篇《各方的答案》（建議 5–6 章）**：深入跨立場交易圈，見證六種立場圍繞同一神秘目標展開交易、雙面滲透與背叛。閻玄霜遭家族勒令停查；夜千羅一面推進多年經營的序紋司「補錄開紋資格（開紋薦舉契）」線索（搭上即將離任的審核執事），一面收到天價委託要出賣顧淵行蹤；過往隱瞞曝光令夜千羅與顧淵爆發正面衝突（雙修不等於信任）。
5. **第五篇《被選中的人》（建議 6–7 章）**：於中段穿插簡短樓內靈素日常與觀察片段（銜接②，角色延續不強塞情報）。尋獲以「升階試煉」為名的秘密測試與留置場所（非活人血祭祭壇，而是將底層修士當成替高層測試古代遺物序紋共鳴門檻的活體試錯樣本，並留置遭封口的遺物流轉知情者）。夜千羅長期信奉的「只要我不直接動手，後果就不必由我負責」徹底崩解，與顧淵關係降至冰點甚至決裂；閻玄霜則自行查證看清「閻氏中立並非沒有代價、安全與利益建立在他人犧牲之上、運作方式並不如想像中乾淨」，憑獨立判斷（而非被顧淵說服）開始脫離家族視角；顧淵找到眾人爭奪的古代遺物，察覺它並非力量源頭。
6. **第六篇《背叛者的宴席》（建議 7–8 章）**：各方藉商討失蹤案之名召開壓下黑幕、瓜分古代遺物的秘密會議，三人分頭入局；閻玄霜於家族命令與獨立判斷間抉擇，夜千羅遭更高層交易商反向利用，顧淵察覺古代遺物與萬界樓跨界機制產生強烈共鳴（尚未正式揭露定性）。機密走漏後爆發**「四方誤判連鎖」**（**五個環節皆留充分反應與發酵時間，由前一步造成的真實局勢推動下一步**）：交易商與暗線走漏機密 → **旁觀派閻氏**基於充分合理的家族風控考量（避免交帳自曝、避免站隊遭清算、封關保產留籌碼）冷靜拒絕調停並封門抽身 → **守序派**見真空與流言蔓延遂預防性過度鎮壓（封鎖下城、斷散煞並大舉搜捕）→ **改革派**在封城滅頂之危下退無可退，被迫提前公開黑幕、號召破封 → **奪權派**藉滲透暗線散播扭曲傳言趁亂奪走古代遺物；秩序瓦解，三人被迫分散。
7. **第七篇《幽羅之亂》（建議 8–10 章）**：第六篇的四方連鎖誤判引爆幽羅界既有矛盾全面爆發（改革派遭奪權派在權力重分配關頭反手背刺而正式反目，利用派因封城與籌碼翻盤自相殘殺）。奪權派（或失控奪位方）誤信傳說強將古代遺物接入主城**幽煞地脈樞紐**欲強改天序；顧淵追至現場並透過萬界樓徹底驗證其跨界指向本質，**至此正式揭曉古代遺物實為「萬界道標物」**——狂暴幽煞強灌入不相容的外界道標反而撕裂空間縫隙、引發**全城地脈煞氣倒灌暴走**（與第一篇《逆行的修為》形成宏觀鏡像）。顧淵的作用嚴格限於「確認失頻共鳴→在兩女配合下將道標物剝離陣眼暫收入樓壓制共鳴」，細小裂隙靠本土世界壁壘彈性逐步收縮癒合，**絕不修復幽羅界地脈**——已倒灌煞潮由幽羅界自行扛下。**兩女成長錯開節奏、保持動機與掙扎差異**：**夜千羅**推回序紋司執事握有的半合法「開紋薦舉契」（放棄個人上升機會、承擔過往交易責任），引導撤離並為顧淵開路；**閻玄霜**憑獨立判斷違令強開閻氏泄壓緩衝閘口與私人通道（從家族執行者轉為獨立承擔判斷後果的人）。兩條感情線各自獨立成熟，以截然不同的「神意無間、彼此託付」自然開啟《乾坤互補》正式實修。
8. **第八篇《各自的道路》（建議 3–4 章）**：失蹤案落幕而天序仍在；閻玄霜回閻氏明確劃出個人底線，夜千羅重掌情報網卻推回觸及底線的天價委託；兩女建立不必完全認同卻彼此信賴的關係；顧淵告別離界，閻玄霜與夜千羅分立不同位置目送光芒消散。歸樓後將**道標物先封存再與靈素共同初步檢視**（銜接③：不解鎖新區域、不增修復度、靈素不驟復記憶），顧淵首度浮現「萬界樓值得重新認識」之疑問，自然過渡第十卷。

## 三、雙修反差與三大伏筆速查

- **夜千羅（低位階｜先雙修，後相愛）**：第一篇為化解修為失控主動交易雙修，**危機解除後主動重新評估顧淵價值**（結果超預期，建立雙向博弈而非單向救助） → 第二至三篇各有算計 → 第四至五篇衝突決裂 → 第六至七篇不計報酬相助（放棄開紋薦舉契、承擔過往交易責任） → 第七至八篇真正傾心託付意志再次雙修。
  - **首次雙修埋下三大伏筆**：① 隱瞞資源來源（關聯失蹤案）；② 對顧淵認識不完整（重估後仍以為能以交易框架框住他）；③ 低位階修為異常改善引來地下圈與各方勢力盯梢。
- **閻玄霜（高位階｜先信任，後親密）**：第二至三篇初遇試探與合作觀察 → **第四至五篇產生真正興趣**（超越單純利益衡量，並保有獨立見解） → **第六至七篇建立深層信任並確認心意**（由家族利益執行者轉為獨立承擔判斷後果之人），於第七篇在有能力拒絕的前提下自主選擇顧淵，完成首次雙修（與夜千羅成長節奏錯開、心理掙扎與代價皆具差異）。
- **功法承接（《太上玄奼真經・乾坤互補》）**：承接第八卷破千顯影之總綱扉頁，**明確區分「前置現象」與「正式修煉」，並避免寫成系統好感度判定**：① **第一篇＝前置現象（未入篇）**：化解夜千羅《逆行的修為》實質靠前四篇既有迴路、僅借扉頁「順勢借道分流」一句微意；雙方各留戒心未達「神意無間」門檻，事後內視扉頁僅一閃即黯、正篇經文完全未展開且僅照常規結算。② **第七篇＝正式修煉（入篇開啟）**：核心在於**「神意無間、彼此託付」**——夜千羅由交易轉為不計報酬地交付真實意志，閻玄霜在不依附家族、不需要拯救下自主選擇平等同行一段親密關係；兩種截然不同的真實契合自然開啟《乾坤互補》實修，同時維持戰力克制。
- **跨卷主線伏筆**：第七篇確認之萬界道標物帶回樓內先封存、再與靈素共同初步檢視（不立即解鎖新區域、不增修復度、不觸發靈素記憶驟復），讓顧淵自然浮現對萬界樓結構與靈素的新疑問，為第十卷《萬界樓・返照本源》鋪平入口。
