## 目錄規範與 novel-reader 閱讀說明

本書為 `novel-reader` 的原型參考格式：

1. **目錄結構**：
   - 章節放置於 `chapters/volume1/` 至 `chapters/volume6/`。
   - 檔名統一採用 `chap001.md` ～ `chap540.md`。
2. **標題格式**：
   - 每章第 1 行為標準 H1 標題（例如 `# 第一章　上都煙塵`）。
3. **編碼**：
   - 全書 540 章全面採用標準 UTF-8 編碼。
