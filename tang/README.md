# 《唐末》——長安秋暮・中原風雲

唐末五代至宋初（875–979 年）歷史群像小說（千載風雲系列）。

- **上冊**：《長安秋暮》（唐朝晚年衰敗、舊秩序瓦解至唐亡）
- **下冊**：《中原風雲》（五代十國權力轉移至宋初統一）
